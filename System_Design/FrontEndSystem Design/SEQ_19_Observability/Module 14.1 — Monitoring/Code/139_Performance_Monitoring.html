Performance monitoring — from lab data to production signals

Lighthouse scores in CI tell you what could happen in ideal conditions. Production performance monitoring tells you what does happen for real users on real devices and networks. The key hierarchy: Core Web Vitals (LCP, CLS, INP) → Custom spans (API time, hydration, route transition) → Navigation Timing API → Long Task observer. At SAP, p75 LCP tracked weekly in Grafana dashboards per BTP product region.

Synthetic monitoring
Scheduled Lighthouse CI runs. Catches regressions before deploy. Consistent lab conditions. Tools: WebpageTest, SpeedCurve, Calibre
Real User Monitoring (RUM)
JS snippet samples real users per percentile. Captures slow device/network edge cases. Tools: Datadog RUM, New Relic
Custom spans
performance.mark() / measure() around your own operations: API calls, chart render, data processing

web-vitals library + custom span instrumentation

// ─── Core Web Vitals collection ───
import { onLCP, onINP, onCLS, onFCP, onTTFB } from 'web-vitals';

function sendVital({ name, value, id }: Metric) {
  navigator.sendBeacon('/api/vitals', JSON.stringify({
    metric: name, value: Math.round(value), id,
    url: location.pathname, timestamp: Date.now()
  }));
}
[onLCP, onINP, onCLS, onFCP, onTTFB].forEach(fn => fn(sendVital));

// ─── Custom span: measure API latency ───
async function fetchOrders() {
  performance.mark('orders-fetch-start');
  const data = await api.get('/orders');
  performance.mark('orders-fetch-end');
  const measure = performance.measure(
    'orders-fetch', 'orders-fetch-start', 'orders-fetch-end'
  );
  logger.info('API span', { name: 'orders-fetch', duration: measure.duration });
  return data;
}

// ─── Long Tasks observer ───
new PerformanceObserver(list => {
  list.getEntries().forEach(entry => {
    if (entry.duration > 50) // >50ms = long task
      logger.warn('Long task', { duration: entry.duration });
  });
}).observe({ entryTypes: ['longtask'] });
