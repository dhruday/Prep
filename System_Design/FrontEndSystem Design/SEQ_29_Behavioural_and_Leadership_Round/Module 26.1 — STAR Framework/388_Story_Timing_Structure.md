# 388 – Story Timing and Structure — The 2-Minute Rule

────────────────────────────────────────────────────────────

## 1. ⚡ HIGH-LEVEL EXPLANATION
Each behavioral answer should be **90-120 seconds** (~200-250 words spoken). Practice with a timer. Structure: punch-line first (state the outcome), then STAR details. The interviewer should know your answer direction within 15 seconds.

## 2. 🔬 DEEP-DIVE EXPLANATION

### Timing Breakdown
```
0:00 - 0:15  → HEADLINE (punch-line first)
               "I improved Lighthouse from 60 to 95 at SAP by..."
               
0:15 - 0:30  → SITUATION + TASK
               "At SAP, our Fiori dashboard was... I was responsible for..."
               
0:30 - 1:15  → ACTION (the bulk)
               "First I... Then I... The key decision was..."
               
1:15 - 1:45  → RESULT + LEARNING
               "This resulted in... I learned that..."
               
1:45 - 2:00  → PAUSE — let interviewer ask follow-up
```

### Headline-First Technique
```
❌ "So at my previous company, there was this project where the team
    was working on a dashboard and we had some performance issues..."
    (30 seconds in, interviewer still doesn't know where this is going)

✅ "I reduced page load time by 70% at SAP by implementing lazy loading
    and OnPush change detection."
    (In 5 seconds, interviewer knows the outcome and is engaged)
```

### Calibration Exercise
```
TOO SHORT (30s): "I fixed a performance issue. Used lazy loading. Score 
                  went up." → No depth, no credibility

TOO LONG (4min): Every technical detail, tangents about team dynamics,
                  repeating points → Interviewer loses interest, runs out
                  of time for other questions

JUST RIGHT (90-120s): Headline → Context → 3-4 key actions → Quantified 
                       result → One learning
```

### Practice Method
```
1. Write out each story (200-250 words)
2. Record yourself telling it
3. Time it (target 90-120s)
4. Cut filler: "basically", "you know", "so basically"
5. Rehearse 5+ times until natural (not memorized)
6. Practice with a friend giving follow-ups
```

### Follow-Up Preparation
```
For each story, prepare answers to:
- "What would you do differently?"
- "How did the team react?"
- "What was the hardest part?"
- "Any pushback? How did you handle it?"
- "What did you learn about yourself?"
```

## 3. 🎯 INTERVIEW-ORIENTED ANSWER
*"I use the headline-first approach — state the outcome in 10 seconds, then fill in STAR details in 90-120 seconds total. This keeps the interviewer engaged and shows I can communicate concisely. I prepare 2-3 follow-up angles per story."*

## 4. 🧠 MEMORY AID
**"90-120 seconds. Headline first (5s). S+T (15s). Actions (45s). Result+Learning (25s). Pause for follow-up. Practice with timer."**
