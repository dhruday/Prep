document.cookie · HttpOnly Invisibility

5. JS Cookie Spy

Key insight: document.cookie will NOT show sid because it is HttpOnly.
This is the entire defence against XSS token theft.
    Open the browser console and type: document.cookie
    You will NOT see sid — but open DevTools → Application → Cookies and you WILL see it listed there (browser shows it for debugging).

    Challenges — try these in DevTools

    1. Login, then open DevTools Console → type document.cookie — which cookies are missing? Why?
    2. After login, manually change the sid cookie value in DevTools → Application → Cookies. Then click "Get Current User". What error do you get?
