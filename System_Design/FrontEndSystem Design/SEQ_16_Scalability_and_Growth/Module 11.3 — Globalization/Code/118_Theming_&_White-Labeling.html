Theming: CSS custom properties make runtime theme switching zero-cost — no JS, no class swap

White-labeling means one codebase produces N customer-branded products. The design system defines semantic CSS variables (--color-primary, --color-surface) and components only reference these variables. Customers inject their own values at runtime or at build time. SAP Fiori's theming is built on this exact model — Fiori is delivered with SAP Morning Horizon, SAP Evening Horizon, SAP High Contrast themes, all via CSS variables.

CSS custom properties theming system + runtime injection

// ─── Design tokens JSON ───
const sapTheme = {
  "color-primary": "#008fd3",
  "color-surface": "#fff",
  "color-text": "#32363a",
  "border-radius": "0.375rem"
};

// ─── Inject theme at runtime ───
function applyTheme(tokens: Record<string, string>) {
  const root = document.documentElement;
  Object.entries(tokens).forEach(([key, value]) =>
    root.style.setProperty(`--${key}`, value)
  );
}

// ─── Component uses semantic variables ───
/* CSS — never hardcode colors */
.button-primary {
  background: var(--color-primary);
  color: var(--color-on-primary, white);
  border-radius: var(--border-radius);
}
