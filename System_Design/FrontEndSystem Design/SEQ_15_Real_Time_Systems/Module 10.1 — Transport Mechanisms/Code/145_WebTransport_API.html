WebTransport — HTTP/3's multiplexed streams for the browser

WebTransport is a browser API built on HTTP/3 (QUIC protocol). It gives you bidirectional streams and datagrams from a web page — capabilities that previously required WebSocket or WebRTC. The key advantage: QUIC eliminates head-of-line blocking (a WebSocket problem) and allows multiplexed streams that fail independently.

Unidirectional/Bidirectional Streams
Reliable, ordered — like WebSocket but multiplexed. Stream A failure doesn't block Stream B. Perfect for: separate chat + notifications + telemetry channels in one QUIC connection.
Datagrams
Unreliable, unordered — like UDP. Lower latency, no HOL blocking. Perfect for: game position updates, live sensor data, video frames where stale data should be discarded.
WebSocket vs WebTransport head-of-line blocking
WebSocket = single TCP stream. One large message blocks all subsequent messages (HOL blocking). WebTransport over QUIC = multiple independent streams. Drop one packet from stream A, stream B is unaffected. Critical for real-time applications under packet loss (mobile networks).

WebTransport client (Chrome 97+)

class GameTransport {
  private transport: WebTransport | null = null;
  private writerStream: WritableStreamDefaultWriter | null = null;
  
  async connect(url: string) {
    this.transport = new WebTransport(url);
    await this.transport.ready;
    console.log('WebTransport connected via HTTP/3');
  }
  
  // Datagrams — fast, unreliable (game player positions)
  async sendPosition(x: number, y: number) {
    const writer = this.transport!.datagrams.writable.getWriter();
    const data = new Float32Array([x, y]);
    await writer.write(data);
    writer.releaseLock();  // datagrams are fire-and-forget
  }
  
  // Bidirectional stream — reliable ordered (chat messages)
  async openChatStream() {
    const stream = await this.transport!.createBidirectionalStream();
    const encoder = new TextEncoderStream();
    encoder.readable.pipeTo(stream.writable);
    
    // Read incoming messages on this stream
    const decoder = new TextDecoderStream();
    stream.readable.pipeTo(decoder.writable);
    const reader = decoder.readable.getReader();
    
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      handleChatMessage(value);
    }
  }
  
  async close() { await this.transport?.close(); }
}
