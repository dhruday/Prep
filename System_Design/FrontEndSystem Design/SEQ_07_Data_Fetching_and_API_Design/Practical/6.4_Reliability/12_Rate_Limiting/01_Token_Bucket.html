Token Bucket Algorithm

A bucket holds up to maxTokens. Each request costs 1 token. Tokens refill at a constant rate. If the bucket is empty, the request is rejected (rate-limited).

1. Bucket starts full (capacity = 10).
2. Each request removes 1 token.
3. Every second, 1 token is added (up to max).
4. Allows short bursts up to bucket capacity.
5. Sustained rate is bounded by refill rate.

Implementation

class TokenBucket {
  constructor(capacity, refillRate) {
    this.capacity = capacity;
    this.tokens = capacity;
    this.refillRate = refillRate; // tokens per second
    this.lastRefill = Date.now();
  }
  refill() {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(this.capacity,
      this.tokens + elapsed * this.refillRate);
    this.lastRefill = now;
  }
  tryConsume() {
    this.refill();
    if (this.tokens >= 1) {
      this.tokens -= 1;
      return true;
    }
    return false;
  }
}

Key Takeaways

Token bucket allows controlled bursts while enforcing a long-term average rate.
  • Smooth traffic shaping — no hard per-second walls
  • Burst-friendly — bucket capacity = max burst size
  • Refill rate = sustained throughput ceiling
  • Used in AWS API Gateway, Stripe, nginx
  • Compare with leaky bucket (fixed drain) and sliding window
