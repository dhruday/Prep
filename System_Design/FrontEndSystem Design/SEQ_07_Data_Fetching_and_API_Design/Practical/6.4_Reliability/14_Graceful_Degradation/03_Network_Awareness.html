Network-Aware Data Strategy

The Network Information API lets you adapt behavior to connection quality:

4G / WiFi Full data — images, animations, prefetch, real-time updates
3G Reduced — compressed images, no prefetch, longer poll intervals
2G / Slow Text only — no images, critical data only, aggressive caching
Save Data User opted in to reduced data — respect unconditionally
navigator.connection is available in Chromium browsers. Always feature-detect and default to full experience.

Network-Aware Fetch Strategy

function getNetworkStrategy() {
  const conn = navigator.connection || {};
  const type = conn.effectiveType || '4g';
  const saveData = conn.saveData || false;

  if (saveData || type === 'slow-2g' || type === '2g') {
    return { images: false, prefetch: false,
             pollInterval: 60000, quality: 'text' };
  }
  if (type === '3g') {
    return { images: 'compressed', prefetch: false,
             pollInterval: 30000, quality: 'reduced' };
  }
  return { images: true, prefetch: true,
           pollInterval: 5000, quality: 'full' };
}

// Listen for network changes
navigator.connection?.addEventListener('change', () => {
  const strategy = getNetworkStrategy();
  applyStrategy(strategy);
});

Key Points

• Always feature-detect: navigator.connection is undefined in Safari/Firefox

• saveData is a user preference — always respect it, even on 4G

• Listen to the change event to adapt in real-time (e.g., entering a tunnel)

• Send Save-Data: on header so the server can also reduce payload

• Default to full experience when API is unavailable

Interview tip: "We check effectiveType to serve text-only on 2G and compress images on 3G, reducing data usage by 80%."
