Items (click delete → 5s undo window)

Delete fades the item and shows an undo toast with a 5-second countdown. If not undone, DELETE is sent to the server.

Soft Delete + Undo Pattern

1. Click delete → item fades (soft delete), undo toast appears with 5s countdown
2. If countdown expires → execute real DELETE /api/posts/todos/:id
3. If user clicks Undo → restore item, cancel the pending delete

Benefits

Users get instant feedback (the item disappears) but have a safety net. The actual destructive operation is deferred, reducing accidental data loss.

Core Logic

function deleteItem(id) {
  const item = items.find(i => i.id === id);
  item.deleting = true;
  render(); // fades the item

  let seconds = 5;
  const toast = showToast(item, seconds);

  const interval = setInterval(() => {
    seconds--;
    updateCountdown(toast, seconds);
    if (seconds <= 0) {
      clearInterval(interval);
      confirmDelete(id); // real DELETE call
    }
  }, 1000);

  // Store cancel function for undo
  pendingDeletes.set(id, () => {
    clearInterval(interval);
    item.deleting = false;
    removeToast(toast);
    render();
  });
}
