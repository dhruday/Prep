📖 AbortSignal.timeout() — Built-in Timeout

// Modern API — one line timeout!
const res = await fetch(`${API}/api/unreliable/timeout`, {
  signal: AbortSignal.timeout(3000) // 3 second deadline
});

// The error type is different from manual abort:
try {
  const data = await res.json();
} catch (e) {
  if (e.name === 'TimeoutError') {
    console.log('Request timed out');
  } else if (e.name === 'AbortError') {
    console.log('Request was manually aborted');
  }
}
AbortSignal.timeout() throws a TimeoutError (not AbortError). This lets you distinguish timeouts from manual cancellations.

🔄 Manual Timeout (Pre AbortSignal.timeout)

// Before AbortSignal.timeout() existed:
async function fetchWithManualTimeout(url, ms) {
  const controller = new AbortController();
  const timer = setTimeout(() => {
    controller.abort();
  }, ms);

  try {
    const res = await fetch(url, { signal: controller.signal });
    clearTimeout(timer); // Don't forget!
    return await res.json();
  } catch (e) {
    clearTimeout(timer);
    throw e;
  }
}

✅ Modern Equivalent

// One line — no manual timer management
const res = await fetch(url, {
  signal: AbortSignal.timeout(ms)
});
AbortSignal.timeout() handles timer cleanup automatically. Less code, fewer bugs.
