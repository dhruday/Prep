Why modern formats matter — bytes saved = seconds saved

Images are typically 50–80% of a page's total bytes. JPEG was designed in 1992; PNG in 1996. Modern ML-driven codecs like AVIF (AV1-based) and JPEG XL achieve 30–50% smaller files at equal quality using better entropy coding, larger transform blocks, and perceptual models. Smaller images = faster LCP, lower bandwidth costs, better Core Web Vitals scores.

AVIF
AV1 video codec stills. Best compression. HDR + wide color gamut. Progressive decode (signal). Browser: Chrome 100, Safari 16, Firefox 93. ✅ Use for hero images, product photos.
WebP
Google codec, 25-35% smaller than JPEG. Lossy + lossless. Full browser support (Chrome, Safari 14+, Firefox 65+, Edge). Best compatibility choice today. ✅ Safe fallback after AVIF.
JPEG XL
Best for lossless re-encoding of existing JPEGs (numerically lossless transcoding). Superior quality but limited browser support (Chrome via flag only). Future-oriented.
Decision Tree
Need max compression → AVIF
Need max compatibility → WebP
Re-encode JPEG losslessly → JPEG XL
Fallback → JPEG/PNG via <picture>

Progressive enhancement with <picture> + srcset

<!-- Browser picks first format it supports -->
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Hero image"
       width="1200" height="800"
       fetchpriority="high"
       decoding="async">
</picture>

<!-- Responsive with srcset — right size for right viewport -->
<picture>
  <source
    type="image/avif"
    srcset="img-400.avif 400w, img-800.avif 800w, img-1200.avif 1200w"
    sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 400px">
  <source
    type="image/webp"
    srcset="img-400.webp 400w, img-800.webp 800w, img-1200.webp 1200w"
    sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 400px">
  <img src="img-800.jpg" alt="Product" loading="lazy">
</picture>

// Build pipeline: Sharp (Node) converts all formats
import sharp from 'sharp';
const convert = async (input: string, base: string) => {
  const img = sharp(input).resize(1200);
  await img.clone().avif({ quality: 60 }).toFile(`${base}.avif`);
  await img.clone().webp({ quality: 75 }).toFile(`${base}.webp`);
  await img.jpeg({ quality: 85 }).toFile(`${base}.jpg`);
};
