OAuth 2.0 = authorization framework; OIDC = identity layer on top of OAuth 2.0

OAuth 2.0 answers "can App X access Resource Y on behalf of User?" — it issues access tokens for authorization. OIDC (OpenID Connect) adds "who is the user?" — it adds an ID token (JWT) containing identity claims. Use OAuth 2.0 alone for API authorization; use OIDC when you need to know who the user is (login). SAP Identity Authentication Service (IAS) is an OIDC-compliant IdP used across all SAP BTP applications.

Access Token
Short-lived (15min). Sent with every API request. Opaque or JWT. Does NOT contain login info.
ID Token (OIDC)
JWT with user claims (sub, name, email, roles). Read by client. Verify signature before trusting.
Refresh Token
Long-lived (30d). Exchanged for new access token. Store in HttpOnly cookie.

JWT anatomy — decode an ID token

A JWT has 3 parts: Header.Payload.Signature — base64url encoded, NOT encrypted
Header
{ "alg": "RS256", "typ": "JWT" }
Payload (claims)
{
  "sub": "user-123",
  "email": "hruday@sap.com",
  "name": "Hruday Kasyap",
  "roles": ["admin"],
  "iss": "https://idp.sap.com",
  "aud": "my-app-client",
  "exp": 1736000000,
  "iat": 1735996400
}
Critical validation steps
✅ Verify iss matches your expected issuer
✅ Verify aud matches your client ID
✅ Check exp — reject if expired
✅ Verify RS256 signature via JWKS endpoint
❌ Don't trust claims without verifying signature

OIDC with auth-js library + JWT validation

// ─── Using @auth0/auth0-spa-js (or @azure/msal-browser) ───
import { createAuth0Client } from '@auth0/auth0-spa-js';

const auth = await createAuth0Client({
  domain: 'sap-tenant.eu.auth0.com',
  clientId: 'MY_CLIENT_ID',
  authorizationParams: {
    redirect_uri: window.location.origin,
    scope: 'openid profile email'
  }
});

// Triggers PKCE flow, handles callback
if (location.search.includes('code=')) {
  await auth.handleRedirectCallback();
  history.replaceState({}, '', '/');
}

// Get user claims from ID token
const user = await auth.getUser(); // { sub, email, name }
// Get access token silently (from cache or silent refresh)
const token = await auth.getTokenSilently();

// ─── Manual JWKS validation (Node.js backend) ───
import * as jose from 'jose';
const JWKS = jose.createRemoteJWKSet(new URL('https://idp.sap.com/.well-known/jwks.json'));
const { payload } = await jose.jwtVerify(token, JWKS, {
  issuer: 'https://idp.sap.com', audience: 'my-api'
});
