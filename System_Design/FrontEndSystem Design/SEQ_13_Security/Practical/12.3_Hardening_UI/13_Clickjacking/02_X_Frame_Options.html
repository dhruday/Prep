X-Frame-Options Header

// X-Frame-Options controls whether a page can be framed

// Values:
X-Frame-Options: DENY
// Page cannot be displayed in any frame, iframe, embed, object
// Even same-origin framing is blocked

X-Frame-Options: SAMEORIGIN
// Page can only be framed by pages on the same origin
// Most common choice for web apps

X-Frame-Options: ALLOW-FROM https://trusted.com
// ⚠️ DEPRECATED — Only worked in Firefox & IE
// Chrome/Safari never supported it
// Use CSP frame-ancestors instead

// Express.js implementation:
const helmet = require('helmet');
app.use(helmet.frameguard({ action: 'deny' }));

// Or manually:
app.use((req, res, next) => {
  res.setHeader('X-Frame-Options', 'SAMEORIGIN');
  next();
});

X-Frame-Options Limitations

// ❌ Problems with X-Frame-Options:

// 1. Only allows ONE value
//    Can't allow multiple trusted domains

// 2. ALLOW-FROM is deprecated
//    Chrome/Safari never implemented it

// 3. No wildcard support
//    Can't do *.trusted.com

// 4. Double headers = undefined behavior
//    If proxy adds DENY and app adds SAMEORIGIN:
//    Chrome uses first, Firefox uses most restrictive

// ✅ Modern replacement: CSP frame-ancestors
Content-Security-Policy: frame-ancestors 'self' https://a.com https://b.com

// Supports:
// - Multiple origins
// - Wildcards: *.trusted.com
// - 'none' (= DENY), 'self' (= SAMEORIGIN)
// - Consistent behavior across browsers

// Best practice: Set BOTH for compatibility
// Old browsers → X-Frame-Options
// Modern browsers → CSP frame-ancestors (takes precedence)

Google Senior Frontend — Frame Protection

Q: When should you allow your app to be framed?

Legitimate framing use cases: (1) Embeddable widgets (payment forms, chat widgets, video players). These should use frame-ancestors with specific partner domains. (2) OAuth consent screens — Google/Facebook login popups are framed. Protected by: frame-ancestors allowing only the auth provider domain + PKCE. (3) Admin dashboards within a parent portal. Use: SAMEORIGIN or frame-ancestors 'self'. For all other pages: DENY or frame-ancestors 'none'. If you must allow framing: (a) frame-ancestors with explicit origins (never *). (b) Use postMessage for communication — validate origin! (c) SameSite=Strict cookies won't be sent in iframes. (d) Consider using window.frameElement to detect framing and adjust behavior.
