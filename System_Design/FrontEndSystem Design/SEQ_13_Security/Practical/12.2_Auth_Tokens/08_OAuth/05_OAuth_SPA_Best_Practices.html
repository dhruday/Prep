Recommended: BFF Pattern

// BFF (Backend-For-Frontend) for OAuth:
// The SPA never touches OAuth tokens directly

// 1. SPA → GET /bff/login
//    BFF generates state + PKCE, redirects to IdP

// 2. User authenticates with IdP

// 3. IdP → GET /bff/callback?code=xxx&state=yyy
//    BFF exchanges code for tokens (server-to-server)
//    BFF stores tokens in session store (Redis)
//    BFF sets HttpOnly session cookie
//    BFF redirects to SPA

// 4. SPA → GET /bff/api/userinfo (cookie auto-sent)
//    BFF reads session, attaches access_token, proxies to API

// 5. Token refresh: BFF handles automatically
//    On upstream 401 → use refresh_token → update session

// SPA code is JUST:
fetch('/bff/api/userinfo', { credentials: 'include' });

BFF Implementation (Next.js/Express)

// Next.js API Route as BFF
// pages/api/auth/login.ts
export default async function handler(req, res) {
  const state = crypto.randomUUID();
  const verifier = generateCodeVerifier();
  const challenge = await generateCodeChallenge(verifier);

  // Store in server-side session
  req.session.oauthState = state;
  req.session.codeVerifier = verifier;

  const authUrl = new URL('https://accounts.google.com/o/oauth2/v2/auth');
  authUrl.searchParams.set('client_id', process.env.GOOGLE_CLIENT_ID);
  authUrl.searchParams.set('redirect_uri', 'https://myapp.com/api/auth/callback');
  authUrl.searchParams.set('response_type', 'code');
  authUrl.searchParams.set('scope', 'openid profile email');
  authUrl.searchParams.set('state', state);
  authUrl.searchParams.set('code_challenge', challenge);
  authUrl.searchParams.set('code_challenge_method', 'S256');

  res.redirect(authUrl.toString());
}

// pages/api/auth/callback.ts
export default async function handler(req, res) {
  if (req.query.state !== req.session.oauthState) {
    return res.status(403).json({ error: 'CSRF detected' });
  }
  const tokens = await exchangeCodeForTokens({
    code: req.query.code,
    codeVerifier: req.session.codeVerifier,
    clientSecret: process.env.GOOGLE_CLIENT_SECRET,
  });
  req.session.accessToken = tokens.access_token;
  req.session.refreshToken = tokens.refresh_token;
  res.redirect('/'); // back to SPA
}

Google Senior Frontend — OAuth for SPAs

Q: Your SPA uses Auth0 with PKCE and stores tokens in memory. The product team wants to add "remember me." How?

Option 1 (Preferred): Use Auth0's silent authentication. On page load, make a hidden iframe request to Auth0 with prompt=none. If the user has an active Auth0 session (SSO cookie), they get a new token without login. This is "remember me" without storing tokens. Option 2: Use refresh token rotation. Store the refresh token in an HttpOnly cookie. On page load, call /token with the refresh cookie. Each refresh issues a new refresh token and invalidates the old one. Option 3: Migrate to BFF pattern — the BFF handles the session with a long-lived HttpOnly cookie, refresh is transparent. Never: Store tokens in localStorage with SameSite cookies disabled.
