Responsive design systems — what differs at scale

A design system isn't just a component library — it's a set of constraints that produce consistent, accessible, and adaptive UI across screen sizes, devices, and user preferences. Adobe Spectrum, SAP Fiori, Microsoft Fluent, and Salesforce Lightning all implement systematic breakpoints, fluid spacing, and adaptive typography. Senior frontend engineers at these companies are expected to understand and extend these systems, not just consume them.

Fluid typography
Font size linearly interpolates between a min and max based on viewport width: clamp(min, preferred, max). No breakpoint jumps — smooth scaling.
Container queries
CSS @container — component responds to its own parent container size, not the viewport. Enables truly reusable components that work in sidebars AND full-width panels.
Preference media queries
prefers-reduced-motion, prefers-color-scheme, prefers-contrast, prefers-reduced-data. Critical for inclusivity — never animate unless motion is allowed.

Body text stays readable at all sizes because it uses clamp() to linearly interpolate between minimum and maximum values.

h1 { font-size: clamp(1.5rem, 2.5vw + 1rem, 3rem); }
body { font-size: clamp(1rem, 1.5vw + 0.5rem, 1.25rem); }

Fluid type scale + container query + media preference code

/* ─── Fluid type scale (Utopia-inspired) ───
   clamp(min, preferred-vw-based, max) — no breakpoints needed */
:root {
  --type-xs: clamp(0.75rem, 0.7rem + 0.25vw, 0.875rem);
  --type-sm: clamp(0.875rem, 0.8rem + 0.375vw, 1rem);
  --type-md: clamp(1rem, 0.9rem + 0.5vw, 1.25rem);
  --type-lg: clamp(1.25rem, 1rem + 1.25vw, 2rem);
  --type-xl: clamp(1.5rem, 1rem + 2.5vw, 3rem);
}

/* ─── Container queries ─── */
.card-wrapper { container-type: inline-size; container-name: card; }

@container card (min-width: 400px) {
  .card { display: grid; grid-template-columns: 80px 1fr; }
}

/* ─── Preference media queries ─── */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 0.01ms !important; }
}
@media (prefers-contrast: more) {
  :root { --text-muted: #ffffff; --border-color: #ffffff; }
}
@media (prefers-color-scheme: dark) {
  :root { --bg: #0f1117; --text: #e2e8f0; }
}

// ─── React hook for user preferences ───
function useMotionSafe() {
  const mq = matchMedia('(prefers-reduced-motion: reduce)');
  const [safe, setSafe] = useState(!mq.matches);
  useEffect(() => {
    mq.addEventListener('change', e => setSafe(!e.matches));
  }, []);
  return safe;
}
