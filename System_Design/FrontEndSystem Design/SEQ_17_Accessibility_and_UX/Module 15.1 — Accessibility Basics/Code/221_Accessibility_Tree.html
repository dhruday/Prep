What is the Accessibility Tree?

A parallel data structure to the DOM that browsers build to expose content to assistive technologies. While the DOM contains every element, the accessibility tree contains only semantically meaningful nodes.

Building Process

Step 1

DOM Parsed

Browser parses HTML into the full DOM tree with all elements.

Step 2

A11y Tree Built

Browser filters DOM into semantic-only tree. Decorative elements excluded.

Step 3

Exposed via API

UIA (Windows), NSAccessibility (macOS) expose tree to screen readers.

Node Properties

PropertySourceExample
RoleElement type / role attrbutton, combobox, heading

Key insight: If an element isn't in the accessibility tree, it doesn't exist for screen reader users. A styled div with onclick but no role = invisible.
