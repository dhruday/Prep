Key Concepts

// LCP considers these element types:
// - <img> elements
// - <image> inside <svg>
// - <video> poster image
// - Elements with background-image via url()
// - Block-level elements with text nodes
//
// LCP size = visible area (viewport-clipped)
// Margins, padding, borders DON'T count
// Elements with opacity:0 or visibility:hidden DON'T count
//
// LCP stops reporting after first user input (click/keydown/scroll)
// The LAST reported entry is the official LCP value
//
// Thresholds: ≤2.5s Good | 2.5–4s Needs Work | >4s Poor
