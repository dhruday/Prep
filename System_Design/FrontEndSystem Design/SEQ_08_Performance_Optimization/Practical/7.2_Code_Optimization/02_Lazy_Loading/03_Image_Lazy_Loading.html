Image Lazy Loading

Practical 7.2 · Native and advanced image loading strategies

1. Native Lazy Loading (Simplest)

<!-- loading="lazy" — built into all modern browsers -->
<img
  src="product.jpg"
  loading="lazy"
  width="400"
  height="300"
  alt="Product photo"
/>

<!-- IMPORTANT: Always set width/height to prevent CLS -->
<!-- Browser loads when ~1250px from viewport (Chrome) -->
<!-- Does NOT lazy-load above-the-fold images (smart!) -->

<!-- For hero/LCP images: eager loading (default) -->
<img
  src="hero.webp"
  loading="eager"
  fetchpriority="high"
  width="1200"
  height="600"
  alt="Hero banner"
/>

<!-- Native lazy for iframes too: -->
<iframe src="https://youtube.com/embed/..." loading="lazy"></iframe>

2. Responsive Images + Lazy Loading

<!-- srcset + loading="lazy" — responsive AND lazy -->
<img
  src="product-400.webp"
  srcset="
    product-400.webp 400w,
    product-800.webp 800w,
    product-1200.webp 1200w
  "
  sizes="(max-width: 600px) 400px, (max-width: 1000px) 800px, 1200px"
  loading="lazy"
  width="800"
  height="600"
  alt="Product"
/>

<!-- <picture> for format fallback + lazy loading -->
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" loading="lazy" width="800" height="600" alt="Photo">
</picture>

3. LQIP (Low Quality Image Placeholder)

// Blur-up technique: show tiny placeholder, then load full image

// Next.js Image component does this automatically:
import Image from 'next/image';

<Image
  src="/hero.jpg"
  width={1200}
  height={600}
  placeholder="blur"
  blurDataURL="data:image/jpeg;base64,/9j/4AAQ..." // tiny 10px version
  priority={true} // For LCP image: disables lazy loading
/>

// Manual CSS blur-up:
.image-container {
  position: relative;
  overflow: hidden;
}
.image-container .placeholder {
  filter: blur(20px);
  transform: scale(1.1); /* Hide blur edges */
  transition: opacity 0.3s;
}
.image-container .full-image {
  position: absolute;
  inset: 0;
  opacity: 0;
  transition: opacity 0.5s;
}
.image-container .full-image.loaded {
  opacity: 1;
}

Decision Tree

Is it the LCP/hero image?
├── Yes → loading="eager" + fetchpriority="high" + preload
└── No → Is it above the fold?
    ├── Yes → loading="eager" (default)
    └── No → loading="lazy" + width/height for CLS

Format priority: AVIF > WebP > JPEG
Always provide width + height (or aspect-ratio)
Always use srcset for responsive images
