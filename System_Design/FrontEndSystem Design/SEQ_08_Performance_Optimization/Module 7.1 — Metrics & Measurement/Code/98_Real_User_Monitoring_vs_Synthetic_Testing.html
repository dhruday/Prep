Two complementary lenses on performance

Synthetic tests run on controlled machines — perfect for CI regression gates. RUM captures what real users experience on their devices and networks. Both are required. One without the other creates dangerous blind spots.

🔬 Synthetic (Lab)
✅ Deterministic, reproducible
✅ Pre-ship regression gate in CI
✅ No real users needed
⚠️ Simulated throttling, not real device
⚠️ Misses regional CDN issues
⚠️ Zero SEO signal (not CrUX)
Tools: Lighthouse CI, WebPageTest
👥 RUM (Field)
✅ Real devices, real networks
✅ Catches regional CDN failures
✅ Google CrUX = SEO ranking signal
⚠️ Needs traffic volume for reliability
⚠️ Post-ship only
⚠️ Noisy — use percentiles not averages
Tools: web-vitals.js, AppInsights, Datadog

What RUM reveals that synthetic never will

Regional CDN failure
São Paulo edge node down → users there see 8s LCP. Synthetic (fixed location) scores 1.2s.
iOS Safari quirk
Synthetic runs Chrome/Linux. iOS Safari users hit CLS bug invisible in CI.
Third-party timeout
Analytics/chat widget 3s timeout hurts p95 TTFB. Excluded from synthetic but present for all real users.
Memory-constrained device
Android with 2GB RAM + 15 tabs: INP 800ms. Clean synthetic machine: 120ms.

Production RUM implementation

// src/monitoring/rum.ts — production-grade with sampling + build version
import { onCLS, onINP, onLCP, onTTFB, type Metric } from 'web-vitals';

const SAMPLE_RATE = 0.1;  // 10% of sessions
const isSampled = Math.random() < SAMPLE_RATE;
const sessionId = crypto.randomUUID();
const buildVersion = window.__BUILD_VERSION__ ?? 'unknown';

function sendMetric(metric: Metric): void {
  if (!isSampled) return;  // Sampling gate

  const payload = {
    name: metric.name, value: Math.round(metric.value),
    rating: metric.rating,  // 'good' | 'needs-improvement' | 'poor'
    url: location.pathname,
    sessionId, buildVersion,  // Enables deploy correlation
    connection: navigator.connection?.effectiveType,
    deviceMemory: navigator.deviceMemory,
    timestamp: Date.now(),
  };

  // sendBeacon: non-blocking, survives page unload, off main thread
  try { navigator.sendBeacon?.('/api/rum', JSON.stringify(payload)); }
  catch {}  // Never crash the page for analytics
}

export function initRUM(): void {
  if (typeof window === 'undefined') return;  // SSR guard
  onCLS(sendMetric); onINP(sendMetric);
  onLCP(sendMetric); onTTFB(sendMetric);
}

// Always use percentiles, never averages:
function p75(arr: number[]): number {
  const sorted = [...arr].sort((a, b) => a - b);
  return sorted[Math.ceil(0.75 * sorted.length) - 1];
}

SAP Context

After the Lighthouse 60→95 improvement, synthetic said "done". RUM would have revealed users in India on 4G saw p75 LCP of 4200ms — the CDN wasn't caching API responses for the Indian edge node. Synthetic, running from a local server, never caught it. This is why both are required.
