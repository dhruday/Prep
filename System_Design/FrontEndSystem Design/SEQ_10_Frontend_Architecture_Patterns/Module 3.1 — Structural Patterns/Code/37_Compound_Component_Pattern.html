What is Compound Component?

A compound component is a set of components that work together via shared implicit (Context) state. The parent owns state; children access it without prop drilling. Think of HTML's <select> + <option> — they share state without the consumer having to wire them up.

❌ Prop Drilling Hell
<Select
  options={options}
  selected={val}
  onSelect={setVal}
  renderOption={...}
  renderTrigger={...}
  isOpen={open}
  onOpen={setOpen}
/>
✅ Compound Pattern
<Select defaultValue="red">
  <Select.Trigger />
  <Select.Options>
    <Select.Option value="red">Red</Select.Option>
    <Select.Option value="blue">Blue</Select.Option>
  </Select.Options>
</Select>
Key benefit: Consumer controls the composition (can reorder, replace parts) while the component handles shared state internally via React Context.

Overview: Compound components used in SAP Fiori to build the ObjectPage tab navigation. Each tab controls its own content section independently.
Performance: Using Context for shared state means zero prop drilling. Re-renders are limited to Tab.Panel components that consume the context.
Security: Tab content is lazily rendered — non-active tabs are not mounted, reducing attack surface of hidden but rendered content.

React + TypeScript implementation

const SelectContext = React.createContext<{
  value: string | null;
  open: boolean;
  select: (val: string) => void;
  toggle: () => void;
} | null>(null);

const useSelectContext = () => {
  const ctx = React.useContext(SelectContext);
  if (!ctx) throw new Error('Must be inside <Select>');
  return ctx;
};

// Root — owns state
const Select = ({ children, defaultValue = null }: SelectProps) => {
  const [value, setValue] = useState<string | null>(defaultValue);
  const [open, setOpen] = useState(false);
  return (
    <SelectContext.Provider value={{ value, open, select: setValue, toggle: () => setOpen(o => !o) }}>
      {children}
    </SelectContext.Provider>
  );
};

// Sub-components read from Context
const Trigger = () => {
  const { value, toggle } = useSelectContext();
  return <button onClick={toggle}>{value ?? 'Select...'} ▼</button>;
};

Select.Trigger = Trigger;
Select.Options = ({ children }: { children: React.ReactNode }) => {
  const { open } = useSelectContext();
  return open ? <div className="options">{children}</div> : null;
};
Select.Option = ({ value, children }: OptionProps) => {
  const { select, value: selected } = useSelectContext();
  return <div onClick={() => select(value)} className={selected === value ? 'active' : ''}>{children}</div>;
};
