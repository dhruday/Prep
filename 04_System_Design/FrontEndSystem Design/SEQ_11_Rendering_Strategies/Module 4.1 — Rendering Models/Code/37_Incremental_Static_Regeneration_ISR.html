ISR — Best of SSG + SSR

ISR combines SSG's performance (CDN-cached HTML) with SSR's freshness. Pages are pre-built, then re-generated in the background after a revalidate TTL. Users always get a fast cached response.

SSG
Built once at deploy. Never updates without full rebuild. Fastest. No freshness.
ISR ✅
Pre-built at deploy + background regeneration after TTL. Fast + fresh.
SSR
New HTML every request. Always fresh. Higher TTFB. Server cost per request.

// app/products/[id]/page.tsx

// Revalidate every 60 seconds (page will seem SSG until TTL expires)
export const revalidate = 60;

export async function generateStaticParams() {
  const products = await getTopProducts(); // pre-build top 100
  return products.map(p => ({ id: p.id }));
}

export default async function ProductPage({ params }) {
  // This fetch is cached + revalidated per revalidate TTL
  const product = await fetch(`/api/products/${params.id}`, {
    next: { revalidate: 60 }, // per-fetch revalidate override
  }).then(r => r.json());

  return <ProductDetail product={product} />;
}
