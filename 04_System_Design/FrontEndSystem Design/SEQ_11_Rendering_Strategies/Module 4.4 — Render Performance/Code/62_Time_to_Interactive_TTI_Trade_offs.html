TTI — Time to Interactive

TTI measures when the page is fully interactive — the main thread is idle (no long tasks), all visible elements have event handlers, and the page responds to user input within 50ms. It's distinct from FCP (first paint) and FID (first interaction).

FCP (First Contentful Paint) → user sees something, but may still be "uncanny valley"
FMP (First Meaningful Paint) → primary content visible
TTI → all event listeners attached, no long tasks, fully interactive
TBT (Total Blocking Time) → sum of all long tasks between FCP and TTI
Lighthouse TTI thresholds: <3.8s = fast 🟢, 3.8-7.3s = needs improvement 🟡, >7.3s = slow 🔴

Code splitting patterns (React)

// Route-level code splitting with React.lazy
import { lazy, Suspense } from 'react';

const OrderPage = lazy(() => import('./pages/Orders'));
const AnalyticsPage = lazy(() => import('./pages/Analytics'));

function App() {
  return (
    <Router>
      <Suspense fallback={<PageSkeleton />}>
        <Route path="/orders" element={<OrderPage />} />
        <Route path="/analytics" element={<AnalyticsPage />} />
      </Suspense>
    </Router>
  );
}

// Prefetch next route on user intent (hover)
function NavLink({ to, children }) {
  const prefetch = () => {
    // Trigger dynamic import to warm up chunk
    import(`./pages/${to}`);
  };
  return <Link to={to} onMouseEnter={prefetch}>{children}</Link>;
}
