Critical CSS — Concept

Critical CSS is the minimum CSS required to render the above-the-fold content without any external stylesheet download. It is inlined directly into the <head> as a <style> block. Non-critical CSS loads asynchronously.

✔ Eliminates the render-blocking stylesheet download for above-fold paint
✔ FCP improves by 400-800ms on typical 3G connections
✔ LCP improves — hero images + fonts styled immediately
⚠ Tradeoff — slightly larger initial HTML, not cached separately
⚠ Requires tooling to extract critical rules automatically per route
SAP context: Hruday used critters (Google) via Next.js to inline critical CSS for the SAP procurement portal's product listing page, reducing FCP from 2.1s → 1.3s.

Critical CSS pattern + deferred full stylesheet

<!-- 1. Inline critical CSS — no download wait -->
<style>
  /* Above-fold rules only (~2-8KB) */
  *,*::before,*::after { box-sizing: border-box }
  body { margin: 0; font-family: system-ui }
  .hero { min-height: 100vh; display: grid }
  .hero__title { font-size: clamp(2rem,5vw,4rem) }
  .nav { height: 64px; display: flex; align-items: center }
</style>

<!-- 2. Full stylesheet loads async — doesn't block paint -->
<link
  rel="preload"
  href="/styles/main.css"
  as="style"
  onload="this.onload=null;this.rel='stylesheet'"
>
<!-- Fallback for no-JS -->
<noscript>
  <link rel="stylesheet" href="/styles/main.css">
</noscript>
