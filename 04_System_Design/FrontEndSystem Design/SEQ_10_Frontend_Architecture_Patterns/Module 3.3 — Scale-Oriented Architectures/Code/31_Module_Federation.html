Shared Dependencies — Singleton vs Versioned

Without sharing, React is bundled 3 times (shell + 2 remotes). With singleton: true, the highest compatible version is used once. But mismatched versions cause silent failures.

❌ Without proper sharing
shell: React 18.2.0 (264KB)
orders: React 18.1.0 (264KB — different ver!)
analytics: React 18.2.0 (264KB duplicate)

Total: 792KB of React alone
Multiple React instances = hooks break across MFE boundaries
✅ With singleton sharing
shared: { react: { singleton: true, requiredVersion: '^18.0.0' } }

Shell negotiates: highest compatible = 18.2.0
Orders and Analytics use shell's React

Total: 264KB React — one instance
Hooks work across MFE boundaries ✅
// Shared config in all webpack.config.js files
shared: {
  react: { singleton: true, requiredVersion: '^18.0.0' },
  'react-dom': { singleton: true, requiredVersion: '^18.0.0' },
  // SAP: also share design-system tokens
  '@sap/fundamental-styles': { singleton: true },
},

Complete Webpack 5 Module Federation Config

// ============ REMOTE (orders app webpack.config.js) ============
const { ModuleFederationPlugin } = require('webpack/lib/container');
module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'orders',           // unique identifier
      filename: 'remoteEntry.js', // entry manifest
      exposes: {
        './OrderList':   './src/components/OrderList',
        './OrderDetail': './src/components/OrderDetail',
        './useOrders':   './src/hooks/useOrders',
      },
      shared: {
        react: { singleton: true, requiredVersion: '^18.0.0' },
        'react-dom': { singleton: true, requiredVersion: '^18.0.0' },
      },
    }),
  ],
};

// ============ HOST (shell webpack.config.js) ============
new ModuleFederationPlugin({
  name: 'shell',
  remotes: {
    orders: `orders@${process.env.ORDERS_URL}/remoteEntry.js`,
    analytics: `analytics@${process.env.ANALYTICS_URL}/remoteEntry.js`,
  },
  shared: { react: { singleton: true }, 'react-dom': { singleton: true } },
});

// ============ Shell usage ============
const OrderList = lazy(() => import('orders/OrderList'));
// Runtime: browsers fetches orders.sap.com/remoteEntry.js → loads chunk → mounts
