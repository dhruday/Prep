Plugin Architecture — Concept

Plugin architecture lets a core application be extended without modifying its source. Plugins register themselves and the core calls their hooks at predetermined extension points. Think: VS Code, Webpack, Vite.

Core App: Defines extension points (hooks). Loads plugins. Orchestrates lifecycle.
Plugin: Registers at a hook. Receives context. Extends behaviour without touching core.
Extension Point: A named slot where plugins can inject behaviour (e.g. beforeRender, afterSave, toolbar:add).
Real-world examples in frontend:
🔧 Webpack/Vite plugins: transform, resolve, generate hooks
📝 Prosemirror/Tiptap: RTE extensions add commands, mark types, node types
🏢 SAP Fiori Launchpad: App tiles registered as plugins by each team
🔨 VS Code: Every extension is a plugin to the extension host

Hook system — waterfall execution

// Core plugin system
type Hook<T> = (context: T) => T | void | Promise<T | void>;

class PluginSystem {
  private hooks = new Map<string, Hook<any>[]>();

  register<T>(hookName: string, fn: Hook<T>): void {
    if (!this.hooks.has(hookName)) this.hooks.set(hookName, []);
    this.hooks.get(hookName)!.push(fn);
  }

  async waterfall<T>(hookName: string, initial: T): Promise<T> {
    const fns = this.hooks.get(hookName) ?? [];
    let result = initial;
    for (const fn of fns) {
      result = (await fn(result)) ?? result;
    }
    return result;
  }
}

// Usage — plugin registers at 'transform:data' hook
registry.register('transform:data', (data) => ({
  ...data,
  timestamp: Date.now(),
}));

// Core calls all registered transforms in order
const processed = await registry.waterfall('transform:data', rawData);

Full plugin interface (TypeScript)

interface AppPlugin {
  name: string;
  version: string;
  description: string;
  install: (app: PluginContext) => void;
  uninstall?: (app: PluginContext) => void;
}

interface PluginContext {
  router: RouterAPI;
  store: StoreAPI;
  ui: UIAPI;
  registerHook: <T>(name: string, fn: Hook<T>) => void;
}

// Example plugin — adds an analytics toolbar item
const analyticsPlugin: AppPlugin = {
  name: 'analytics-toolbar',
  version: '1.0.0',
  description: 'Adds analytics shortcuts to the toolbar',
  install(app) {
    app.ui.addToolbarItem({
      id: 'analytics',
      icon: '📊',
      label: 'Analytics',
      onClick: () => app.router.push('/analytics'),
    });
    app.registerHook('beforePageLoad', async (ctx) => {
      await analytics.track('page_view', { path: ctx.path });
    });
  },
};
