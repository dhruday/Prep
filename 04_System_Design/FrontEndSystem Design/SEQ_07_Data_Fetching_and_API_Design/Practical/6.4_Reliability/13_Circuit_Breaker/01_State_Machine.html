Circuit Breaker States

CLOSED — Requests pass through. Failures are counted. When failure threshold (3) is reached, circuit opens.
OPEN — All requests are fast-failed immediately (no network call). A cooldown timer starts (5s).
HALF-OPEN — One probe request is allowed. If it succeeds → CLOSED. If it fails → OPEN again.

Why 70% Fail Rate?

The /api/unreliable/flaky?failRate=0.7 endpoint fails 70% of the time, making it easy to observe the breaker trip after a few calls.

CircuitBreaker Class

class CircuitBreaker {
  constructor(threshold = 3, cooldown = 5000) {
    this.state = 'CLOSED';
    this.failures = 0;
    this.threshold = threshold;
    this.cooldown = cooldown;
    this.nextAttempt = 0;
  }
  async call(fn) {
    if (this.state === 'OPEN') {
      if (Date.now() < this.nextAttempt)
        throw new Error('Circuit OPEN — fast fail');
      this.state = 'HALF_OPEN'; // cooldown elapsed
    }
    try {
      const res = await fn();
      this.onSuccess();
      return res;
    } catch(e) { this.onFailure(); throw e; }
  }
}

Key Takeaways

✅ Circuit breakers prevent cascading failures by fast-failing when a service is down.
✅ The HALF-OPEN state acts as a probe — one request checks if the service recovered.
✅ Threshold & cooldown are tunable per service reliability profile.
✅ Fast-fail in OPEN state saves bandwidth and reduces user-perceived latency.
