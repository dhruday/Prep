Shimmer Animation Technique

The shimmer effect uses a linear-gradient with three color stops animated via background-position:

1. Base color (dark) → highlight (lighter) → base color

2. background-size: 200% 100% makes the gradient wider than the element

3. Animate background-position from -200% to 200% for the sweep

prefers-reduced-motion

Users who enable "Reduce motion" in OS settings should see a static gray placeholder instead of animation. Use @media (prefers-reduced-motion: reduce) to disable the shimmer.

CSS Shimmer Implementation

/* Shimmer keyframes */
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.skeleton {
  background: linear-gradient(
    90deg,
    #1e2130 25%,    /* base color */
    #2d3551 50%,    /* highlight */
    #1e2130 75%     /* base color */
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
  border-radius: 6px;
}

/* Reduced motion fallback */
@media (prefers-reduced-motion: reduce) {
  .skeleton {
    animation: none;
    background: #2d3551;
  }
}

Key Points

• Use linear-gradient + background-position — pure CSS, no JS needed

• background-size: 200% lets the gradient slide across the element

• Always respect prefers-reduced-motion — show static gray instead

• Use will-change: background-position for GPU acceleration if many skeletons

• The shimmer direction (90deg) mimics a left-to-right reading pattern

Interview tip: "Our shimmer uses CSS-only animated gradients with a reduced-motion fallback to static gray."
