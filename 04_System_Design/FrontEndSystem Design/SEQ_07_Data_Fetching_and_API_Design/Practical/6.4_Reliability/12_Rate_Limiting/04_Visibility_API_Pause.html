Page Visibility API

document.visibilityState tells you if the tab is visible or hidden. The visibilitychange event fires on transitions.
  1. Start a polling interval (e.g., every 2 seconds).
  2. On visibilitychange, check document.hidden.
  3. If hidden → clear the interval (pause polling).
  4. If visible → restart the interval (resume polling).
  5. Optional: fire an immediate poll on resume to get fresh data.

Implementation

let pollTimer = null;
const INTERVAL = 2000;

function poll() {
  fetch('/api/status')
    .then(r => r.json())
    .then(data => updateUI(data));
}

function startPolling() {
  poll(); // immediate first poll
  pollTimer = setInterval(poll, INTERVAL);
}

function stopPolling() {
  clearInterval(pollTimer);
  pollTimer = null;
}

document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    stopPolling();
    console.log('⏸ Tab hidden — polling paused');
  } else {
    startPolling();
    console.log('▶ Tab visible — polling resumed');
  }
});

startPolling();

Key Takeaways

Pausing background polling saves bandwidth, reduces server load, and preserves battery on mobile.
  • document.hidden + visibilitychange = reliable detection
  • Fire an immediate poll on resume for instant freshness
  • Saves API quota — critical with rate-limited backends
  • React Query & SWR use this pattern built-in (refetchOnWindowFocus)
  • Also useful for pausing animations, videos, WebSocket connections
