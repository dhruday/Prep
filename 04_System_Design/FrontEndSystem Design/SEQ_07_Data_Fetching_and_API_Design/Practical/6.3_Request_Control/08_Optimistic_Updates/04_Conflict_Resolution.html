Last-Write-Wins (LWW)

The last save always overwrites. No conflict detection — simple but can silently lose data.

Version Check (Optimistic Locking)

Each save includes the version it was based on. Server rejects if version doesn't match, forcing a refresh.

When to Use Which?

LWW: Low-stakes data, single-user scenarios, rapid updates (e.g., settings).
Version check: Collaborative editing, important data, multi-user environments (e.g., docs, inventory).

Version Check Logic

async function saveWithVersionCheck(newTitle, localVer) {
  const res = await fetch(`${API}/api/posts/${postId}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      title: newTitle,
      expectedVersion: localVer  // server checks this
    })
  });

  if (res.status === 409) {
    // Conflict! Someone else saved first
    const conflict = await res.json();
    showConflict(conflict.currentTitle, conflict.version);
    return false;
  }

  const data = await res.json();
  localVer = data.version; // update local version
  return true;
}
