What Is Debounce?

Debounce delays invoking a function until N ms after the last call. If the user keeps typing, only the final pause triggers the API request.

Typing "react" at normal speed fires 5 raw requests but only 1 debounced request.

Classic Implementation

function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

When To Use

• Search-as-you-type  • Window resize handlers  • Auto-save drafts  • Form validation on input

Event Loop & Timers

setTimeout schedules a macro-task. clearTimeout cancels the pending timer ID before it fires, so only the last scheduled callback survives.

Network Waterfall Impact

// Without debounce — typing "react"
GET /api/search?q=r        → 200  45 ms
GET /api/search?q=re       → 200  52 ms
GET /api/search?q=rea      → 200  38 ms
GET /api/search?q=reac     → 200  41 ms
GET /api/search?q=react    → 200  47 ms   ← 5 requests

// With 300 ms debounce
GET /api/search?q=react    → 200  47 ms   ← 1 request

Memory & GC

Each setTimeout holds a closure reference. clearTimeout releases the pending callback, making the previous closure eligible for garbage collection.

Q: Debounce vs Throttle?

Debounce waits for silence — fires once after activity stops.
Throttle fires at fixed intervals during activity.

Q: How do you cancel an in-flight fetch with debounce?

function debouncedFetch(fn, delay) {
  let timer, controller;
  return (...args) => {
    clearTimeout(timer);
    if (controller) controller.abort();
    controller = new AbortController();
    timer = setTimeout(() => fn(...args, controller.signal), delay);
  };
}

Q: What is the stale-closure risk?

If the debounced callback captures an old state variable, it fires with outdated values. Use a ref in React or pass the latest value as an argument.

Q: Should debounce delay be configurable?

Yes — 150–300 ms for search, 500–1000 ms for auto-save. Expose it as a parameter so callers can tune for their UX.
