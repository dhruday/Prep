RTL languages and what they demand from your layout

Arabic, Hebrew, Persian (Farsi), and Urdu are right-to-left scripts. Combined they represent 750M+ users. A proper RTL layout isn't just reversing text direction — the entire UI must mirror: start/end flips, icons pointing the other way, scrollbars on the left, form inputs right-aligned, progress bars filling right-to-left.

What breaks without RTL support
  • Padding-left applied → becomes wrong side (should be right)
  • margin-left → opposite meaning in RTL
  • text-align: left → should be right for RTL
  • Float/absolute positioned elements at wrong side
  • Icons (arrows, chevrons) pointing wrong direction
  • Flexbox row keeps LTR order
Modern approach: logical CSS properties
  • padding-left → padding-inline-start (auto-flips)
  • margin-right → margin-inline-end (auto-flips)
  • border-left → border-inline-start
  • text-align: left → text-align: start
  • Flexbox + dir="rtl" → row-reverse automatically
  • width/height → inline-size / block-size

RTL implementation in React + Tailwind

// 1. Set dir attribute on html or root element
// _document.tsx / index.html
<html lang="ar" dir="rtl">  // or dir="ltr" for LTR languages

// 2. React context for direction
export const DirectionContext = createContext<'ltr'|'rtl'>('ltr');
export function App({ locale }: { locale: string }) {
  const dir: 'ltr'|'rtl' = ['ar','he','fa','ur'].includes(locale) ? 'rtl' : 'ltr';
  return <DirectionContext.Provider value={dir}><div dir={dir}>...</div></DirectionContext.Provider>;
}

// 3. CSS: logical properties for auto-flip
.card {
  padding-inline-start: 16px;  /* left in LTR, right in RTL */
  border-inline-start: 2px solid #60a5fa;
  text-align: start;
}

// 4. Tailwind v3: RTL variant (ps = padding-start, pe = padding-end)
// <div className="ps-4 pe-2 text-start"> works in both LTR and RTL
// <div className="rtl:rotate-180"> for directional icons

// 5. MUI (Material UI): RTL requires rtl cache + CacheProvider
import rtlPlugin from 'stylis-plugin-rtl';
import createCache from '@emotion/cache';
const cacheRtl = createCache({ key: 'muirtl', stylisPlugins: [rtlPlugin] });
