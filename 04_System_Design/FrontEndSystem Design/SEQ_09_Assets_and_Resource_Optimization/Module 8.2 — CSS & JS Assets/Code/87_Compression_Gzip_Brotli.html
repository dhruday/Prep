Transfer compression — the free performance win

Compression reduces transfer size without changing the file on disk. The browser sends Accept-Encoding: gzip, br and the server compresses on-the-fly (or serves pre-compressed files). Enabling Brotli on SAP's CDN reduced JS transfer size by an additional 15% vs gzip, with zero code changes.

Gzip (deflate)
~70% reduction on text. Universal support. CPU-friendly. Dynamic compression feasible at request time. Level 6 is the default (balance).
Brotli (br)
~20% better than gzip. Built for web (common dictionary). Supported by all modern browsers. High levels (11) are slow to compress — use pre-compressed static files.
Zstandard (zstd)
Emerging (Chrome 123+). Similar ratio to Brotli, much faster to compress. Good for dynamic content. Not yet universal.

What to compress: HTML, CSS, JS, JSON, SVG, XML, fonts (TTF). Do NOT compress: already-compressed formats (JPEG, PNG, WebP, WOFF2, ZIP, MP4) — negligible gain, CPU waste.

Static pre-compression vs dynamic compression

Static pre-compression (preferred)
At build time, generate .js.gz and .js.br files alongside originals. nginx/CDN serves pre-compressed file directly — zero CPU at request time. Best for SPA static assets. 
dist/main.abc123.js
dist/main.abc123.js.gz    # gzip
dist/main.abc123.js.br    # brotli
Dynamic compression (for API responses)
Server compresses JSON on the fly per request. Use level 1–4 for dynamic content (low CPU). Brotli level 1 is comparable to gzip-9 in ratio but compresses 7× faster. 
Response-Headers:
Content-Encoding: br
Vary: Accept-Encoding

CDN tip: Cloudflare, Fastly, CloudFront compress on the edge automatically when you enable brotli. The origin sees uncompressed traffic; the CDN compresses for each client. Multi-region caching means compression happens once per PoP.

Compression config patterns

# ─── nginx brotli + gzip config ───
brotli on;
brotli_comp_level 6;
brotli_types text/plain text/css application/javascript application/json;

gzip on;
gzip_comp_level 6;
gzip_types text/plain text/css application/javascript application/json image/svg+xml;
gzip_static on;    # serve pre-compressed .gz files
brotli_static on;  # serve pre-compressed .br files

// ─── Vite pre-compress at build time ───
import viteCompression from 'vite-plugin-compression';
export default defineConfig({
  plugins: [
    viteCompression({ algorithm: 'gzip' }),
    viteCompression({ algorithm: 'brotliCompress', ext: '.br' }),
  ],
});

// ─── Node.js Express middleware ───
import compression from 'compression';
import shrinkRay from 'shrink-ray-current'; // brotli

app.use(shrinkRay());  // brotli first, gzip fallback

// ─── Check if working ───
// curl -H "Accept-Encoding: br" -I https://yoursite.com/main.js
