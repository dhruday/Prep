What is Synthetic Monitoring?

Proactive observability — automated scripts simulate user interactions on a schedule from multiple regions, detecting issues before real users are affected.

Three Tiers

Tier 1

Uptime Ping

HTTP request every 1 min. Is the URL reachable? Status 200?

Tier 2

API Monitor

Every 5 min. Does the endpoint return correct data structure?

Tier 3

Browser Monitor

Every 10-15 min. Playwright/Puppeteer tests full user flows.

Synthetic vs RUM

DimensionSyntheticRUM
ApproachProactive (scheduled)Reactive (real users)
Coverage24/7 even with no trafficOnly when users visit
EnvironmentControlled (cold cache)Real-world diversity
Best forSLO measurement, alertingUser experience analysis
Best practice: Use BOTH. Synthetic for 24/7 SLO, RUM for real user experience data. They complement, not replace.

// Checkly + Playwright — Synthetic Canary Flow
import { test, expect } from '@playwright/test';

test('Fiori Login Flow', async ({ page }) => {
  await page.goto('https://launchpad.company.com');
  await page.fill('#username', process.env.SYNTHETIC_USER);
  await page.fill('#password', process.env.SYNTHETIC_PASS);
  await page.click('#login-button');
  await expect(page.locator('#dashboard')).toBeVisible({
    timeout: 10000
  });
  // Assert LCP < 3s
  const lcp = await page.evaluate(() => {
    return new Promise(resolve => {
      new PerformanceObserver(list => {
        resolve(list.getEntries().at(-1)?.startTime);
      }).observe({ type: 'largest-contentful-paint' });
    });
  });
  expect(lcp).toBeLessThan(3000);
});
