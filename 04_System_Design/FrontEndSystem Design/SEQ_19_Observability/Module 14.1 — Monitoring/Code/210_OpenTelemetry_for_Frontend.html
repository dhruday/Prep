What is OpenTelemetry?

A vendor-neutral observability framework providing unified APIs for traces, metrics, and logs. One instrumentation, any backend — Jaeger, Tempo, Datadog, or your own collector.

Key OTel Concepts

Trace

End-to-End Journey

Click → JS processing → fetch → backend → DB → response → DOM update. All linked by one traceId.

Span

Single Unit of Work

Each fetch call, DOM operation, or custom function creates a span with timing and attributes.

Context Propagation

The Magic Link

traceparent header auto-injected in fetch — backend continues the same trace.

Sampling

Cost Control

10% head-based + 100% errors. At 10M users, unsampled = storage explosion.

Context Propagation Header:
traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
Format: version-traceId-parentSpanId-traceFlags (W3C Trace Context standard)
⚠️ Never expose your OTel Collector URL to the browser. Proxy OTLP through your backend (/api/otel/v1/traces). Direct exposure = DDoS risk on your telemetry pipeline.

Production OTel Setup

// OpenTelemetry Browser Setup
import { WebTracerProvider } from '@opentelemetry/sdk-trace-web';
import { BatchSpanProcessor } from '@opentelemetry/sdk-trace-base';
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';
import { FetchInstrumentation } from '@opentelemetry/instrumentation-fetch';
import { TraceIdRatioBasedSampler } from '@opentelemetry/sdk-trace-base';

const provider = new WebTracerProvider({
  resource: new Resource({
    'service.name': 'sap-fiori-app',
    'service.version': '2.4.1',
  }),
  sampler: new TraceIdRatioBasedSampler(0.1), // 10% in production
});

provider.addSpanProcessor(new BatchSpanProcessor(
  new OTLPTraceExporter({
    url: '/api/otel/v1/traces', // Proxied — never expose collector
  }),
  { maxQueueSize: 512, scheduledDelayMillis: 5000 }
));

// Manual span for business logic
const tracer = trace.getTracer('invoice-module');

async function approveInvoice(id: string) {
  const span = tracer.startSpan('invoice.approve');
  try {
    const res = await fetch(`/api/invoices/${id}/approve`);
    span.setAttribute('http.status', res.status);
  } catch (e) {
    span.setStatus({ code: SpanStatusCode.ERROR });
    span.recordException(e);
  } finally {
    span.end();
  }
}
