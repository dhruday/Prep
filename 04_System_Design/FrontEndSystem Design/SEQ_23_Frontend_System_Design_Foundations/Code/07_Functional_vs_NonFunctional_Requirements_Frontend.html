📚 Definition Reference

TypeQuestion it answersMeasurable?
FunctionalWhat should the system do?Via acceptance tests
Non-FunctionalHow should the system perform?Via SLOs / metrics
Implicit NFRWhat is assumed but un-stated?Via audits (a11y, security)
Golden rule: In FAANG interviews, every NFR must have a NUMBER. Not "fast" — "LCP < 2.5s". Not "available" — "99.9% uptime = 8.7 hrs downtime/yr".
