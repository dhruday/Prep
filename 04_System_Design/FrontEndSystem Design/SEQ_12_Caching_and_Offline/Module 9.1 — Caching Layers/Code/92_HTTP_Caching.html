HTTP Caching — the protocol-level cache layer

HTTP caching lets browsers and intermediaries (proxies, CDNs) store responses and serve them without hitting the origin server. Properly configured headers cut 70-90% of repeat requests. At SAP, enabling correct Cache-Control on static assets reduced CDN origin hits by 85%.

Key response headers
  • Cache-Control — main directive (max-age, no-cache, private, immutable)
  • ETag — fingerprint for conditional GETs (304 Not Modified)
  • Last-Modified — date-based conditional validation
  • Vary — vary cache by request headers (Accept-Encoding, Cookie)
Key request headers
  • If-None-Match — sends cached ETag, gets 304 if unchanged
  • If-Modified-Since — date-based conditional GET
  • Cache-Control: no-cache — force revalidation
  • Pragma: no-cache — legacy HTTP/1.0 (avoid)

Cache-Control directive builder

max-age 
Cache-Control: max-age=3600
Cached for 1 hour. After that, revalidated with the server.

HTTP cache decision flow

1. Cache lookup — is there a cached response for this URL? If no → fetch from origin
2. Is it fresh? — compare current time vs max-age + Date header. If fresh → serve without request
3. Stale — revalidate — send conditional GET with If-None-Match (ETag) or If-Modified-Since
4a. 304 Not Modified — serve cached body, update headers. Zero bytes transferred for body.
4b. 200 New response — content changed. Download new body, replace cache entry.

Cache-Control patterns by resource type

// ─── Express: set cache headers by route type ───
import { Request, Response, NextFunction } from 'express';

const ONE_YEAR = 60 * 60 * 24 * 365;

// Immutable hashed assets: JS, CSS, fonts
app.use('/static', (req, res, next) => {
  res.set('Cache-Control', `public, max-age=${ONE_YEAR}, immutable`);
  next();
});

// HTML entry point — always revalidate
app.get('/', (req, res) => {
  res.set('Cache-Control', 'no-cache'); // revalidate but use ETag
  sendIndex(res);
});

// API: short TTL + stale-while-revalidate
app.get('/api/orders', (req, res) => {
  res.set('Cache-Control', 'public, max-age=60, stale-while-revalidate=300');
  sendOrders(res);
});

// Per-user data — prevent CDN caching
app.get('/api/profile', (req, res) => {
  res.set('Cache-Control', 'private, no-store');
  sendProfile(res);
});
