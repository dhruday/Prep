Real-time UI: show live server data without user action

Real-time UI means the view updates automatically when backend state changes — without the user refreshing. Key challenges: (1) merging server deltas into local state without flickering, (2) throttling high-frequency updates to avoid thrashing the DOM, (3) showing stale indicators when disconnected. At SAP Bosch, the Angular machine monitoring dashboard throttled telemetry to 100ms render batches even though events arrived every 10ms.

Optimistic updates
Apply change to UI immediately before server confirms. Rollback on error. Best UX.
Throttle / debounce
High-frequency events (telemetry, cursors) must be throttled before DOM updates.
Stale indicator
Show visual cue when WS/SSE is disconnected so users know data may be stale.

Throttled batch updates in React + optimistic mutation

// ─── Throttled batch render ───
const [telemetry, setTelemetry] = useState(initial);
const pendingRef = useRef([]);
const frameRef   = useRef(null);
ws.onmessage = (e) => {
  pendingRef.current.push(JSON.parse(e.data));
  if (!frameRef.current) {
    frameRef.current = requestAnimationFrame(() => {
      setTelemetry(prev => mergeBatch(prev, pendingRef.current));
      pendingRef.current = [];
      frameRef.current = null;
    });
  }
};

// ─── Optimistic status update (React Query) ───
const mutation = useMutation({
  mutationFn: (id) => approveOrder(id),
  onMutate: async (id) => {
    await queryClient.cancelQueries(['orders']);
    const prev = queryClient.getQueryData(['orders']);
    queryClient.setQueryData(['orders'], old =>
      old.map(o => o.id === id ? {...o, status: 'approved'} : o)
    );
    return { prev };
  },
  onError: (_, __, ctx) => queryClient.setQueryData(['orders'], ctx.prev),
});
