ARIA — fill in semantic gaps between HTML and assistive technology

WAI-ARIA (Web Accessibility Initiative – Accessible Rich Internet Applications) adds semantics to HTML for screen readers. The #1 ARIA rule: don't use ARIA if native HTML can do it. A <button> is already a button — don't add role="button" to a <div>. ARIA is for custom widgets (tab panel, combobox, tree view, tooltip) that have no HTML equivalent. At Microsoft (one of ARIA's creators), proper ARIA usage is a hard requirement for all UI components.

Roles
What an element IS. role="tabpanel", role="alert", role="combobox", role="tree". Maps to ARIA role in accessibility tree.
Properties
Characteristics that don't change. aria-label, aria-labelledby, aria-describedby, aria-required, aria-haspopup.
States
Dynamic values that change with interaction. aria-expanded, aria-selected, aria-checked, aria-disabled, aria-busy.

ARIA anti-patterns — what NOT to do

Anti-patternFix
<div role="button">Use <button> — native keyboard, focus, click events included
aria-label on div with textaria-label overrides visible text — only use when label differs from visible text
role="presentation" on interactive elementNever suppress semantics of focusable elements
Static aria-expanded (never updated)Must toggle true/false in JS when menu opens/closes

ARIA patterns for common widgets

WidgetKey ARIAKeyboard

Modal dialogrole="dialog" aria-modal aria-labelledbyEsc closes, Tab cycles focus inside
Comboboxrole="combobox" aria-expanded aria-autocomplete, role="listbox" role="option" aria-selected↑↓ options, Enter select, Esc close
Alertrole="alert" (or aria-live="assertive")No keyboard — announces immediately on change

Custom tabs + combobox ARIA implementation

// ─── Accessible tab component ───
function Tabs({ tabs }) {
  const [active, setActive] = useState(0);
  function handleKey(e, i) {
    if (e.key === 'ArrowRight') setActive((i+1) % tabs.length);
    if (e.key === 'ArrowLeft')  setActive((i-1+tabs.length) % tabs.length);
    if (e.key === 'Home')       setActive(0);
    if (e.key === 'End')        setActive(tabs.length - 1);
  }
  return (
    <>
      <div role="tablist">
        {tabs.map((tab, i) => (
          <button key={i} role="tab"
            aria-selected={i === active}
            aria-controls={`panel-${i}`}
            tabIndex={i === active ? 0 : -1}
            onKeyDown={e => handleKey(e, i)}
            onClick={() => setActive(i)}>
            {tab.label}
          </button>
        ))}
      </div>
      {tabs.map((tab, i) => (
        <div key={i} role="tabpanel" id={`panel-${i}`}
             aria-labelledby={`tab-${i}`}
             hidden={i !== active}>
          {tab.content}
        </div>
      ))}
    </>
  );
}
