What is a performance budget?

A performance budget is a limit on a metric that the team agrees must not be exceeded. If a PR causes the bundle to exceed the limit, the CI pipeline fails — preventing regressions from shipping. At SAP we set Lighthouse score ≥ 90 and JS bundle ≤ 300 KB gzipped as hard gates on every merge to main. Before budgets we were at 2.4 MB — parity check revealed 3 duplicate lodash versions.

Metric-based budgets
  • ⏱ LCP ≤ 2.5 s
  • ⏱ FID / INP ≤ 200 ms
  • 📐 CLS ≤ 0.1
  • ⚡ TTI ≤ 3.8 s
  • 📦 Total JS ≤ 170 KB gzip
Resource-based budgets
  • 📦 Initial JS bundle ≤ 300 KB
  • 🖼 Images ≤ 500 KB per page
  • 🔤 Fonts ≤ 100 KB
  • 🌐 Total page weight ≤ 1.5 MB
  • 🔑 Lighthouse score ≥ 90

Rule of thumb: Budget = baseline × 1.2. If today's bundle is 200 KB, budget at 240 KB — gives room for features while blocking spikes.

CI pipeline enforcement strategies

Lighthouse CI (LHCI)
Runs Lighthouse in CI, asserts metric thresholds, comments diff on PR. Pass/fail gates merge. At SAP this caught a 400 KB third-party widget import before it hit production.
bundlesize / size-limit
Pure bundle size check — no browser needed. Runs in seconds. size-limit integrates with webpack/rollup, reports gzip sizes, fails build if any bundle exceeds config.
webpack-bundle-analyzer as PR artifact
Generate treemap on every PR, post as GitHub Actions artifact. Team can visually inspect which new dependency caused the size increase.
Core Web Vitals monitoring (RUM)
Lab data (Lighthouse) catches regressions before deploy. RUM (real user monitoring) via web-vitals.js + Analytics confirms real-world data matches budget assumptions across devices/connections.

Lighthouse CI + size-limit config

// ─── lighthouserc.js ───
module.exports = {
  ci: {
    assert: {
      assertions: {
        'categories:performance': ['error', { minScore: 0.9 }],
        'first-contentful-paint': ['error', { maxNumericValue: 2000 }],
        'largest-contentful-paint': ['error', { maxNumericValue: 2500 }],
        'cumulative-layout-shift': ['error', { maxNumericValue: 0.1 }],
        'interactive': ['error', { maxNumericValue: 3800 }],
      },
    },
    collect: { url: ['http://localhost:3000'], numberOfRuns: 3 },
  },
};

// ─── .size-limit.js ───
module.exports = [
  { path: 'dist/main.*.js',   limit: '300 KB',  gzip: true },
  { path: 'dist/vendor.*.js', limit: '150 KB',  gzip: true },
  { path: 'dist/*.css',       limit: '20 KB',   gzip: true },
];

// ─── GitHub Actions step ───
- name: Check bundle size
  run: npx size-limit --json | tee size-result.json
- name: Run Lighthouse CI
  run: |
    npm install -g @lhci/cli
    lhci autorun
