Side Effect Detection & sideEffects Field

Practical 7.2 · Tell the bundler which files are safe to tree-shake

What Is a Side Effect?

// A "side effect" is code that runs just by importing the module
// — independent of which exports you use

// ❌ Side effect: modifies global state on import
// polyfill.js
Array.prototype.customMethod = function() { ... };
// Just importing this file changes Array.prototype!
// Bundler CANNOT remove this even if no exports are used

// ❌ Side effect: CSS import
import './styles.css';
// No named export, but has the side effect of adding styles

// ❌ Side effect: self-executing code
console.log('Module loaded!');
window.myLib = { version: '1.0' };
export const utils = { ... };

// ✅ No side effects: pure exports only
export function add(a, b) { return a + b; }
export function multiply(a, b) { return a * b; }
// Nothing runs on import — safe to tree-shake unused exports

package.json sideEffects Field

// Tell webpack/Rollup which files have side effects

// "None of my files have side effects" — maximum tree-shaking
{
  "name": "my-library",
  "sideEffects": false
}
// Bundler can safely remove ANY unused export from ANY file

// "Only CSS files have side effects"
{
  "sideEffects": ["*.css", "*.scss", "./src/polyfills.js"]
}
// Bundler keeps CSS imports and polyfills.js
// Everything else is tree-shakeable

// Without sideEffects field:
// Bundler assumes ALL files MIGHT have side effects
// → Cannot remove unused modules → larger bundle
//
// This is why many libraries ship huge bundles by default
// until they add "sideEffects": false

Webpack /*#__PURE__*/ Annotation

// Mark function calls as pure (no side effects)
// Allows bundler to remove them if result is unused

const result = /*#__PURE__*/ createComponent({
  name: 'MyComponent',
  render: () => { ... }
});

// Without /*#__PURE__*/:
// Bundler keeps createComponent() call even if result is unused
// (because it might have side effects inside)

// With /*#__PURE__*/:
// Bundler knows: if `result` is unused, remove the entire call

// Babel/TypeScript compilers add this automatically for:
// - React.createElement() → /*#__PURE__*/ React.createElement()
// - styled-components → /*#__PURE__*/ styled.div``
