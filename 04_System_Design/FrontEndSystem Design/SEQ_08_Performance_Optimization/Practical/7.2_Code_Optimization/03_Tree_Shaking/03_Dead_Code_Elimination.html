Dead Code Elimination

Practical 7.2 · How minifiers remove unreachable code

Tree Shaking vs Dead Code Elimination

// Tree Shaking (bundler — webpack/Rollup/esbuild):
// Removes unused EXPORTS across module boundaries
// Works at the MODULE level
//
// Dead Code Elimination (minifier — Terser/esbuild):
// Removes unreachable code WITHIN a module
// Works at the CODE level
//
// They're complementary:
// 1. Bundler tree-shakes unused exports
// 2. Minifier eliminates dead code in remaining modules

Patterns Eliminated by Minifiers

// 1. Unreachable code after return
function example() {
  return 42;
  console.log('never runs'); // ← removed by Terser
}

// 2. Always-false conditions (with process.env)
if (process.env.NODE_ENV === 'development') {
  console.log('debug info'); // ← removed in production build
}
// webpack DefinePlugin replaces process.env.NODE_ENV with "production"
// → if ("production" === "development") → if (false) → removed

// 3. Unused variables
const unused = expensiveComputation(); // removed if `unused` never read

// 4. Empty functions
function noop() {} // inlined as nothing at call sites

// 5. Feature flags
const FEATURE_NEW_UI = false; // set by build config
if (FEATURE_NEW_UI) {
  renderNewUI(); // entire block removed when flag is false
} else {
  renderOldUI(); // this branch is kept
}

Build Config for Elimination

// webpack.config.js — DefinePlugin for compile-time constants
const webpack = require('webpack');

module.exports = {
  mode: 'production', // Enables Terser + tree shaking
  plugins: [
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production'),
      __DEV__: false,
      FEATURE_FLAGS: JSON.stringify({
        newCheckout: true,
        darkMode: false,
      }),
    }),
  ],
  optimization: {
    usedExports: true,    // Mark unused exports
    minimize: true,       // Run Terser
    sideEffects: true,   // Respect sideEffects field
  },
};

// Vite — same concept, different API:
export default defineConfig({
  define: {
    __DEV__: false,
    'import.meta.env.FEATURE_NEW_UI': false,
  },
});
