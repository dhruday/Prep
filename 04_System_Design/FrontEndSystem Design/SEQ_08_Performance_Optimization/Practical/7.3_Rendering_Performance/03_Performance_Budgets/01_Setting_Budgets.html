How to Derive Budgets (Google Method)

// Step 1: Define target TTI in seconds
//   Recommendation: 5s on Fast 3G (mid-tier mobile)
//   Moto G4 / Samsung A-series = target device

// Step 2: Calculate total transfer budget
//   Fast 3G ≈ 4 Mbps = 500 KB/s
//   5s × 500 KB/s = 2500 KB total transfer budget
//   BUT: subtract ~300ms TCP + TLS + DNS overhead
//   AND: 1.5s for JavaScript parse/compile on slow CPU
//   Effective budget: ~2500 - 750 = ~1750 KB transfer

// Step 3: Allocate budget across resource types
//   HTML:   ~20 KB (10% - document + inline critical CSS)
//   CSS:    ~50 KB (critical + above-fold)
//   JS:     ~170 KB (compressed — Google's recommendation)
//   Fonts:  ~50 KB (2 weights × 25KB each)
//   Images: ~500 KB (hero + above-fold, lazy rest)
//   ─────────────────
//   Total:  ~790 KB (leaves margin for analytics/3rd party)

// Step 4: Set up enforcement
//   → Lighthouse CI budgets (above)
//   → bundlesize / size-limit in CI
//   → webpack performance.hints: 'error'
//   → PR checks blocking on budget violations
