What Each Metric Means

FCP  (First Contentful Paint)   — First text/image rendered
LCP  (Largest Contentful Paint) — Largest element rendered (Core Web Vital)
TTI  (Time to Interactive)      — Page fully responds to input within 50ms
TBT  (Total Blocking Time)      — Sum of long task time between FCP and TTI
DOMContentLoaded                — HTML parsed, deferred scripts executed
Load                            — All resources (images, CSS) loaded

Thresholds (Good):
  FCP  ≤ 1.8s  |  LCP ≤ 2.5s  |  TTI ≤ 3.8s  |  TBT ≤ 200ms
