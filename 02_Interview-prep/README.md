## 🎯 The 5 Rules of the Interview

1. **Numbers first.** "60 → 95 Lighthouse" beats "improved performance."
2. **Own the trade-off.** Every choice has a cost. Say what you gave up.
3. **Bridge to depth.** End every answer with a hook the interviewer can pull.
4. **Silence is fine.** Think 3 seconds. Don't fill air with "umm."
5. **"I don't know" + a plan** is stronger than a guess.

## 🧠 Memory Hooks (memorize these 10 lines)

1. **Launchpad:** *"Legacy jQuery jungle → React island city."*
2. **Performance:** *"Ship less JS, ship it later, cache it forever."*
3. **Micro-frontends:** *"Independent teams, independent deploys, shared shell."*
4. **CSP:** *"Whitelist what runs. Block everything else."*
5. **XSS:** *"Never trust input. Never inject HTML. Always escape."*
6. **Web Vitals:** *"LCP paints, INP responds, CLS stays still."*
7. **React fiber:** *"Interruptible work, prioritized rendering."*
8. **Redux Toolkit:** *"Slices, not reducers. Immer, not spread."*
9. **Testing:** *"Test behavior, not implementation."*
10. **Leadership:** *"Multiplier, not hero."*
