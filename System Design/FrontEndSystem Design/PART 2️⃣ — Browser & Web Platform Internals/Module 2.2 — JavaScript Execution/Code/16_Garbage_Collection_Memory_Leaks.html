// Generational GC simulator — most objects die young!
Generational Hypothesis: Most objects die young (allocated in one render cycle, discarded). Scavenge runs every few MB — copies ~1-5% of objects to old space, wipes the rest in one operation. Major GC runs infrequently. This is why temporary objects have almost zero GC cost.

// WeakMap vs Map memory behaviour simulator
Rule: Use WeakMap when keys are DOM nodes or component instances — entry auto-removed when key is GC'd. Use Map when you need .size, iteration, or explicit eviction (LRU cache). WeakRef is for observing without owning — always check .deref() before use.
