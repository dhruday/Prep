What does opening a connection actually cost?

Every new origin your page talks to requires: DNS lookup → TCP handshake → TLS handshake. Adjust RTT to simulate network conditions, then see how resource hints eliminate wasted time.

RTT 80 ms
▲ Resource hints push these costs off the critical path — DNS/TCP/TLS happen in parallel while HTML parses.

Without hints

1. Browser parses HTML
2. Finds <script src="cdn.example.com/app.js">
3. Stops to DNS resolve cdn.example.com
4. Waits for TCP handshake
5. Waits for TLS handshake
6. Finally starts downloading

With preconnect

1. <link rel="preconnect"> in <head>
2. Browser immediately starts DNS + TCP + TLS
3. While HTML parses further...
4. Finds the script → connection already warm!
5. Immediately starts downloading

SAP Example: 380ms LCP Improvement

Hruday's team found the LCP image was hosted on a dedicated CDN origin — not referenced until a CSS background rule was parsed (late discovery). Adding preconnect + preload hints moved it from 2,840ms to 2,460ms LCP.

Resource Hint Decision Tree

📌 Is this a resource critical to first paint?
→ Yes + you know the URL → preload
→ Yes + it's from a specific origin → preconnect
→ Maybe + origin uncertain → dns-prefetch
→ No + needed on next page → prefetch
→ It's an ES module → modulepreload
⚠️ Don't over-preconnect: Each preconnect opens a real socket and holds TLS state. Limit to 2–3 critical origins. Use dns-prefetch for everything else.

TypeScript utility — injectResourceHints()

// Production utility used in SAP Fiori performance work
interface ResourceHint {
  rel: 'dns-prefetch' | 'preconnect' | 'preload' | 'prefetch' | 'modulepreload';
  href: string;
  as?: 'script' | 'style' | 'font' | 'image' | 'fetch';
  crossorigin?: boolean;
  type?: string; // MIME type for preload
}

function injectResourceHints(hints: ResourceHint[]): void {
  const fragment = document.createDocumentFragment();

  hints.forEach(hint => {
    // Deduplicate: skip if already in <head>
    const existing = document.querySelector(
      `link[rel="${hint.rel}"][href="${hint.href}"]`
    );
    if (existing) return;

    const el = document.createElement('link');
    el.rel = hint.rel;
    el.href = hint.href;
    if (hint.as) el.setAttribute('as', hint.as);
    if (hint.crossorigin) el.setAttribute('crossorigin', '');
    if (hint.type) el.setAttribute('type', hint.type);
    fragment.appendChild(el);
  });

  document.head.appendChild(fragment);
}

// Usage:
injectResourceHints([
  { rel: 'preconnect', href: 'https://fonts.googleapis.com' },
  { rel: 'preconnect', href: 'https://fonts.gstatic.com', crossorigin: true },
  { rel: 'dns-prefetch', href: 'https://analytics.example.com' },
  { rel: 'preload', href: '/hero-image.webp', as: 'image' },
]);
