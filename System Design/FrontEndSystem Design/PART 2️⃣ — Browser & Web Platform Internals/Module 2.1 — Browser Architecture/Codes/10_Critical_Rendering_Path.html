🔄 CRP Steps

1

HTML Parsing → DOM

Browser tokenizes HTML and builds DOM incrementally as bytes arrive.

2

CSS Parsing → CSSOM

CSS is render-blocking. Browser stops painting until CSSOM is complete.

3

JavaScript Execution

Sync JS pauses HTML parsing. Defer/Async JS avoids this.

4

Render Tree = DOM + CSSOM

Only visible nodes included. display:none is excluded.

5

Layout → Paint → Composite

Geometry calculated, pixels drawn, GPU layers composited.

6

🎨 First Paint (FCP)

User sees first meaningful content. This is what CRP optimization targets.
