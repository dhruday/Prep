HTTP/3 / QUIC advantages:
• UDP-based: no TCP HOL blocking!
• Built-in TLS 1.3 (0-RTT handshake)
• Connection ID survives IP change (mobile)
• Independent per-stream loss recovery

⛔ TCP Head-of-Line Blocking (HTTP/2)

HTTP/2 multiplexes over ONE TCP connection. If a single TCP packet is lost, ALL streams in that connection must wait for retransmission — even unrelated ones.

✅ QUIC: No HOL Blocking (HTTP/3)

HTTP/3 / QUIC uses independent per-stream delivery. A dropped packet on Stream 1 has ZERO effect on Stream 2, 3, 4... Each stream retransmits independently.
