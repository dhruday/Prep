⚙️ Protocol Stack (OSI Model — Browser Perspective)

HTTP/S or HTTP2/3 (Application Layer) Requests, Responses, Headers
TLS 1.3 (Session/Presentation Layer) Encryption, Cert Validation
TCP or QUIC (Transport Layer) Reliable delivery, flow control
IP (Network Layer) Routing packets across networks
Ethernet/Wi-Fi (Data Link + Physical) Physical transmission
Browser-relevant layers: The browser deals with HTTP, TLS, and half of TCP. The OS handles IP, TCP flow control, and the physical layer. HTTP/3 (QUIC) moves to UDP + handles its own reliability, removing TCP's HOL blocking.

🔄 Request Steps

1

🔍 DNS Lookup

Resolve hostname → IP address. Browser cache → OS cache → Recursive resolver → Authoritative DNS.

—
2

🤝 TCP Handshake (3-way)

SYN → SYN-ACK → ACK. Costs 1 RTT before any data. Skipped with Keep-Alive / QUIC.

—
3

🔐 TLS 1.3 Handshake

Client Hello + Server Hello. TLS 1.3 = 1 RTT (or 0-RTT resumption). TLS 1.2 = 2 RTTs.

—
4

📤 HTTP Request Sent

GET /resource HTTP/1.1 over established connection. Server begins processing.

—
5

⏳ TTFB (Time To First Byte)

Server processes request = DB query + rendering + sending first byte. Ideal <200ms.

—
6

⬇️ Download Response

Server sends response body in TCP segments. Browser can start parsing HTML as bytes arrive.
