WCAG contrast requirements — the math

~300 million people have colour-vision deficiency worldwide. WCAG SC 1.4.3 (AA) and 1.4.6 (AAA) set minimum contrast ratios between foreground text and background. Contrast ratio = (L1 + 0.05) / (L2 + 0.05) where L1 is the lighter relative luminance and L2 the darker. Range: 1:1 (no contrast) to 21:1 (black on white). Adobe's design system enforces contrast programmatically at build time.

4.5 : 1
AA — Normal text (<18pt regular, <14pt bold)
3 : 1
AA — Large text (≥18pt / ≥14pt bold)
3 : 1
AA — UI components & graphical objects (SC 1.4.11)
7 : 1
AAA — Enhanced contrast for normal text

Common misconceptions

MisconceptionReality
"Dark text on light bg is always fine"Grey on white (#767676 on #fff) fails AA — only 4.5:1 at exactly #757575
"Placeholder text counts as content"Placeholder doesn't replace label and must still meet contrast (SC 1.4.3)
"Disabled elements are exempt"True — disabled UI components are explicitly excluded from contrast requirements
"You only need contrast for text"WCAG 1.4.11 also requires 3:1 for UI components (borders, icons, chart elements)

/* ─── Design token layer (CSS custom properties) ───
   Define palette → derive semantic tokens → never use raw hex in components */

:root {
  /* Primitives */
  --color-teal-700: #0d9488;
  --color-slate-50:  #f8fafc;
  --color-slate-900: #0f172a;

  /* Semantic tokens — accessible pairs verified at design time */
  --text-on-dark:   var(--color-slate-50);    /* 15.8:1 on slate-900 */
  --text-on-teal:   #ffffff;                  /*  4.6:1 on teal-700  */
  --text-muted:     #94a3b8;                  /*  4.6:1 on slate-900 */
}

// ─── postcss-plugin-check-contrast (CI) ───
// Parses every color/background-color pair in CSS at build time
// Fails the build if ratio < 4.5:1 for any regular text token

// ─── Inline luminance calculator (utility) ───
function luminance(hex) {
  const rgb = [hex.slice(1,3), hex.slice(3,5), hex.slice(5,7)]
    .map(h => parseInt(h, 16) / 255)
    .map(c => c <= 0.03928 ? c/12.92 : ((c+0.055)/1.055)**2.4);
  return 0.2126*rgb[0] + 0.7152*rgb[1] + 0.0722*rgb[2];
}
function contrast(hex1, hex2) {
  const [l1, l2] = [luminance(hex1), luminance(hex2)].sort((a,b)=>b-a);
  return (l1 + 0.05) / (l2 + 0.05);
}
