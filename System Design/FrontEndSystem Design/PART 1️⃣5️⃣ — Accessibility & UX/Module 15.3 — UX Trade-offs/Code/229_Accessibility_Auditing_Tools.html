The Big Three

axe-core

Engine by Deque

Most accurate rule engine. ~0% false positives. 100+ rules. CI-ready with Playwright/Cypress. Open-source.

Lighthouse

Google Chrome

Uses axe-core internally. Scores 0-100. Built into Chrome DevTools. Lighthouse CI for pipelines.

Arc Toolkit

TPGi

Manual + automated. Detailed WCAG mapping. Best for compliance documentation.

axe-core + Playwright in CI

import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

const PAGES = ['/', '/dashboard', '/invoices'];

for (const route of PAGES) {
  test(`a11y: ${route}`, async ({ page }) => {
    await page.goto(route);
    const results = await new AxeBuilder({ page })
      .withTags(['wcag2a', 'wcag2aa'])
      .analyze();
    expect(results.violations).toHaveLength(0);
  });
}
