Finite State Machine — the problem it solves

Without a state machine, boolean flags proliferate: isLoading, isError, isSuccess, isRetrying, hasTimedOut. These can appear in impossible combinations (isLoading=true AND isSuccess=true). A FSM guarantees the system is in exactly ONE state at a time.

❌ Boolean flag soup
isIdle: true
isLoading: false
isError: false
isSuccess: false
isRetrying: false
2^5 = 32 possible states — most are impossible
✅ State machine
State: 'idle' | 'loading' | 'success' | 'error' | 'retrying'
Exactly 5 valid states. Impossible combos eliminated.

Transitions are explicit & exhaustive.

XState vs useState / useReducer

Use useState when: simple, isolated, 2-3 possible values, no transitions logic.
e.g. modal open/close, counter, form field value
Use useReducer when: multiple related fields that change together, action-based updates.
e.g. form multi-field state, shopping cart
Use XState when: complex flows with multiple valid/invalid transitions, parallel states, async workflows, need visual documentation.
e.g. checkout flow, payment, multi-step wizard, drag-and-drop, real-time collaboration

XState v5 — createMachine + useMachine

import { createMachine, assign } from 'xstate';
import { useMachine } from '@xstate/react';

const paymentMachine = createMachine({
  id: 'payment',
  initial: 'idle',
  context: { amount: 0, retries: 0, error: null as string | null },
  states: {
    idle: {
      on: { SUBMIT: 'validating' }
    },
    validating: {
      on: {
        VALIDATION_OK: 'processing',
        VALIDATION_FAIL: 'idle',
      }
    },
    processing: {
      invoke: {
        src: 'processPayment',
        onDone:  { target: 'success' },
        onError: { target: 'error', actions: assign({ error: ({ event }) => event.error }) },
      },
      after: { 30000: 'timeout' },  // auto-timeout after 30s
    },
    success: { type: 'final' },
    error: {
      on: {
        RETRY: {
          target: 'processing',
          guard: ({ context }) => context.retries < 3,
          actions: assign({ retries: ({ context }) => context.retries + 1 }),
        },
        CANCEL: 'idle',
      }
    },
    timeout: { on: { RESET: 'idle' } },
  },
});

const PaymentForm = () => {
  const [snapshot, send] = useMachine(paymentMachine, {
    actors: { processPayment: fromPromise(() => api.pay()) }
  });
  return (
    <>
      <p>State: {snapshot.value}</p>
      {snapshot.matches('idle') && <button onClick={() => send({ type: 'SUBMIT' })}>Pay</button>}
      {snapshot.matches('error') && <button onClick={() => send({ type: 'RETRY' })}>Retry</button>}
    </>
  );
};
