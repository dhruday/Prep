URL is the ultimate shareable state container

Any UI state that users would want to share, bookmark, or return to should live in the URL. Local state is ephemeral. URL state is permanent, shareable, and survives refresh.

✅ Put in URL
  • Search query (?q=laptop)
  • Filter selections (?status=pending)
  • Sort order (?sort=price_asc)
  • Active tab (?tab=analytics)
  • Pagination (?page=3)
  • Date range (?from=2024-01&to=2024-06)
❌ Don't put in URL
  • Modal open/close
  • Tooltip visibility
  • Expanded/collapsed state
  • Scroll position
  • Unsaved form field values
  • Authentication tokens
SAP context: SAP Procurement Analytics dashboard — users frequently share report views. Migrating from useState filters → URL params (via nuqs) let analysts share exact report state with one link. 60% reduction in "how do I reproduce this view?" Slack messages.

Decision guide — useState vs URL state

nuqs (type-safe URL state) + Next.js

// nuqs — type-safe URL query string state
import { useQueryState, parseAsInteger, parseAsString } from 'nuqs';

export function OrdersPage() {
  const [tab, setTab]       = useQueryState('tab',    parseAsString.withDefault('orders'));
  const [status, setStatus] = useQueryState('status', parseAsString.withDefault('all'));
  const [page, setPage]     = useQueryState('page',   parseAsInteger.withDefault(1));

  // Changing state pushes to URL: /orders?tab=analytics&status=pending&page=2
  // Fully shareable, bookmarkable, survives refresh

  return (
    <>
      <StatusFilter value={status} onChange={setStatus} />
      <Pagination    page={page}   onPageChange={setPage} />
    </>
  );
}

// Next.js 14 server component — read URL params server-side
export default async function OrdersPage({
  searchParams,
}: {
  searchParams: { tab?: string; status?: string; page?: string }
}) {
  const status = searchParams.status ?? 'all';
  const page   = parseInt(searchParams.page ?? '1', 10);
  const orders = await fetchOrders({ status, page }); // server fetch
  return <OrderList orders={orders} />;
}
