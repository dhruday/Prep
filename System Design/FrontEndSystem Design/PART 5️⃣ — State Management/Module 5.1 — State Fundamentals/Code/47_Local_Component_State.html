Local State — owned by one component

Local component state is state that is owned, managed, and consumed entirely within a single component. In React: useState, useReducer. In Angular: component-scoped variables / signals. In Vue: ref() / reactive(). The state is initialised fresh on mount and destroyed on unmount.

✔ UI state — isOpen, isSelected, inputValue — lives here
✔ Form draft state — text being typed, before submit
✔ Animation state — hover, focus, toggle
⚠ Move to global if multiple unrelated components need it

💡 Colocation principle: state should live as close as possible to where it is used. Only lift when forced by sibling/parent needs.

useState, useReducer, and derived state

// useState — simple single value
const [isOpen, setIsOpen] = useState(false);
const [count, setCount] = useState(0);

// Functional update — always use when next state depends on prev
const increment = () => setCount(prev => prev + 1);

// useReducer — complex state with multiple sub-values
type State = { count: number; history: number[] };
type Action =
  | { type: 'increment' }
  | { type: 'decrement' }
  | { type: 'reset' };

function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1, history: [...state.history, state.count + 1] };
    case 'reset':
      return { count: 0, history: [] };
    default: return state;
  }
}

// Derived state — computed from existing state, not stored separately
const [items, setItems] = useState([...]);
const total = items.reduce((s, i) => s + i.price, 0); // derived
// Don't: const [total, setTotal] = useState(0); // duplicated state
