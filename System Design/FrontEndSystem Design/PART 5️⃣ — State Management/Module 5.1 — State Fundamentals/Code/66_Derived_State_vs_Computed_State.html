Derived State — never store what you can compute

Derived state is any value that can be calculated from existing state. Storing it creates a single source of truth violation — you now have two pieces of state that must be kept in sync manually. Bugs arise when they diverge.

❌ Redundant stored state
items: Item[]
total: number ← derived from items
count: number ← derived from items.length
Must keep all 3 in sync on every mutation
✅ Single source of truth
items: Item[] ← only stored state
const total = items.reduce(sum)
const count = items.length
total and count are always correct by definition

Common anti-patterns with derived state

// ❌ 1. Storing derived state in useState
const [items, setItems] = useState([]);
const [total, setTotal] = useState(0); // ← don't!
setItems(prev => {
  const newItems = [...prev, item];
  setTotal(newItems.reduce((s,i) => s+i.price, 0)); // sync hell
  return newItems;
});

// ✅ Compute inline — always fresh
const total = items.reduce((s, i) => s + i.price, 0);

// ❌ 2. useEffect to sync derived state
useEffect(() => {
  setTotal(items.reduce(...))// triggers extra render!
}, [items]);

// ✅ useMemo for expensive derivations
const sortedFiltered = useMemo(() =>
  items
    .filter(i => i.category === selected)
    .sort((a, b) => a.price - b.price),
  [items, selected] // only recompute when these change
);

useMemo + Redux selectors for derived state

// Memoised derivation — no unnecessary recalculation
const CartSummary = () => {
  const items = useCartStore(s => s.items);

  // useMemo: only re-compute when items changes
  const { total, tax, grandTotal } = useMemo(() => {
    const total = items.reduce((s, i) => s + i.price * i.qty, 0);
    const tax = total * 0.18;
    return { total, tax, grandTotal: total + tax };
  }, [items]);

  return <Summary total={total} tax={tax} grandTotal={grandTotal} />;
};

// Redux selector with reselect — memoised across components
import { createSelector } from 'reselect';

const selectItems = (state: RootState) => state.cart.items;
const selectTotal = createSelector(
  selectItems,
  (items) => items.reduce((s, i) => s + i.price, 0) // memoised
);
