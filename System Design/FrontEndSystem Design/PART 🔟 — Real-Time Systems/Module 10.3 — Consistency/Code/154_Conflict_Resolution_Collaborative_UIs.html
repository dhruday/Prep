The problem: two users editing the same data simultaneously

In collaborative apps (Google Docs, Figma, Notion), multiple users can edit the same document concurrently. If both make changes offline or simultaneously, the server receives conflicting operations. How do we merge them without losing data or asking users to manually resolve conflicts?

Last-Write-Wins (LWW)
Whoever writes last overwrites. Simple but lossy. The "Alice's work got deleted!" problem. Acceptable only for non-text fields (user status, color choice).
Operational Transformation (OT)
Transform operations relative to concurrent ops. Used by Google Docs. Mathematically complex, requires central server to sequence ops. Hard to implement correctly.
CRDTs (Conflict-free Replicated Data Types)
Data structures that can be merged automatically in any order. No coordination needed. Used by Figma, Liveblocks. Yjs, Automerge are JS implementations. Best for rich text, lists, maps.
Version Vectors / Vector Clocks
Each node tracks causality with a vector clock [userA: 3, userB: 2]. Detects true concurrency vs causal order. Needed for detecting when OT/CRDT merge should be applied.

Yjs CRDT implementation

// npm install yjs y-websocket
import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';

// Create shared document (CRDT)
const ydoc = new Y.Doc();
const ytext = ydoc.getText('content');       // Shared text type
const ymap  = ydoc.getMap('metadata');       // Shared map

// Connect to Y-WebSocket server (sync + awareness)
const provider = new WebsocketProvider(
  'wss://my-yjs-server.com',
  'my-doc-id',
  ydoc
);

// Bind to Quill editor
import { QuillBinding } from 'y-quill';
const binding = new QuillBinding(ytext, quillEditor, provider.awareness);

// Awareness: presence + cursors (ephemeral state)
provider.awareness.setLocalStateField('user', {
  name: 'Hruday',
  color: '#60a5fa',
  cursor: { anchor: 42, head: 48 }
});

provider.awareness.on('change', () => {
  const states = [...provider.awareness.getStates().values()];
  renderCursors(states);
});

// Transactions — batch multiple changes
ydoc.transact(() => {
  ytext.insert(0, 'Hello ');
  ymap.set('title', 'My Document');
}, 'local');  // origin = 'local' for undo manager
