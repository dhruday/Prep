HTTP streaming — server pushes text/event-stream over a persistent connection

SSE uses a standard HTTP connection (no protocol upgrade) with Content-Type: text/event-stream. The server keeps the response open, pushing newline-delimited events. The browser's built-in EventSource API handles reconnection automatically. At SAP, SSE is perfect for AI stream responses (like SAP Joule) — the text streams token by token as the LLM generates it.

SSE strengths
  • ✅ Works over plain HTTP/2
  • ✅ Auto-reconnect + Last-Event-ID
  • ✅ Standard browser EventSource API
  • ✅ Easy CDN / proxy compatibility
  • ✅ Named event types
SSE limitations
  • ❌ Server → Client only (no client push)
  • ❌ Text only (no binary frames)
  • ❌ HTTP/1.1: max 6 connections per origin
  • ❌ No ping/pong heartbeat built-in

SSE client (EventSource) + Express server + React hook

// ─── Browser: EventSource ───
const es = new EventSource('/api/stream?id=abc');
es.addEventListener('token', (e) => appendToken(e.data));
es.addEventListener('done',  (e) => es.close());
es.onerror = () => handleError(); // auto-reconnects by default

// ─── Express server ───
app.get('/api/stream', async (req, res) => {
  res.set({ 'Content-Type': 'text/event-stream', 'Cache-Control': 'no-cache', Connection: 'keep-alive' });
  res.flushHeaders();
  for await (const token of generateTokens(req.query.id)) {
    res.write(`event: token\ndata: ${token}\n\n`);
  }
  res.write('event: done\ndata: \n\n');
  res.end();
});

// ─── React hook with EventSource ───
function useSSE(url: string) {
  const [text, setText] = useState('');
  useEffect(() => {
    const es = new EventSource(url);
    es.addEventListener('token', e => setText(t => t + e.data));
    es.addEventListener('done', () => es.close());
    return () => es.close();
  }, [url]);
  return text;
}
