Correlation IDs — link a user action to every system log it touches

In microservices, a single "Pay" button click triggers 5+ backend services. Without a correlation ID threading all these calls together, debugging a failure requires manually matching timestamps across 5 log streams. With a correlation ID (UUID generated on the frontend, passed as X-Correlation-ID header), you run one log query and see the full trace. W3C Trace Context standardizes this as traceparent header. SAP BTP uses X-CorrelationID in all Fiori apps, which maps to the Dynatrace trace.

Without correlation ID
Support ticket: "Payment failed at 14:23"
Search API logs: 50,000 lines at 14:23
Search DB logs: 80,000 lines at 14:23
Search payment service: 30,000 lines

→ 1-2 hours to correlate which logs belong to this user's transaction
With correlation ID
Support ticket includes correlationId from UI error message

Kibana query: correlationId:"req-7f3a9b"

→ Instantly see 12 log entries across 4 services showing exactly what happened

X-Correlation-IDSAP BTP, many enterprise systemsUUID v4 string
X-Request-IDnginx, Express, many REST APIsUUID or nanoid string
traceparent (W3C)OpenTelemetry standard00-{traceId}-{spanId}-{flags}
X-Amzn-Trace-IdAWS X-Ray / ALBRoot=1-{timestamp}-{hex}

Frontend correlation ID generation + Axios injection + error surface

// ─── Generate per-request correlation ID ───
import { v4 as uuid } from 'uuid';

api.interceptors.request.use(cfg => {
  const corrId = uuid();
  cfg.headers['X-Correlation-ID'] = corrId;
  cfg.metadata = { corrId };          // store for response interceptor
  logger.info('API request', { corrId, url: cfg.url });
  return cfg;
});

// ─── Log correlation ID on error ───
api.interceptors.response.use(
  res => res,
  err => {
    const corrId = err.config?.metadata?.corrId;
    logger.error('API error', { corrId, status: err.response?.status });
    Sentry.captureException(err, { extra: { corrId } });
    throw { ...err, corrId }; // surface to UI for support display
  }
);

// ─── Show correlation ID in UI error message ───
function ErrorToast({ error }) {
  return (
    <Toast title="Something went wrong">
      <p>Please contact support with this ID:</p>
      <code style={{ userSelect: 'all' }}>{error.corrId}</code>
    </Toast>
  );
}
