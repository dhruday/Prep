User analytics — understand how users actually use your product

User analytics bridges product decisions and engineering data. Tools like Mixpanel, Amplitude, PostHog, or custom ETL pipelines answer: Where do users drop off? Which features are actually used? What paths do power users take? SAP builds product analytics using internal telemetry in BTP Cockpit to drive quarterly roadmap decisions — usage of features directly influences engineering investment.

Event tracking
Track user actions (click, submit, scroll, view). Structure: event name + properties. Example: "checkout_started" {items: 3, cart_value: $142}
Funnel analysis
Multi-step conversion path. Identifies highest drop-off step. "Search → PDP → Add to cart → Checkout → Pay" — where are you losing users?
Cohort analysis
Group users by signup date or feature adoption. Compare Day 7 retention across cohorts to measure product improvement over releases.

Analytics abstraction layer + SPA route tracking

// ─── Analytics abstraction (swap tools without code change) ───
interface Analytics {
  track(event: string, props?: Record<string, unknown>): void;
  identify(userId: string, traits?: object): void;
  page(name: string, props?: object): void;
}

class MixpanelAdapter implements Analytics {
  track(event, props) { mixpanel.track(event, props); }
  identify(id, traits) { mixpanel.identify(id); mixpanel.people.set(traits); }
  page(name, props) { mixpanel.track('Page Viewed', { page: name, ...props }); }
}
export const analytics: Analytics = new MixpanelAdapter();

// ─── SPA page view tracking (React Router) ───
function AnalyticsProvider({ children }) {
  const location = useLocation();
  useEffect(() => {
    analytics.page(location.pathname, {
      search: sanitizeUrl(location.search) // strip tokens from params
    });
  }, [location.pathname]);
  return children;
}

// ─── Usage ───
analytics.track('checkout_started', {
  cart_items: cart.length,
  cart_value: cart.reduce((s,i) => s+i.price, 0),
  payment_method: 'card'
});
