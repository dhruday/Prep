Session replay — watch exactly what the user saw and did

Session replay tools (FullStory, LogRocket, Hotjar, Sentry Replay) record DOM mutations, user interactions, network activity, and console logs. When a bug is reported, you watch the replay and see exactly what state the UI was in. This is invaluable for issues that are hard to reproduce. At SAP, LogRocket is used for premium customer support — when a customer reports a P1 bug, support attaches the session replay URL directly in the Jira ticket.

How it works
MutationObserver records DOM changes. Mouse/keyboard events captured. Replays using rrweb serialized DOM snapshots. Bandwidth-optimized: only diffs sent.
What it captures
• Mouse movements & clicks
• Scroll positions
• Form interactions (masked)
• Console errors
• Network timeline
• Page navigation
Privacy requirements
GDPR: explicit consent needed. Mask all PII fields. Block sensitive elements (credit card, password, SSN). Respect user opt-out.

Privacy-by-design for session replay

Concern Risk Mitigation
Password fieldsKeystroke capture → credential theftBlock all type="password" by default
Credit card numbersPCi-DSS violation if recordedBlock input[data-sensitive], payment iframes
Personal data fieldsGDPR: recording email/address requires consentMask inputs: data-rr-block or className="rr-mask"
Sensitive UI contentAccount balance, health data shown in DOMdata-rr-block attribute hides element from replay
ConsentRecording without consent is illegal in GDPR jurisdictionsInitialize replay SDK only after consent granted

LogRocket / Sentry Replay setup with privacy masking

// ─── Sentry Replay (rrweb-based) ───
Sentry.init({
  integrations: [new Sentry.Replay({
    maskAllText:    false,  // only mask specific elements
    blockAllMedia:  false,  // keep images
    mask: ['.sensitive', '[data-private]'],
    block: ['input[type=password]', '.payment-field']
  })],
  replaysSessionSampleRate: 0.1,     // 10% of all sessions
  replaysOnErrorSampleRate: 1.0      // 100% when error occurs
});

// ─── LogRocket with privacy options ───
import LogRocket from 'logrocket';
LogRocket.init('org/app', {
  dom: {
    inputSanitizer: true,  // replaces all input values with ****
    textSanitizer:  true   // redacts all text nodes
  }
});

// Only initialize after GDPR consent:
consentService.onConsent('analytics', () => {
  LogRocket.init('org/app');
  LogRocket.identify(userId, { plan: userPlan });
});

// ─── HTML: mark elements to block from replay ───
<div data-rr-block>{account.balance}</div>
<input className="rr-mask" type="text" name="ssn" />
