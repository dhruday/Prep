Font loading — the invisible CLS and FCP blocker

Fonts are render-blocking. The browser must download a font before painting text that uses it. This causes FOIT (Flash of Invisible Text) or FOUT (Flash of Unstyled Text). A 300 KB Google Font delayed FCP by 1.2 s on a 3G connection. Self-hosting + subsetting + font-display:swap cut this to 80 ms at SAP.

font-display: block
Text invisible for up to 3s (FOIT). Full block period — bad for LCP/CLS.
font-display: swap
Fallback text shows immediately (FOUT). Swaps when custom font loads. Slight CLS if metrics differ.
font-display: optional
100ms window to use custom font; after that fallback is used permanently for that page load. Best for CLS but font may never show.

Best practice stack: Self-host WOFF2 + subset to Latin only + font-display: swap + <link rel="preload"> for above-fold fonts. Saves ~200 KB vs full Google Fonts download.

Font optimization patterns

/* ─── Self-hosted WOFF2 + subsetting ───*/
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-var.woff2') format('woff2');
  font-weight: 100 900;   /* variable font — single file */
  font-display: swap;       /* FOUT — fallback shows immediately */
  unicode-range: U+0000-00FF, U+0131; /* Latin subset only */
}

<!-- Preload above-fold font -->
<link rel="preload" as="font" type="font/woff2"
  href="/fonts/inter-var.woff2" crossorigin>

// ─── Next.js: Google Fonts via next/font ───
import { Inter } from 'next/font/google';
const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
  preload: true, // auto-preloads used subsets
});
// next/font downloads, self-hosts, and preloads automatically
// no Google request from user's browser — faster, more private

/* ─── Size-adjusted fallback (reduce CLS) ───*/
@font-face {
  font-family: 'FallbackArial';
  src: local('Arial');
  size-adjust: 107%;         /* match Inter metrics */
  ascent-override: 90%;
  descent-override: 22%;
}
