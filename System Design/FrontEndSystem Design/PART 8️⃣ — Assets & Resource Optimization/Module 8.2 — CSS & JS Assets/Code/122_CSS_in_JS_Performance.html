The CSS-in-JS performance tradeoff

CSS-in-JS libraries like styled-components or Emotion generate CSS at runtime: hash → serialize → inject into <style> tag. This work happens on the main thread during component render. At small scale: negligible. At scale: 1000 components × 0.1ms = 100ms of style recalculation on every re-render. This is why the React team's StyleX and CSS Modules exist — they eliminate runtime cost.

Runtime CSS-in-JS (styled-components, Emotion)
① Component renders
② Library hashes and serializes styles
③ Injects <style> element to <head>
④ Browser recalculates styles
⑤ Repeat on every prop change
= Runtime CPU + blocking
Static extraction (CSS Modules, Linaria, StyleX)
① Build tool extracts CSS at compile time
② Generates static .css file + class map
③ Component uses static className
④ Browser parses CSS once (cached)
⑤ Zero runtime style work
= Zero runtime CPU ✅

SSR problem — styled-components doubles JS work

Styled-components on SSR: (1) server serializes styles, injects <style> tag into HTML, (2) client hydrates, re-runs same serialization to match, (3) twice the style work per component. With RSCs + static extraction this goes to zero — styles are in the CSS bundle, not computed

Migration: styled-components → CSS Modules

// ❌ Before: styled-components — runtime serialization every render
const Button = styled.button<{ variant: 'primary' | 'ghost' }>`
  padding: 8px 16px;
  background: ${p => p.variant === 'primary' ? '#3b82f6' : 'transparent'};
  border-radius: 6px;
`;

// ✅ After: CSS Modules — zero runtime, static class lookup
/* Button.module.css */
.btn { padding: 8px 16px; border-radius: 6px; }
.primary { background: #3b82f6; color: white; }
.ghost { background: transparent; border: 1px solid #3b82f6; }

/* Button.tsx */
import styles from './Button.module.css';
const Button = ({ variant, children }: Props) => (
  <button className={`${styles.btn} ${styles[variant]}`}>{children}</button>
);

// ✅ Vanilla Extract — full TypeScript, static extraction
/* button.css.ts */
import { styleVariants, style } from '@vanilla-extract/css';
export const base = style({ padding: '8px 16px', borderRadius: '6px' });
export const variant = styleVariants({
  primary: { background: '#3b82f6' },
  ghost:   { background: 'transparent' },
});
