What is prototype pollution?

In JavaScript, every object inherits from Object.prototype. Prototype pollution is an attack where an attacker manipulates Object.prototype (or another shared prototype) by injecting malicious properties. Because ALL objects inherit these properties, every object in the application suddenly has attacker-injected properties — bypassing security checks that expect properties to be undefined.

Classic attack vector
// Attacker controls JSON input like: {"__proto__": {"isAdmin": true}}
// Deep merge function naively assigns properties:
function merge(target, source) {
  for (const key in source) {
    target[key] = source[key];  // ← "__proto__" key pollutes prototype
  }
}
merge({}, JSON.parse('{"__proto__": {"isAdmin": true}}'));

// NOW: every plain object in the app has isAdmin = true!
const user = {};
console.log(user.isAdmin);  // true ← ATTACK SUCCEEDED
Common vulnerable patterns
Object.assign() with untrusted input, recursive merge (lodash < 4.17.19), jQuery $.extend deep, express query string parsing, JSON.parse without validation
Consequences
Authorization bypass (isAdmin=true), RCE in Node.js (child_process.spawn options), app crashes, DoS, XSS via injected attributes

Safe object merge implementations 
// ❌ Vulnerable: naive recursive merge
function unsafeMerge(target: any, source: any) {
  Object.keys(source).forEach(key => {
    target[key] = source[key];  // __proto__ pollutes!!
  });
  return target;
}

// ✅ Fix 1: Check for dangerous keys
function safeMerge(target: Record<string, unknown>, source: Record<string, unknown>) {
  for (const key of Object.keys(source)) {
    if (key === '__proto__' || key === 'constructor' || key === 'prototype') continue;
    target[key] = source[key];
  }
  return target;
}

// ✅ Fix 2: Object.create(null) — no prototype to pollute
const safeObj = Object.create(null) as Record<string, unknown>;
// safeObj has NO prototype chain — __proto__ assignment does nothing

// ✅ Fix 3: structuredClone for deep copy without pollution risk
const safe = structuredClone(untrustedInput);

// ✅ Fix 4: Validate with Zod BEFORE merging
const UserSchema = z.object({
  name: z.string().max(100),
  email: z.string().email(),
  // __proto__ not in schema → stripped by z.strict()
}).strict();  // rejects any extra keys
const user = UserSchema.parse(body);  // throws if __proto__ present

// ✅ Fix 5: Object.freeze(Object.prototype) at app startup
Object.freeze(Object.prototype);  // prevents mutation at runtime
