# 402 – Researching Compensation Data — Levels.fyi, Glassdoor, Blind

────────────────────────────────────────────────────────────

## 1. ⚡ HIGH-LEVEL EXPLANATION
Research compensation BEFORE the interview. Use **Levels.fyi** (most accurate for FAANG), **Glassdoor**, **Blind** (anonymous verified), and **LinkedIn Salary**. Understand total compensation: base salary + bonus + RSU/ESOP + signing bonus. Know your target range and walk-away number.

## 2. 🔬 DEEP-DIVE EXPLANATION

### Compensation Research Sources
| Source | Strength | Use For |
|---|---|---|
| **Levels.fyi** | Verified, company-level-specific | FAANG/big tech comp bands |
| **Glassdoor** | Broad coverage, reviews | Base salary ranges |
| **Blind** | Anonymous verified tech workers | Negotiation stories, real offers |
| **LinkedIn Salary** | Industry averages | Market benchmarking |
| **Paysa/Comparably** | Role-specific | Startup compensation |

### Total Compensation Breakdown
```
┌──────────────────────────────────────────────────┐
│ TOTAL COMPENSATION (TC)                          │
├──────────────────────────────────────────────────┤
│ Base Salary    : Fixed monthly/annual pay         │
│ Bonus          : Annual performance bonus (10-20%)│
│ RSU/ESOP       : Stock vesting over 4 years       │
│ Signing Bonus  : One-time joining incentive        │
│ Relocation     : Moving allowance (if applicable)  │
│ Benefits       : Insurance, PF, food, transport    │
└──────────────────────────────────────────────────┘
```

### Frontend Engineer Compensation Ranges (India, 2024-25, Sr. Level)
```
Microsoft:  Base 25-45 LPA + RSU 15-30 LPA + Bonus 15%
Adobe:      Base 22-40 LPA + RSU 10-25 LPA + Bonus 10-15%
Salesforce: Base 25-42 LPA + RSU 12-28 LPA + Bonus 10%
Cisco:      Base 20-35 LPA + RSU 8-20 LPA + Bonus 10-15%
```
*Note: Ranges vary by level, location, and experience. Research current data before interviews.*

### How to Research for YOUR Target Role
```
1. Find the LEVEL (SDE-2, L5, IC3, etc.) on Levels.fyi
2. Filter by: role, location (India/Bangalore), experience
3. Note 25th, median, 75th percentile
4. Check Blind for recent offers in similar roles
5. Set YOUR range: target = 75th percentile, floor = median
```

## 3. 🎯 KEY TAKEAWAY
**"Know your number before the call. Research company-specific levels and bands. TC = base + bonus + stock. Your target should be 75th percentile; your floor is the median."**
