Interview STAR Answer

S — At SAP Labs, we had a procurement portal that served both a public product catalogue (SEO needed) and an authenticated order management dashboard (complex, real-time).

T — I needed to choose the right rendering strategy for each section: one size does not fit all.

A — I mapped each screen to its requirements:
  • Product catalogue → SSG + ISR (revalidate: 3600s). CDN-served, SEO-friendly, updated hourly.
  • Order dashboard → CSR (Next.js SPA mode). Auth-gated, no SEO needed, rich data tables.
  • Order detail page → SSR. Personalised per user, needed fresh inventory status.

I validated with Lighthouse: catalogue pages scored 97 (SSG CDN), dashboard TTI was 2.1s (CSR, JS-heavy) — acceptable given auth context.

R — LCP on catalogue improved from 3.4s (was CSR) to 0.8s (SSG/CDN). SEO organic traffic +35% in 3 months. Order dashboard retained its rich interactivity.
