RUM — performance as experienced by real users in production

RUM collects performance metrics directly from real users' browsers. Unlike Lighthouse (lab), RUM captures: actual device speeds, network conditions, geographic distribution, browser/OS diversity, and real user interaction patterns. Crucial insight: your p50 LCP may be 1.8s (good) but p90 may be 6s (poor) — slow-device users are invisible without RUM. SAP Fiori Elements uses Dynatrace RUM to track p75 Core Web Vitals per product per region.

What RUM measures
• Core Web Vitals (LCP, CLS, INP)
• Navigation/Resource timing
• JavaScript errors & unhandled rejections
• Long tasks (main thread jank)
• User session data (device, browser, country)
• Custom business metrics (time-to-interactive for key flows)
Percentile reporting (use p75, not average)
Average LCP 2.1s sounds good. But:
p50: 1.2s ✅
p75: 2.4s ⚠
p90: 5.8s ❌
p99: 14s ❌

p75 rule: 75% of users must pass the threshold. Google CrUX uses p75 for field data ranking.

RUM vs Synthetic monitoring comparison

Aspect RUM Synthetic
Data sourceReal browsers, real usersScripted runs in controlled env
When data arrivesContinuously (production)On-demand / scheduled (CI/CD)
Device varianceFull — all devices/networksSimulated throttling only
Privacy concernYes — user data, consent neededNone — no real users involved
Best useDetect production regressions, segment analysisPre-deploy checks, CI performance budgets

RUM beacon + sampling + session segmentation

// ─── RUM data collection with sampling ───
const SAMPLE_RATE = 0.1; // send only 10% of sessions
if (Math.random() < SAMPLE_RATE) {
  collectRUM();
}

function collectRUM() {
  const nav = performance.getEntriesByType('navigation')[0];
  const rumPayload = {
    ttfb:         nav.responseStart - nav.requestStart,
    domLoad:      nav.domContentLoadedEventEnd - nav.fetchStart,
    windowLoad:   nav.loadEventEnd - nav.fetchStart,
    url:          location.pathname,
    deviceType:   getDeviceType(),          // mobile|tablet|desktop
    connection:   (navigator as any).connection?.effectiveType,
    sessionId:    sessionStorage.getItem('sid'),
    timestamp:    Date.now()
  };
  navigator.sendBeacon('/api/rum', JSON.stringify(rumPayload));
}
