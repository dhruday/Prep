# 140. RUM (Real User Monitoring)

## 1. High-Level Explanation (Frontend Interview Level)

**Real User Monitoring (RUM)** is the practice of collecting performance, error, and behavioral data from actual end-users' browsers in production to understand real-world application experience across diverse devices, networks, and locations.

- **What**: Passive monitoring capturing Core Web Vitals, page load times, API latency, errors, user flows—from real users in production without synthetic tests
- **Why**: Understand actual user experience (not lab conditions), detect issues affecting specific segments (mobile, slow networks, regions), correlate performance with business metrics
- **When**: Essential for production apps, critical for understanding performance-revenue correlation, required for data-driven optimization
- **Role**: Foundation of user-centric performance strategy enabling targeted optimizations

**Key Principle**: "Lab data shows what's possible, RUM shows what's actual"—measure real user conditions for meaningful insights.

### RUM Data Collection

**1. Comprehensive RUM Agent**:
```typescript
interface RUMSession {
  // Session identification
  sessionId: string;
  userId?: string;
  anonymousId: string;
  
  // Device & browser
  userAgent: string;
  browser: { name: string; version: string };
  os: { name: string; version: string };
  device: { type: 'mobile' | 'tablet' | 'desktop'; vendor?: string };
  screen: { width: number; height: number };
  viewport: { width: number; height: number };
  
  // Network
  connection: {
    effectiveType?: '4g' | '3g' | '2g' | 'slow-2g';
    downlink?: number; // Mbps
    rtt?: number; // ms
    saveData?: boolean;
  };
  
  // Location
  geo: {
    country?: string;
    region?: string;
    city?: string;
    timezone: string;
  };
  
  // Session metadata
  startTime: number;
  referrer: string;
  landingPage: string;
  campaign?: {
    source?: string;
    medium?: string;
    campaign?: string;
  };
}

interface RUMPageView {
  sessionId: string;
  url: string;
  title: string;
  timestamp: number;
  
  // Navigation timing
  timing: {
    dns: number;
    tcp: number;
    ssl: number;
    ttfb: number;
    domLoad: number;
    loadComplete: number;
  };
  
  // Core Web Vitals
  vitals: {
    fcp?: number;
    lcp?: number;
    fid?: number;
    inp?: number;
    cls?: number;
    ttfb?: number;
  };
  
  // Custom metrics
  custom: {
    firstInteraction?: number;
    timeToCart?: number;
    timeToCheckout?: number;
  };
  
  // Resources
  resources: {
    count: number;
    totalSize: number;
    cacheHitRate: number;
    slowResources: Array<{ url: string; duration: number }>;
  };
}

class RUMAgent {
  private session: RUMSession;
  private pageViews: RUMPageView[] = [];
  private queue: any[] = [];
  
  constructor() {
    this.session = this.initializeSession();
    this.startTracking();
  }
  
  private initializeSession(): RUMSession {
    return {
      sessionId: this.getOrCreateSessionId(),
      userId: this.getUserId(),
      anonymousId: this.getAnonymousId(),
      
      userAgent: navigator.userAgent,
      browser: this.getBrowser(),
      os: this.getOS(),
      device: this.getDevice(),
      screen: {
        width: screen.width,
        height: screen.height
      },
      viewport: {
        width: window.innerWidth,
        height: window.innerHeight
      },
      
      connection: this.getConnection(),
      geo: this.getGeo(),
      
      startTime: Date.now(),
      referrer: document.referrer,
      landingPage: window.location.href,
      campaign: this.getCampaignParams()
    };
  }
  
  private startTracking() {
    // Track page views
    this.trackPageView();
    
    // Track navigation
    this.trackNavigation();
    
    // Track Web Vitals
    this.trackWebVitals();
    
    // Track user interactions
    this.trackInteractions();
    
    // Track errors
    this.trackErrors();
    
    // Periodic flush
    setInterval(() => this.flush(), 30000); // Every 30s
    
    // Flush on page hide
    document.addEventListener('visibilitychange', () => {
      if (document.hidden) {
        this.flush();
      }
    });
  }
  
  private trackPageView() {
    window.addEventListener('load', () => {
      const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
      
      const pageView: RUMPageView = {
        sessionId: this.session.sessionId,
        url: window.location.href,
        title: document.title,
        timestamp: Date.now(),
        
        timing: {
          dns: navigation.domainLookupEnd - navigation.domainLookupStart,
          tcp: navigation.connectEnd - navigation.connectStart,
          ssl: navigation.secureConnectionStart > 0 
            ? navigation.connectEnd - navigation.secureConnectionStart 
            : 0,
          ttfb: navigation.responseStart - navigation.requestStart,
          domLoad: navigation.domContentLoadedEventEnd - navigation.fetchStart,
          loadComplete: navigation.loadEventEnd - navigation.fetchStart
        },
        
        vitals: {},
        custom: {},
        
        resources: this.analyzeResources()
      };
      
      this.pageViews.push(pageView);
      this.queue.push({ type: 'pageview', data: pageView });
    });
  }
  
  private trackWebVitals() {
    import('web-vitals').then(({ onCLS, onFID, onLCP, onFCP, onTTFB, onINP }) => {
      const sendVital = (metric: any) => {
        const pageView = this.pageViews[this.pageViews.length - 1];
        
        if (pageView) {
          pageView.vitals[metric.name.toLowerCase() as keyof typeof pageView.vitals] = metric.value;
        }
        
        this.queue.push({
          type: 'web-vital',
          data: {
            sessionId: this.session.sessionId,
            metric: metric.name,
            value: metric.value,
            rating: metric.rating,
            navigationType: metric.navigationType,
            url: window.location.href,
            timestamp: Date.now()
          }
        });
      };
      
      onCLS(sendVital);
      onFID(sendVital);
      onLCP(sendVital);
      onFCP(sendVital);
      onTTFB(sendVital);
      onINP(sendVital);
    });
  }
  
  private trackInteractions() {
    let firstInteractionTime: number | null = null;
    
    const events = ['click', 'keydown', 'touchstart'];
    
    events.forEach(eventType => {
      document.addEventListener(eventType, (e) => {
        if (!firstInteractionTime) {
          firstInteractionTime = performance.now();
          
          const pageView = this.pageViews[this.pageViews.length - 1];
          if (pageView) {
            pageView.custom.firstInteraction = firstInteractionTime;
          }
        }
        
        // Track specific interactions
        if (eventType === 'click') {
          const target = e.target as HTMLElement;
          
          this.queue.push({
            type: 'interaction',
            data: {
              sessionId: this.session.sessionId,
              eventType,
              targetTag: target.tagName,
              targetId: target.id,
              targetClass: target.className,
              targetText: target.textContent?.slice(0, 100),
              url: window.location.href,
              timestamp: Date.now()
            }
          });
        }
      }, { once: eventType !== 'click', passive: true });
    });
  }
  
  private trackErrors() {
    window.addEventListener('error', (event) => {
      this.queue.push({
        type: 'error',
        data: {
          sessionId: this.session.sessionId,
          message: event.message,
          filename: event.filename,
          lineno: event.lineno,
          colno: event.colno,
          stack: event.error?.stack,
          url: window.location.href,
          timestamp: Date.now()
        }
      });
    });
    
    window.addEventListener('unhandledrejection', (event) => {
      this.queue.push({
        type: 'error',
        data: {
          sessionId: this.session.sessionId,
          message: String(event.reason),
          type: 'unhandled-rejection',
          url: window.location.href,
          timestamp: Date.now()
        }
      });
    });
  }
  
  private trackNavigation() {
    // Track SPA navigation
    const originalPushState = history.pushState;
    const originalReplaceState = history.replaceState;
    
    history.pushState = (...args) => {
      originalPushState.apply(history, args);
      this.onNavigate();
    };
    
    history.replaceState = (...args) => {
      originalReplaceState.apply(history, args);
      this.onNavigate();
    };
    
    window.addEventListener('popstate', () => this.onNavigate());
  }
  
  private onNavigate() {
    this.queue.push({
      type: 'navigation',
      data: {
        sessionId: this.session.sessionId,
        from: document.referrer || 'direct',
        to: window.location.href,
        timestamp: Date.now()
      }
    });
  }
  
  private analyzeResources() {
    const resources = performance.getEntriesByType('resource') as PerformanceResourceTiming[];
    
    let totalSize = 0;
    let cacheHits = 0;
    const slowResources: Array<{ url: string; duration: number }> = [];
    
    for (const resource of resources) {
      totalSize += resource.transferSize;
      
      // Check if cached
      if (resource.transferSize === 0 && resource.decodedBodySize > 0) {
        cacheHits++;
      }
      
      // Track slow resources
      if (resource.duration > 1000) {
        slowResources.push({
          url: resource.name,
          duration: resource.duration
        });
      }
    }
    
    return {
      count: resources.length,
      totalSize,
      cacheHitRate: resources.length > 0 ? cacheHits / resources.length : 0,
      slowResources: slowResources.slice(0, 10) // Top 10
    };
  }
  
  private async flush() {
    if (this.queue.length === 0) return;
    
    const data = [...this.queue];
    this.queue = [];
    
    const body = JSON.stringify({
      session: this.session,
      events: data
    });
    
    // Use sendBeacon for reliability
    if (navigator.sendBeacon) {
      navigator.sendBeacon('/api/rum', body);
    } else {
      fetch('/api/rum', {
        method: 'POST',
        body,
        keepalive: true,
        headers: { 'Content-Type': 'application/json' }
      }).catch(err => console.error('RUM flush failed:', err));
    }
  }
  
  // Helper methods
  private getOrCreateSessionId(): string {
    let sessionId = sessionStorage.getItem('rum_session_id');
    
    if (!sessionId) {
      sessionId = `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
      sessionStorage.setItem('rum_session_id', sessionId);
    }
    
    return sessionId;
  }
  
  private getAnonymousId(): string {
    let anonId = localStorage.getItem('rum_anonymous_id');
    
    if (!anonId) {
      anonId = `${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
      localStorage.setItem('rum_anonymous_id', anonId);
    }
    
    return anonId;
  }
  
  private getUserId(): string | undefined {
    return window.__USER_ID__;
  }
  
  private getBrowser() {
    const ua = navigator.userAgent;
    if (/Chrome/i.test(ua)) return { name: 'Chrome', version: this.extractVersion(ua, /Chrome\/(\d+)/) };
    if (/Firefox/i.test(ua)) return { name: 'Firefox', version: this.extractVersion(ua, /Firefox\/(\d+)/) };
    if (/Safari/i.test(ua) && !/Chrome/i.test(ua)) return { name: 'Safari', version: this.extractVersion(ua, /Version\/(\d+)/) };
    if (/Edge/i.test(ua)) return { name: 'Edge', version: this.extractVersion(ua, /Edge\/(\d+)/) };
    return { name: 'Unknown', version: '0' };
  }
  
  private getOS() {
    const ua = navigator.userAgent;
    if (/Windows/i.test(ua)) return { name: 'Windows', version: this.extractVersion(ua, /Windows NT (\d+\.\d+)/) };
    if (/Mac/i.test(ua)) return { name: 'macOS', version: this.extractVersion(ua, /Mac OS X (\d+[._]\d+)/) };
    if (/Linux/i.test(ua)) return { name: 'Linux', version: '' };
    if (/Android/i.test(ua)) return { name: 'Android', version: this.extractVersion(ua, /Android (\d+)/) };
    if (/iOS/i.test(ua)) return { name: 'iOS', version: this.extractVersion(ua, /OS (\d+)/) };
    return { name: 'Unknown', version: '' };
  }
  
  private getDevice(): { type: 'mobile' | 'tablet' | 'desktop'; vendor?: string } {
    const ua = navigator.userAgent;
    
    if (/Mobile|Android|iPhone/i.test(ua)) {
      return { type: 'mobile', vendor: this.extractVendor(ua) };
    }
    
    if (/iPad|Tablet/i.test(ua)) {
      return { type: 'tablet', vendor: this.extractVendor(ua) };
    }
    
    return { type: 'desktop' };
  }
  
  private getConnection() {
    const connection = (navigator as any).connection || (navigator as any).mozConnection || (navigator as any).webkitConnection;
    
    if (!connection) return {};
    
    return {
      effectiveType: connection.effectiveType,
      downlink: connection.downlink,
      rtt: connection.rtt,
      saveData: connection.saveData
    };
  }
  
  private getGeo() {
    // Populated server-side from IP
    return {
      timezone: Intl.DateTimeFormat().resolvedOptions().timeZone
    };
  }
  
  private getCampaignParams() {
    const params = new URLSearchParams(window.location.search);
    
    return {
      source: params.get('utm_source') || undefined,
      medium: params.get('utm_medium') || undefined,
      campaign: params.get('utm_campaign') || undefined
    };
  }
  
  private extractVersion(ua: string, pattern: RegExp): string {
    const match = ua.match(pattern);
    return match ? match[1] : '0';
  }
  
  private extractVendor(ua: string): string | undefined {
    if (/iPhone|iPad/.test(ua)) return 'Apple';
    if (/Samsung/.test(ua)) return 'Samsung';
    if (/Pixel/.test(ua)) return 'Google';
    return undefined;
  }
}

// Initialize RUM
export const rumAgent = new RUMAgent();
```

```typescript
// Aggregate RUM data for insights
interface RUMInsights {
  // Performance by segment
  performanceByDevice: Record<'mobile' | 'tablet' | 'desktop', {
    lcp: { p50: number; p75: number; p95: number };
    fid: { p50: number; p75: number; p95: number };
    cls: { p50: number; p75: number; p95: number };
    ttfb: { p50: number; p75: number; p95: number };
  }>;
  
  performanceByConnection: Record<string, any>;
  performanceByCountry: Record<string, any>;
  performanceByBrowser: Record<string, any>;
  
  // User experience score
  apdex: number; // Application Performance Index
  
  // Business impact
  bounceRateByLoadTime: Array<{ loadTime: number; bounceRate: number }>;
  conversionRateByLoadTime: Array<{ loadTime: number; conversionRate: number }>;
}

// Calculate Apdex (0-1 score)
function calculateApdex(responseTimes: number[], satisfactory: number = 2000, tolerable: number = 8000): number {
  let satisfied = 0;
  let tolerating = 0;
  
  for (const time of responseTimes) {
    if (time <= satisfactory) {
      satisfied++;
    } else if (time <= tolerable) {
      tolerating++;
    }
  }
  
  return (satisfied + (tolerating / 2)) / responseTimes.length;
}
```

### What NOT to Do

- ❌ **Track PII without consent** (GDPR violations)
- ❌ **No sampling** (expensive, unnecessary for all users)
- ❌ **Ignore privacy** (don't track incognito/private mode)
- ❌ **Only track desktop** (mobile users often have worse experience)
- ❌ **No actionable insights** (data without analysis is useless)

## 4. Interview-Oriented Explanation

### Sample Answer (7+ Years Level)

> **Question**: "How would you implement RUM for a global e-commerce site?"

**Answer**:

"I'd implement **comprehensive RUM** tracking real user experience:

**1. Data Collection**:

Capture on every page load:
- **Performance**: Core Web Vitals (LCP, FID, CLS), TTFB, DOM load
- **Device**: Browser, OS, screen size, viewport
- **Network**: Connection type (4G/3G), downlink speed
- **Location**: Country, region (from IP server-side)
- **Session**: Session ID, user ID (if authenticated)

**2. Sampling**:

100% Web Vitals (lightweight), 10% detailed resource timing (cost). Sample by session, not by page (consistent experience).

**3. Segmentation**:

Analyze performance by:
- **Device**: Mobile vs desktop (mobile 2-3x slower)
- **Connection**: 4G vs 3G vs 2G
- **Country**: US vs India vs Brazil (different infra)
- **Browser**: Chrome vs Safari vs Firefox

**4. Business Correlation**:

Correlate speed with business metrics:
```
Fast load (< 2s) → 5% conversion
Slow load (> 5s) → 2% conversion
```

Prioritize optimizing slow segments with high traffic.

**5. Alerting**:

Alert if P75 LCP > 3s for 15 minutes (sustained degradation). Different thresholds by segment (mobile allowed higher).

**6. Privacy**:

GDPR compliant:
- Anonymous ID for non-authenticated users
- No PII in events
- Cookie consent before tracking
- Data retention: 90 days

**7. Integration**:

Use **Datadog RUM** or **Google Analytics 4**:
- Automatic Web Vitals tracking
- Session replay (20% sample)
- Error correlation

**8. Custom Metrics**:

Track business-specific timings:
```typescript
rumAgent.addTiming('first_product_visible');
rumAgent.addTiming('add_to_cart_interaction');
```

**9. Analysis**:

Weekly reports:
- P50/P75/P95 by page, device, country
- Slowest pages (priority for optimization)
- Revenue impact of performance

**Real-World**: Amazon saw 100ms faster = 1% revenue increase. Walmart found 1s improvement = 2% conversion lift. RUM validates optimizations with real user data."

## 6. Why & How Summary

### Why It Matters

**Real Conditions**: Lab data != real users (device, network, location vary)  
**Business Impact**: Correlate speed with conversion, revenue  
**Segmentation**: Optimize for worst-performing segments

### How It Works

**1. Capture**: Web Vitals, timing, device, network from real users  
**2. Batch**: Queue events, flush every 30s or on page hide  
**3. Segment**: Group by device, connection, country  
**4. Analyze**: P75/P95, correlate with business metrics  
**5. Alert**: Sustained degradation triggers investigation

**FAANG**: 100% Web Vitals sampling, segment by device/network/geo, correlate with revenue, < 5 min detection
