Frontend scales differently from backend — network, CDN, and browser are your infrastructure

When serving millions of users, a single server is never the bottleneck — your frontend is. Key levers: (1) CDN distribution near every user, (2) static asset delivery (no server compute), (3) lazy loading so each user only downloads what they see, (4) edge rendering for personalized pages without origin hits. SAP's Fiori Launchpad serves 300K+ enterprise users globally — it uses content delivery networks and aggressively caches the shell.

// ─── Cloudflare Workers edge personalization ───
export default {
  async fetch(req: Request): Promise<Response> {
    const country = req.cf?.country ?? 'US';
    const cached = await caches.default.match(`${req.url}:${country}`);
    if (cached) return cached;
    const res = await fetch(req); // origin hit only on cache miss
    caches.default.put(`${req.url}:${country}`, res.clone());
    return res;
  }
};
