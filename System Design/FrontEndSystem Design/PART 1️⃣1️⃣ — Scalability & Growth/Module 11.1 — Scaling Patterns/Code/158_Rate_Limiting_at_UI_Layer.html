UI-layer rate limiting — protecting APIs from the frontend

UI-layer rate limiting isn't a security control (server must enforce that) — it's a UX and infrastructure optimization. Limiting how often the UI fires API calls for search-as-you-type, scroll-based loading, resize events, and window focus reduces server load, prevents API quota exhaustion, and improves user experience. The three core patterns: debounce, throttle, and request deduplication.

Debounce
Wait N ms after LAST call before executing. Search: fire only after user stops typing for 300ms. Eliminates all intermediate keypresses.
Throttle
Execute at most once per N ms, regardless of call frequency. Scroll handler: fire max once/100ms. Guarantees periodic execution.
Request deduplication
If identical request in-flight, return same Promise. Multiple components mounting simultaneously don't each trigger separate API calls. React Query does this automatically.

Debounce + AbortController for search

// Typed debounce + AbortController (cancel stale requests)
function debounce<T extends (...args: any[]) => any>(fn: T, ms: number): T {
  let timer: ReturnType<typeof setTimeout>;
  return ((...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  }) as T;
}

// React hook: debounced search with cancellation
function useSearch(query: string) {
  const [results, setResults] = useState<Result[]>([]);
  
  useEffect(() => {
    if (!query.trim()) { setResults([]); return; }
    
    const controller = new AbortController();
    const timer = setTimeout(async () => {
      try {
        const data = await searchAPI(query, controller.signal);
        setResults(data);
      } catch (e) {
        if (e.name !== 'AbortError') console.error(e);
      }
    }, 300);
    
    return () => { clearTimeout(timer); controller.abort(); };
  }, [query]);
  
  return results;
}

// Throttle for scroll handler
const handleScroll = throttle(() => {
  if (window.scrollY + window.innerHeight >= document.body.scrollHeight - 200) {
    loadNextPage();
  }
}, 100);
window.addEventListener('scroll', handleScroll, { passive: true });
