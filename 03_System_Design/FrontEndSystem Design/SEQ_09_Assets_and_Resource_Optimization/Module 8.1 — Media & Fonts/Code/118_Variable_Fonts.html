Code Patterns

One file. Infinite styles. Traditional vs Variable fonts.

Traditional fonts: every weight (Regular, Bold, Italic, Bold Italic, SemiLight...) is a separate .woff2 file — each ~20-80KB. A site using 5 weights = 5 network requests + ~200KB. Variable fonts encode the entire design space (weight axis, width axis, slant axis) in a single file using interpolation. One file covers ALL weights interpolated along continuous axes.

Traditional fonts
Inter-Thin.woff2 → 24KB
Inter-Regular.woff2 → 28KB
Inter-Medium.woff2 → 28KB
Inter-Bold.woff2 → 29KB
Inter-ExtraBold.woff2 → 29KB
Total: 138KB + 5 requests
Variable font
Inter-Variable.woff2
→ ALL weights 100–900
→ ALL widths (if supported)
→ Smooth animation between values
Total: 95KB + 1 request 🎉

Axes — what can vary

wght
Weight 100–900. Most common axis.
wdth
Width — condensed to expanded.
slnt
Slant (synthetic italics).
ital
True italic (0 or 1).
opsz
Optical size for small/large text.
custom
Font-specific (e.g., "casual" 0–1).

Variable font loading with subset + preload

/* @font-face with variable font axes range */
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-var.woff2') format('woff2-variations'),
       url('/fonts/inter-var.woff')  format('woff-variations');
  font-weight: 100 900;        /* range for variable */
  font-style: normal;
  font-display: swap;
  unicode-range: U+0000-00FF;  /* Latin subset only */
}

/* CSS custom axes */
.heading {
  font-variation-settings: 'wght' 650, 'wdth' 110;
  /* Fallback for browsers without variable font support */
  font-weight: 700;
}

/* Animated weight on hover — only possible with variable fonts */
.hero-title {
  font-variation-settings: 'wght' 300;
  transition: font-variation-settings 0.3s ease;
}
.hero-title:hover {
  font-variation-settings: 'wght' 800;
}

<!-- HTML preload hint — critical path font -->
<link rel="preload" as="font" type="font/woff2"
  href="/fonts/inter-var.woff2" crossorigin>
