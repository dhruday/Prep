Supported Entry Types

// Entry types available via PerformanceObserver:
// 'paint'                    → FP, FCP
// 'largest-contentful-paint'  → LCP candidates
// 'layout-shift'             → CLS entries
// 'longtask'                 → Tasks > 50ms
// 'event'                    → Interaction timing (INP)
// 'resource'                 → Fetch, script, image loads
// 'navigation'               → Page navigation timing
// 'mark'                     → Custom performance.mark()
// 'measure'                  → Custom performance.measure()
// 'first-input'              → FID (deprecated by INP)
