What is layout thrashing (forced synchronous layout)?

The browser batches DOM writes and performs layout once per frame. A forced synchronous layout happens when you read a layout property (offsetWidth, clientHeight, getBoundingClientRect) immediately after writing a style — forcing the browser to flush its pending style/layout queue to guarantee an accurate measurement. In a loop, this means layout is recalculated per iteration — "thrashing".

Thrashing pattern (bad) 
for (const el of elements) {
  el.style.width = '100px';   // WRITE
  const h = el.offsetHeight; // READ — forced relayout!
  el.style.height = h + 'px'; // WRITE again
}
// 100 elements = 100 forced layouts
Batched pattern (good) 
// READ phase first
const heights = elements.map(el => el.offsetHeight);
// WRITE phase after all reads
elements.forEach((el, i) => {
  el.style.width = '100px';
  el.style.height = heights[i] + 'px';
});
// 1 layout, 1 paint — regardless of element count

Properties that trigger layout (read with caution)

Layout-triggering reads
  • offsetTop / offsetLeft / offsetWidth / offsetHeight
  • clientTop / clientLeft / clientWidth / clientHeight
  • scrollTop / scrollLeft / scrollWidth / scrollHeight
  • getBoundingClientRect()
  • getComputedStyle()
  • innerWidth / innerHeight (window)
Alternatives that don't force layout
  • ResizeObserver (batched, async)
  • IntersectionObserver (async)
  • CSS custom properties for measurements
  • transform instead of left/top
  • contain: layout on heavy subtrees
  • will-change: transform on animated elements

Chrome DevTools: In the Performance panel, forced synchronous layouts appear as purple warning bars labeled "Forced reflow". Filter for "Layout" in the flame chart.

Batch reads/writes with FastDOM pattern

// ─── Read / write batching utility ───
type Job = () => void;
const reads: Job[] = [], writes: Job[] = [];
let scheduled = false;

function flush() {
  reads.splice(0).forEach(r => r());  // all reads → 1 layout
  writes.splice(0).forEach(w => w()); // all writes → 1 paint
  scheduled = false;
}
function scheduleRead(fn: Job)  { reads.push(fn);  if(!scheduled){ scheduled=true; requestAnimationFrame(flush); } }
function scheduleWrite(fn: Job) { writes.push(fn); if(!scheduled){ scheduled=true; requestAnimationFrame(flush); } }

// ─── ResizeObserver (no forced layout) ───
const ro = new ResizeObserver((entries) => {
  // batched, async — never causes forced layout
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    onResize(entry.target, width, height);
  }
});
ro.observe(container);

// ─── CSS containment (reduce layout scope) ───
/* Tells browser: layout changes inside this element */
/* cannot affect elements outside it */
.order-table {
  contain: layout style;   /* scoped layout */
  will-change: transform;  /* hint GPU layer */
}
