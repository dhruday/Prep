What is DOM-Based XSS?

DOM-based XSS occurs entirely in the client-side JavaScript. The payload never reaches the server — instead, JavaScript reads user input from sources (URL hash, query params, document.referrer) and writes it to sinks (innerHTML, document.write, eval) without sanitization.

🔬 V8 & DOM Parser Behavior

innerHTML assignment: When you set innerHTML, the browser invokes the HTML fragment parsing algorithm. This creates a new DocumentFragment, parses the HTML, and replaces the element's children. <script> tags in fragments are NOT executed (per HTML5 spec), but <img onerror>, <svg onload>, and other event handlers ARE.

textContent assignment: This creates a single Text node. No parsing occurs — the browser treats the string as literal text. Even valid HTML becomes visible text on screen.

document.write(): Invokes the HTML parser directly. Unlike innerHTML, <script> tags inserted via document.write() ARE executed because they go through the main parser, not the fragment parser.

Why <script> via innerHTML doesn't execute: The HTML5 spec (§8.4) explicitly states that script elements inserted via innerHTML must not be executed. This is a security mitigation — but it's NOT sufficient because event handlers still work.

Google Senior Frontend — DOM XSS Questions

Q: How would you detect DOM-based XSS in a large codebase?

Static analysis: ESLint rules (no-innerHTML, no-document-write). Grep for dangerous sinks: innerHTML, outerHTML, document.write, eval, document.querySelector().src. Dynamic: use Chrome's Trusted Types (enforcement mode) to catch all sink violations at runtime. At Google, Trusted Types are deployed as a CSP directive: require-trusted-types-for 'script'.

Q: What are Trusted Types and how do they prevent DOM XSS?

Trusted Types is a browser API that prevents strings from being assigned to DOM sinks. You must create a policy that wraps strings into typed objects (TrustedHTML, TrustedScript, TrustedScriptURL). If any code tries to assign a raw string to innerHTML, the browser throws an error. Google originated this spec and uses it across Google Search, YouTube, etc.
