Principles of secure API consumption from the frontend

Calling APIs from the browser exposes you to token leakage, response injection, broken object-level auth, rate limit abuse, and more. SAP APIs in BTP are consumed via destination services — tokens are managed server-side, never in the browser.

🔑 Auth headers
Always use Authorization: Bearer, never pass tokens in URL params (?token=...) — they end up in logs and history
✅ Response validation
Validate response structure before rendering. Don't trust API shape blindly — attackers can swap data in MITM or compromised CDNs
⚡ Rate limiting (client)
Debounce/throttle user-triggered calls. Use exponential back-off for retries. Honor 429 Retry-After headers
🧱 BFF proxy
Backend-for-frontend keeps secrets (API keys) server-side; browser only calls your own /api/* endpoints, not third-party directly
🚫 No API keys in browser
Never place API keys in .env (REACT_APP_*) that ship to browser bundle — they are public. Use server-side proxy instead
🔏 HTTPS only
Enforce HTTPS. Use SRI for embedded scripts. Do not make mixed-content HTTP calls from HTTPS pages

Secure Axios instance + BFF proxy + response validation

// ─── Secure Axios instance (frontend) ───
const api = axios.create({
  baseURL: '/api',             // BFF proxy — never direct third-party
  withCredentials: true,       // send HttpOnly cookie with every request
  timeout: 10_000
});

// Never put auth in URL — use header interceptor
api.interceptors.request.use(cfg => {
  const t = tokenStore.get();
  if (t) cfg.headers['Authorization'] = `Bearer ${t}`;
  return cfg;
});

// ─── Response validation with Zod ───
import { z } from 'zod';

const OrderSchema = z.object({
  id: z.string().uuid(),
  total: z.number().positive(),
  status: z.enum(['pending', 'paid', 'shipped'])
});

async function getOrder(id: string) {
  const { data } = await api.get(`/orders/${encodeURIComponent(id)}`);
  return OrderSchema.parse(data); // throws if shape is wrong
}

// ─── BFF proxy (Next.js API route) ───
// pages/api/orders/[id].ts
export default async function handler(req, res) {
  const token = await getServerSideToken(req); // from HttpOnly cookie
  const upstream = await fetch(
    `${process.env.INTERNAL_API}/orders/${req.query.id}`,
    { headers: { Authorization: `Bearer ${token}`,
                 'X-API-Key': process.env.API_KEY } } // key stays on server
  );
  const data = await upstream.json();
  res.json(data);
}
