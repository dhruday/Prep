Security headers — cheap wins that eliminate entire attack classes

HTTP response headers instruct the browser on how to handle content. Missing or misconfigured headers are consistently found in OWASP Top 10 audits. Setting them costs nearly nothing but closes off XSS, MIME sniffing, clickjacking, HSTS stripping, and more. At SAP, all cloud services must pass secureHeaders scan before production deployment.

HSTS
Forces HTTPS even on first visit. Prevents SSL stripping attacks by MitM.
X-Content-Type-Options
nosniff — prevents browser guessing content-type (stops some XSS via image/text with embedded script)
Referrer-Policy
Controls how much URL is sent in Referer to third parties. Protect sensitive URL params (e.g. IDs in path)
Permissions-Policy
Restricts browser features (camera, geolocation, payment) third-party iframes can request.
X-Frame-Options
DENY / SAMEORIGIN — clickjacking defence. Superseded by CSP frame-ancestors but still useful for IE.
Cache-Control
Sensitive pages: no-store to prevent caching of auth'd responses in proxies, shared caches, and CDNs.

Next.js headers config + Helmet.js for Express

// ─── Next.js: next.config.js ───
const securityHeaders = [
  { key: 'Strict-Transport-Security',
    value: 'max-age=63072000; includeSubDomains; preload' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  { key: 'Permissions-Policy',
    value: 'camera=(), microphone=(), geolocation=()' },
  { key: 'Content-Security-Policy',
    value: "default-src 'self'; script-src 'self'; frame-ancestors 'none'" }
];

module.exports = {
  async headers() {
    return [{ source: '/(.*)', headers: securityHeaders }];
  }
};

// ─── Express / Node.js: Helmet.js ───
import helmet from 'helmet';
app.use(helmet({
  hsts: { maxAge: 63072000, includeSubDomains: true, preload: true },
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'"],
      frameAncestors: ["'none'"]
    }
  },
  referrerPolicy: { policy: 'strict-origin-when-cross-origin' }
}));

// ─── Auth page: no-store cache ───
res.setHeader('Cache-Control', 'no-store, no-cache, must-revalidate');
res.setHeader('Pragma', 'no-cache');
res.setHeader('Expires', '0');
