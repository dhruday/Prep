JWT anatomy

A JWT is 3 base64url-encoded parts separated by dots. It is signed (tamper-proof) but NOT encrypted — anyone can read the payload.

PropertyHS256 (HMAC)RS256 (RSA)
Key typeShared secretPublic/private key pair
SignShared keyPrivate key (auth server only)
VerifyShared keyPublic key (any service)
Token forgery riskAny service with key can forgeOnly auth server can forge

Key rotationAll services need new keyPublish new public key via JWKS endpoint
JWKS endpoint pattern
Auth server exposes: GET /.well-known/jwks.json
API services fetch public keys at startup and cache them. When auth server rotates keys (new private key), services re-fetch from JWKS — zero downtime rotation.

Silent refresh with concurrent request queue

// accessToken lives ONLY in memory — cleared on page close
let accessToken: string | null = null;
let refreshing = false;
let queue: Array<{resolve:Function; reject:Function}> = [];

axiosInstance.interceptors.response.use(
  r => r,
  async (err: AxiosError) => {
    const req = err.config as AxiosRequestConfig & {_retry?: boolean};
    if (err.response?.status !== 401 || req._retry) return Promise.reject(err);

    if (refreshing) {
      // Queue concurrent requests while refresh in-flight
      return new Promise((resolve, reject) => queue.push({resolve, reject}))
        .then(token => {
          req.headers!['Authorization'] = `Bearer ${token}`;
          return axiosInstance(req);
        });
    }

    req._retry = true; refreshing = true;
    try {
      const { data } = await axiosInstance.post('/auth/refresh');
      accessToken = data.accessToken;
      axiosInstance.defaults.headers.common['Authorization'] = `Bearer ${accessToken}`;
      queue.forEach(p => p.resolve(accessToken));
      return axiosInstance(req);
    } catch {
      queue.forEach(p => p.reject('Session expired'));
      logout();
      return Promise.reject('Session expired');
    } finally {
      refreshing = false; queue = [];
    }
  }
);
