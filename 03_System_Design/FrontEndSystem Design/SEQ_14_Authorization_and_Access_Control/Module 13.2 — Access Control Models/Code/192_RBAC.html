Why RBAC scales
Manage 20 roles vs 50,000 users. Role change propagates to all members instantly. Compliance audits check roles, not per-user permissions.
RBAC limits
Can't express "edit only your own records" or "access only your department's data" — those need ABAC predicates.

When you see roles like editor-europe, editor-usa, editor-apac — you're fighting RBAC. Switch to scoped RBAC or ABAC for the regional dimension instead.

Hierarchical RBAC in TypeScript

type Permission = `${string}:${string}`;

const ROLES: Record<string, {perms:Permission[];inherits?:string}> = {
  viewer:  { perms: ['document:read', 'user:read'] },
  editor:  { perms: ['document:write', 'document:publish'], inherits: 'viewer' },
  admin:   { perms: ['user:invite', 'user:delete'], inherits: 'editor' },
  billing: { perms: ['billing:manage'], inherits: 'viewer' },
};

function resolve(role: string, seen = new Set<string>()): Set<Permission> {
  if (seen.has(role)) return new Set();
  seen.add(role);
  const r = ROLES[role];
  const perms = new Set<Permission>(r.perms);
  if (r.inherits) resolve(r.inherits, seen).forEach(p => perms.add(p));
  return perms;
}

// admin inherits editor → viewer: resolve('admin') has ALL permissions
// billing inherits viewer only: no document:write
