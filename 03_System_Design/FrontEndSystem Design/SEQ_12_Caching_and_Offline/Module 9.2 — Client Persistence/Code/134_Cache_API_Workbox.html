Service Worker Cache API — your own programmable HTTP cache

The Cache API (window.caches / self.caches in SW) is a programmatic key-value store for Request→Response pairs. Unlike HTTP cache which is controlled by headers and managed by the browser, you write JavaScript to intercept every fetch, check the cache, decide what to return, update the cache, and handle offline scenarios. Workbox is Google's library that wraps Cache API with tested, named strategy implementations.

CacheOnly
Serve from cache, never network. For: precached app shell. Fails if not precached.
NetworkOnly
Always network. For: auth endpoints, payment, POST requests. Fails offline.
CacheFirst
Cache → network on MISS. For: static assets with long TTL. Fast but stale risk.
NetworkFirst
Network → cache on failure. For: APIs, HTML pages. Fresh when online, offline fallback.
StaleWhileRevalidate
Cache immediately + update in background. For: user avatars, non-critical data. Always fast, eventually fresh.
Precaching
Download app shell on SW install. Core files always offline. Workbox injectManifest wires this automatically.

Workbox v7 configuration (vite-plugin-pwa)

// vite.config.ts — using vite-plugin-pwa with Workbox
import { VitePWA } from 'vite-plugin-pwa';
export default {
  plugins: [VitePWA({
    strategies: 'injectManifest',
    srcDir: 'src', filename: 'sw.ts',
    workbox: {
      globPatterns: ['**/*.{js,css,html,woff2}'],
      runtimeCaching: [
        {
          urlPattern: /^https:\/\/api\.example\.com\/products/,
          handler: 'NetworkFirst',
          options: {
            cacheName: 'api-products',
            expiration: { maxEntries: 50, maxAgeSeconds: 300 },
            networkTimeoutSeconds: 3,  // fall to cache after 3s
          }
        },
        {
          urlPattern: /\.(png|jpg|avif|webp)$/,
          handler: 'CacheFirst',
          options: {
            cacheName: 'images',
            expiration: { maxEntries: 200, maxAgeSeconds: 86400 * 30 }
          }
        },
      ]
    }
  })]
};

// sw.ts — manual Cache API example (no framework)
const CACHE = 'app-v2';
self.addEventListener('fetch', (e: FetchEvent) => {
  if (e.request.method !== 'GET') return;  // never cache POST
  e.respondWith(
    caches.open(CACHE).then(async cache => {
      const cached = await cache.match(e.request);
      const netPromise = fetch(e.request).then(res => {
        cache.put(e.request, res.clone());
        return res;
      });
      return cached || netPromise;  // CacheFirst pattern
    })
  );
});
