Service Worker — the programmable network proxy

A Service Worker is a JS script running in a separate background thread, acting as a programmable proxy between the page and the network. It intercepts all fetch requests, enables offline support, background sync, and push notifications. SAP Fiori Launchpad uses a Service Worker to pre-cache the app shell → 0 ms loads on repeat visits.

What service workers can do
  • 🔌 Intercept all fetch requests (fetch event)
  • 💾 Cache responses (CacheStorage API)
  • 📴 Serve content when offline
  • 🔄 Background sync (sync event)
  • 🔔 Push notifications (push event)
Constraints
  • ❌ No DOM access (separate thread)
  • 🔒 HTTPS only (or localhost)
  • 🌐 Same-origin as the page
  • 💤 Terminated when idle — no persistent state
  • 📦 Scope limited to containing directory

Service Worker lifecycle — step through registration → activation

1. navigator.serviceWorker.register('/sw.js')
2. SW downloaded + parsed → state: 'installing'
3. install event fires → cache shell assets in waitUntil()
4. State: 'installed' — waiting for old SW to release clients
5. activate event fires → delete old caches
6. State: 'activated' → intercepts fetch events on all pages

Five caching strategies — when to use each

Cache First — serve from cache if available; fetch if miss. Best for: static assets (JS, CSS, images). Fastest but stale.
Network First — try network; fallback to cache. Best for: API data where freshness matters. Fresh but slow offline.
Stale While Revalidate — serve cache immediately AND fetch in background to update cache for next request. Best for: non-critical data (news feeds, infrequently updated lists). Fast + eventually fresh.
Cache Only — only serve from cache; never fetch. For fully offline capabilities after pre-caching.
Network Only — bypass cache entirely. For analytics, POST mutations, real-time data.

Service Worker patterns (Workbox + manual)

// ─── Workbox (recommended for production) ───
import { precacheAndRoute, cleanupOutdatedCaches } from 'workbox-precaching';
import { registerRoute } from 'workbox-routing';
import { StaleWhileRevalidate, CacheFirst, NetworkFirst } from 'workbox-strategies';
import { ExpirationPlugin } from 'workbox-expiration';

precacheAndRoute(self.__WB_MANIFEST);  // pre-cache app shell
cleanupOutdatedCaches();

// Images: cache first, expire after 30 days
registerRoute(
  ({ request }) => request.destination === 'image',
  new CacheFirst({ cacheName: 'images', plugins: [new ExpirationPlugin({ maxAgeSeconds: 30*86400 })] })
);

// API: stale while revalidate
registerRoute(
  ({ url }) => url.pathname.startsWith('/api/'),
  new StaleWhileRevalidate({ cacheName: 'api-cache' })
);

// ─── Manual registration in main app ───
if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('/sw.js', { scope: '/' })
      .then(reg => console.log('SW registered', reg.scope));
  });
}
