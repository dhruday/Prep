Cache poisoning: tricking caches into storing malicious responses

Cache poisoning is an attack where an attacker manipulates a cache (CDN, shared proxy, browser) to store a malicious or incorrect response that is then served to other users. It's classified in the OWASP Top 10 under both Injection and Security Misconfiguration. A poisoned CDN edge can serve malicious JS to millions of users until the cache TTL expires.

Vectors that enable poisoning:
  • 🎯 Unkeyed request headers reflected in response (X-Forwarded-Host, X-Forwarded-Scheme)
  • 🔍 Unkeyed query params reflected in body/headers but cached as same key
  • 🍪 Cookie values reflected in responses cached by CDN
  • 🔗 HTTP request smuggling feeding poisoned response into cache

Detecting cache poisoning

Detection techniques
  • 1. Add Pragma: x-get-cache-info header to see if CDN is caching
  • 2. Use distinct param?cachebuster=1 values to test reflection
  • 3. Check Age response header — if >0, cached on CDN
  • 4. Tools: Param Miner (Burp), web-cache-vulnerability-scanner
  • 5. Add non-existent headers — does the response reflect them?
Red flags to audit:
  • ⚠️ App reflects X-Forwarded-Host in <script src> or <link href>
  • ⚠️ Query param like ?utm_source=evil reflected in body but NOT in cache key
  • ⚠️ Response includes Vary header not listing reflected headers
  • ⚠️ Missing Vary: Origin on CORS responses

Secure cache configuration patterns

// ─── Never reflect unvalidated headers ───
// BAD — reflects X-Forwarded-Host in response
app.get('/', (req, res) => {
  const host = req.headers['x-forwarded-host'] || req.hostname;
  res.send(`<script src="https://${host}/app.js"></script>`); // POISONABLE!
});

// GOOD — use fixed, trusted base URL
const ASSET_BASE = process.env.ASSET_BASE_URL; // https://static.sap.com
app.get('/', (req, res) => {
  res.send(`<script src="${ASSET_BASE}/app.js"></script>`);
});

// ─── Vary header covers reflected headers ───
app.get('/api/catalog', (req, res) => {
  res.set({
    'Cache-Control': 'public, max-age=300',
    'Vary': 'Accept-Encoding, Accept-Language', // vary on all reflected headers
  });
});

// ─── CDN: explicit cache key (Cloudfront) ───
// Only cache-key on path + Accept-Encoding — drop all other headers
CachePolicy:
  QueryStringsConfig:
    QueryStringBehavior: none  # don't cache-key on query params
  HeadersConfig:
    HeaderBehavior: whitelist
    Headers: [Accept-Encoding]  # explicit whitelist only

// ─── CSP header prevents poisoned script execution ───
res.set('Content-Security-Policy',
  "default-src 'self'; script-src 'self' https://static.sap.com");
