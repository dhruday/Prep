Background Sync — defer API calls until connectivity returns

Background Sync API allows Service Workers to defer network requests until connectivity is available — even after the browser tab is closed. The browser triggers a 'sync' event on the Service Worker when connectivity returns, giving it a chance to send queued operations. This solves the "works offline but loses data" problem for write operations (form submissions, orders, messages).

One-time sync (SyncManager)
1. User submits form offline
2. App queues request in IndexedDB
3. App calls registration.sync.register('send-order')
4. Browser fires SW 'sync' event when online
5. SW reads queue, sends all pending requests
6. Remove from queue on success
Periodic Background Sync
• Fires at regular intervals (browser decides frequency)
• Requires 'background-sync' permission
• For: refreshing cached articles, prices
• Chrome 80+, needs installed PWA
• Less predictable interval — browsers throttle heavily

Browser support caveat

Background Sync: Chrome/Edge support, Firefox no (2024). For broad coverage, implement idempotent retry with IndexedDB queue yourself, checking connectivity via navigator.onLine and 'online' event. Workbox's BackgroundSyncPlugin wraps this with fallback logic.

Full implementation: IDB queue + Background Sync

// app-code.ts — client side
async function submitOrder(order: Order) {
  if (!navigator.onLine) {
    await queueToIDB('orders', order);
    const reg = await navigator.serviceWorker.ready;
    await reg.sync.register('sync-orders');
    return { queued: true };
  }
  return fetch('/api/orders', { method: 'POST', body: JSON.stringify(order) });
}

// sw.ts — service worker
self.addEventListener('sync', (event: SyncEvent) => {
  if (event.tag === 'sync-orders') {
    event.waitUntil(syncOrders());
  }
});

async function syncOrders() {
  const db = await openIDB();
  const pending = await getAllFromStore(db, 'orders');
  
  await Promise.all(pending.map(async order => {
    const res = await fetch('/api/orders', {
      method: 'POST',
      body: JSON.stringify(order),
      headers: { 'Content-Type': 'application/json' }
    });
    if (res.ok) await deleteFromIDB(db, 'orders', order.id);
    // If fetch throws (offline): event.waitUntil rejects → browser retries
  }));
}

// Workbox alternative (much simpler):
import { BackgroundSyncPlugin } from 'workbox-background-sync';
import { NetworkOnly } from 'workbox-strategies';
registerRoute(
  /\/api\/orders/,
  new NetworkOnly({
    plugins: [new BackgroundSyncPlugin('orders-queue', { maxRetentionTime: 24 * 60 })]
  }),
  'POST'
);
