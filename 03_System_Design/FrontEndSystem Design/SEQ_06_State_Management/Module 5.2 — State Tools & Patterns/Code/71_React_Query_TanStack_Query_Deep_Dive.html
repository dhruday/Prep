TanStack Query — async state management for server data

useQuery
  • Fetch, cache, and sync server data
  • Automatic background refetch
  • staleTime / gcTime lifecycle
  • Parallel and dependent queries
  • Infinite scroll via useInfiniteQuery
useMutation
  • Create / update / delete operations
  • onMutate, onSuccess, onError, onSettled
  • Optimistic updates + rollback
  • invalidateQueries on success
  • Retry on failure

Advanced TanStack Query features

Parallel Queries: Use useQueries([...]) to fire multiple independent fetches simultaneously. Eliminates waterfall.
Dependent Queries: Pass enabled: !!userId to delay a query until a dependency resolves.
Infinite Queries: useInfiniteQuery with getNextPageParam. Automatically fetches the next page and merges data.
Prefetching: queryClient.prefetchQuery on hover/route change. User perceives zero-latency navigation.
Suspense mode: Set suspense: true — component suspends while loading, works with React Suspense + Error Boundaries.

Full TanStack Query patterns

// Setup — wrap app in QueryClientProvider
const queryClient = new QueryClient({
  defaultOptions: { queries: { staleTime: 5 * 60 * 1000, retry: 2 } },
});

// ─── useQuery ───
function OrderList() {
  const { data, isLoading, isFetching, isStale } = useQuery({
    queryKey: ['orders', { status: 'pending' }],
    queryFn: () => fetchOrders('pending'),
  });
  if (isLoading) return <Skeleton />;
  return <>{isFetching && <Spinner small />}{data?.map(o => <OrderRow key={o.id} order={o} />)}</>;
}

// ─── useMutation with optimistic update ───
const { mutate: approve } = useMutation({
  mutationFn: (id: string) => approveOrder(id),
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ['orders'] });
    const snapshot = queryClient.getQueryData(['orders']);
    queryClient.setQueryData(['orders'], (old: Order[]) =>
      old.map(o => o.id === id ? { ...o, status: 'approved' } : o)
    );
    return { snapshot };
  },
  onError: (_, __, ctx) => queryClient.setQueryData(['orders'], ctx?.snapshot),
  onSettled: () => queryClient.invalidateQueries({ queryKey: ['orders'] }),
});

// ─── Parallel queries ───
const results = useQueries({ queries: [
  { queryKey: ['profile'], queryFn: fetchProfile },
  { queryKey: ['permissions'], queryFn: fetchPermissions },
]});
