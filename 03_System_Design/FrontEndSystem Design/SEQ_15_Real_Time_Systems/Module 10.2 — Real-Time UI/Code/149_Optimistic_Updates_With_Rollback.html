Optimistic UI — respond instantly, reconcile asynchronously

Instead of waiting 200-500ms for API confirmation before updating the UI, optimistic updates show the result immediately as if the operation succeeded. If the API fails, the UI rolls back to the previous state and shows an error. This makes UI feel instant — especially critical for toggle actions (like/unlike, complete task, follow/unfollow) where the expected success rate is high.

Pessimistic (traditional)
User clicks "Like" →
Button disabled + spinner →
Wait 300ms for API →
UI updates on success
300ms to see feedback every time
Optimistic (modern)
User clicks "Like" →
UI updates IMMEDIATELY →
API call in background →
On success: confirm / On failure: rollback + toast
~0ms perceived latency

React Query + optimistic update with rollback

// React Query v5 — typed, automatic rollback on error
const { mutate } = useMutation({
  mutationFn: (id: string) => fetch(`/api/todos/${id}/complete`, { method: 'PATCH' }),
  
  // 1. Snapshot current cache, apply optimistic update
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ['todos'] });
    const previous = queryClient.getQueryData<Todo[]>(['todos']);
    
    queryClient.setQueryData<Todo[]>(['todos'], old =>
      old?.map(t => t.id === id ? { ...t, completed: true } : t)
    );
    return { previous };  // context passed to onError
  },
  
  // 2. On error: ROLLBACK to snapshot
  onError: (err, id, context) => {
    queryClient.setQueryData(['todos'], context?.previous);
    toast.error('Failed to complete task — rolled back');
  },
  
  // 3. On success or settle: refetch to sync with server
  onSettled: () => queryClient.invalidateQueries({ queryKey: ['todos'] }),
});

// Usage — instant feedback
<button onClick={() => mutate(todo.id)}>Complete</button>
