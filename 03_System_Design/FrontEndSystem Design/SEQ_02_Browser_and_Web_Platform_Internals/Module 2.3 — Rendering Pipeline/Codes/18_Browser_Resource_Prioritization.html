🎯 fetchpriority Attribute Demo

The fetchpriority attribute (high/low/auto) lets you override browser heuristics. Watch how LCP hero image loads first with fetchpriority="high".

❌ Without fetchpriority

<img src="hero.jpg" class="lcp-image">
Browser treats this as same priority as all other images in the page

✅ With fetchpriority="high"

<img src="hero.jpg" fetchpriority="high" class="lcp-image">
Browser fetches this before other low-priority images → faster LCP!

💡 Resource Hints Cheatsheet

preload

<link rel="preload" href="hero.jpg" as="image">
Fetch NOW, HIGH priority. Use for LCP images, critical fonts.

preconnect

<link rel="preconnect" href="https://api.cdn.com">
Open TCP/TLS early to a 3rd-party origin. Saves 200-400ms per connection.

dns-prefetch

<link rel="dns-prefetch" href="//fonts.googleapis.com">
Resolve DNS early. Cheaper but less powerful than preconnect.

prefetch

<link rel="prefetch" href="/next-page.js">
Fetch at IDLE time. For next page resources. LOWEST priority.
