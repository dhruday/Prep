❌ The Problem — Stale Responses Overwrite Fresh Ones

// User types "a", then "ab", then "abc" quickly
// Request for "a" takes 800ms, "ab" takes 200ms, "abc" takes 400ms
// Response order: "ab"(200ms) → "abc"(400ms) → "a"(800ms)
// Final display shows results for "a" — WRONG!

async function naiveSearch(query) {
  const res = await fetch(`${API}/api/search/slow?q=${query}`);
  const data = await res.json();
  display(data); // Last response wins, not last request!
}
The core issue: network latency is non-deterministic. A request sent first can arrive last, overwriting the correct result.

✅ The Fix — Cancel Previous Requests

let controller = null;

async function safeSearch(query) {
  // Cancel any in-flight request
  if (controller) controller.abort();
  controller = new AbortController();

  try {
    const res = await fetch(`${API}/api/search/slow?q=${query}`, {
      signal: controller.signal
    });
    const data = await res.json();
    display(data); // Only the latest request completes
  } catch (e) {
    if (e.name !== 'AbortError') throw e;
    // Aborted — silently ignore
  }
}
Each new keystroke aborts the previous fetch. Only the response matching the current input is displayed.
