Likes update instantly. On server failure the count rolls back and the card flashes red.

Optimistic Update Pattern

1. User clicks like → UI updates immediately (no spinner)
2. POST sent to server in background
3. On failure → revert to previous state + notify user

Why Optimistic?

Most like requests succeed. Waiting 200-500ms for confirmation feels sluggish. Optimistic updates give perceived instant feedback, making the UI feel native-app fast.

Core Logic

async function toggleLike(postId) {
  const prev = posts.find(p => p.id === postId);
  const snapshot = { ...prev }; // save for rollback

  // 1. Optimistic update
  prev.likes += prev.liked ? -1 : 1;
  prev.liked = !prev.liked;
  render();

  try {
    await fetch(`${API}/api/posts/${postId}/like`, {
      method: 'POST'
    });
    log('✓ Server confirmed');
  } catch (err) {
    // 2. Rollback on failure
    Object.assign(prev, snapshot);
    render();
    flashCard(postId);
    log('✗ Rolled back');
  }
}
