Speculation Rules API — instant page navigations

The Speculation Rules API (Chrome 109+) is a JSON-based mechanism to instruct the browser to prefetch (download HTML) or prerender (fully render, execute JS) pages the user is likely to navigate to next. Prerender = ~0ms navigation.

prefetch
Downloads the HTML of likely-next pages.
Low cost. Saves download time on navigation.
JS not executed until navigation.
prerender
Full render in background tab.
JS, CSS, layout all computed.
Navigation = instant (0ms).
Costly — use only for near-certain URLs.
Eagerness levels: immediate — as soon as script runs  |  eager — on hover/pointer-over  |  moderate — 200ms hover  |  conservative — pointer-down / tap

Speculation Rules JSON + dynamic injection

<!-- Static JSON in HTML -->
<script type="speculationrules">
{
  "prefetch": [
    {
      "source": "list",
      "urls": ["/products", "/about"],
      "eagerness": "moderate"
    }
  ],
  "prerender": [
    {
      "source": "document",
      "where": { "href_matches": "/products/*" },
      "eagerness": "conservative"
    }
  ]
}
</script>

// Dynamic injection based on user behaviour:
function addSpeculationRule(url: string, type = 'prefetch') {
  if (!HTMLScriptElement.supports?.('speculationrules')) return;
  const rules = { [type]: [{ source: 'list', urls: [url] }] };
  const script = document.createElement('script');
  script.type = 'speculationrules';
  script.textContent = JSON.stringify(rules);
  document.head.appendChild(script);
}

// Call on hover of checkout button
checkoutBtn.addEventListener('pointerover', () => {
  addSpeculationRule('/checkout', 'prerender');
});
