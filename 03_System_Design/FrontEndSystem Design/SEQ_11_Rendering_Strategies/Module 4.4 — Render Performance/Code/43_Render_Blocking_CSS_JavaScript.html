The browser rendering critical path

Before the browser can paint pixels, it needs both the DOM (from HTML) and CSSOM (from CSS). Any CSS file in <head> is render-blocking — the browser halts rendering until that CSS downloads, parses, and the CSSOM is built. Synchronous <script> blocks both HTML parsing AND rendering.

🔴 <link rel="stylesheet"> — browser must download + build CSSOM before first paint
🔴 <script src="..."> — HTML parser stops, JS downloads, executes, then parser resumes
🟢 <script defer> — downloads in parallel, executes after HTML parse complete, does NOT block
🟢 <script async> — downloads in parallel, executes as soon as ready (can interrupt parser)
🟡 <link media="print"> — downloads but doesn't block rendering (low priority)
