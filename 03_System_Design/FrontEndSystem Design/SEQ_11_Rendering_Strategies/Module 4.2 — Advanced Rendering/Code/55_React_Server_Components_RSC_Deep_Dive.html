React Server Components — concept

RSC (React 18+, Next.js App Router) introduces a new component model: Server Components run only on the server — they read databases, call APIs, access secrets — and produce HTML/React tree that streams to the client. They ship zero JavaScript to the browser. Client Components (marked 'use client') behave like traditional React — they hydrate and run in the browser.

Server Component
✅ Async/await at top level
✅ Direct DB access
✅ Access environment secrets
✅ Reduce bundle size
❌ No useState/useEffect
❌ No event handlers
❌ No browser APIs
Client Component ('use client')
✅ useState / useReducer
✅ useEffect / browser APIs
✅ Event handlers (onClick etc.)
✅ Real-time UI
❌ No direct DB access
❌ Ships JS to client
❌ Can't be async component

Solving the data waterfall

Traditional fetch-in-component causes sequential waterfalls. RSC allows parallel fetching and removes the client round-trip entirely.

❌ Old CSR waterfall
0ms Download JS bundle
800ms App renders, fetch /user
1100ms Render UserLayout, fetch /posts
1400ms Render Posts, fetch /comments
Total: ~1400ms + 3 round trips
✅ RSC parallel fetch
0ms Server runs ALL fetches in parallel
0ms Promise.all([user, posts, comments])
~300ms All data ready, HTML streams
~320ms FCP — full page visible
Total: ~320ms, 0 client round trips

RSC — server + client component pattern

// app/dashboard/page.tsx — SERVER COMPONENT (default)
import InteractiveChart from './InteractiveChart'; // client

export default async function Dashboard() {
  // Direct DB/API — no useEffect, no fetch on client
  const [metrics, user] = await Promise.all([
    getMetrics(),
    getCurrentUser(),
  ]);

  return (
    <section>
      <h1>Welcome, {user.name}</h1>
      {/* Server component — no JS */}
      <MetricsSummary data={metrics} />
      {/* Client component — ships JS, interactive */}
      <InteractiveChart data={metrics.series} />
    </section>
  );
}

// InteractiveChart.tsx — CLIENT COMPONENT
'use client';
import { useState } from 'react';

export default function InteractiveChart({ data }) {
  const [range, setRange] = useState('7d');
  return (
    <div>
      <RangeSelector value={range} onChange={setRange} />
      <Chart data={data} range={range} />
    </div>
  );
}
