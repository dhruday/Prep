Why structured frontend logging matters

Frontend logs bridge the gap between "something broke in production" and "here's exactly what happened and why." Raw console.log is useless at scale. Structured logs (JSON, with level/timestamp/sessionId/userId/context) can be shipped to centralized platforms (Datadog, Splunk, ELK) and correlated with backend traces. At SAP, all BTP UI5 apps emit structured logs to Kibana for SRE teams.

🪲
DEBUG
Dev only — stripped in prod build
ℹ️
INFO
User actions, page loads, feature use
⚠️

Recoverable issues, deprecated APIs, slow network
🔴

Unhandled exceptions, failed API calls, crash events

Logging transport pipeline

UI Action
→
Logger.info()
→
Batch buffer
→
POST /logs (beacon API)
→
Datadog / ELK

Use navigator.sendBeacon() for reliability on page unload — fetch is not guaranteed. Batch logs every 5s or on 50-item flush to avoid excessive HTTP calls.

    "stack":  "..."             // source-mapped in tool
  }
}

Logger class + batched beacon transport

// ─── Structured logger ───
type Level = 'debug' | 'info' | 'warn' | 'error';

class Logger {
  private queue: object[] = [];
  private timer?: ReturnType<typeof setTimeout>;

  log(level: Level, message: string, ctx = {}) {
    if (level === 'debug' && ENV !== 'development') return;
    const entry = {
      timestamp: new Date().toISOString(),
      level, message,
      context: { ...baseContext, ...ctx }
    };
    this.queue.push(entry);
    if (this.queue.length >= 50) this.flush();
    else if (!this.timer) this.timer = setTimeout(() => this.flush(), 5000);
  }

  private flush() {
    if (!this.queue.length) return;
    const batch = this.queue.splice(0);
    navigator.sendBeacon('/api/logs', JSON.stringify(batch));
    clearTimeout(this.timer); this.timer = undefined;
  }
}
export const logger = new Logger();

// ─── Global error capture ───
window.addEventListener('unhandledrejection', e =>
  logger.log('error', e.reason?.message, { reason: e.reason }));
window.addEventListener('error', e =>
  logger.log('error', e.message, { filename: e.filename, line: e.lineno }));
