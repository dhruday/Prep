### For Portfolio
1. Pick 2-3 Advanced/Production projects

2. Be ready to explain architecture decisions

## 🎓 Project Completion Checklist

For each project, ensure you:

- [ ] Understand the business problem
- [ ] Explore and clean the dataset
- [ ] Establish baseline model
- [ ] Try advanced approaches
- [ ] Evaluate properly (right metrics, test set)
- [ ] Document your findings
- [ ] (Intermediate+) Build API/UI
- [ ] (Advanced+) Consider scale & optimization
- [ ] (Production) Deploy with monitoring
