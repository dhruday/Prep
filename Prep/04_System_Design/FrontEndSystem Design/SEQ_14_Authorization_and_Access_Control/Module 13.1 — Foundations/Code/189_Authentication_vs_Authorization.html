The fundamental distinction

🔐 Authentication (AuthN)
Who are you?
Verifies identity
Done once per session
Result: identity token

Examples:
• Password + MFA login
• OAuth 2.0 / OIDC flow
• Passkey / WebAuthn
• Corporate SSO / SAML
🛡️ Authorization (AuthZ)
What can you do?
Verifies permissions
Checked on EVERY request
Result: allow / deny

Examples:
• Can user edit document?
• Can user access /admin?
• Can user see salary field?
• Can user call DELETE /users/:id?
⚠️ Frontend hides UI — Server enforces authorization
Hiding a button or route in the frontend is UX only, never security. A user with DevTools can manipulate client-side state and call any API directly. The server MUST independently check authorization on every request regardless of what the UI shows.

Passport analogy:
Passport = Authentication — proves who you are. Visa = Authorization — specifies which countries you can enter and what you can do. You need both — a valid passport doesn't mean all visas are granted.

Separating AuthN and AuthZ in Angular

// auth.service.ts — AUTHENTICATION only
@Injectable({ providedIn: 'root' })
export class AuthService {
  private currentUser$ = new BehaviorSubject<User | null>(null);

  isAuthenticated(): boolean {
    return this.currentUser$.value !== null;
  }
  getIdentity(): User | null { return this.currentUser$.value; }
}

// permissions.service.ts — AUTHORIZATION only (separate concern)
@Injectable({ providedIn: 'root' })
export class PermissionsService {
  can(permission: string): boolean {
    const user = this.auth.getIdentity();
    if (!user) return false;
    return user.permissions.includes(permission);  // UX only!
  }
}

// HTTP interceptor — correct 401 vs 403 handling
const httpErrorInterceptor: HttpInterceptorFn = (req, next) =>
  next(req).pipe(
    catchError((err: HttpErrorResponse) => {
      if (err.status === 401) {
        router.navigate(['/login']);       // not authenticated
      } else if (err.status === 403) {
        router.navigate(['/access-denied']); // not authorized
      }
      return throwError(() => err);
    })
  );
