CSS is render-blocking — every byte in the critical path delays FCP

The browser cannot paint until all CSS in <head> is downloaded and parsed. A 200 KB CSS bundle blocks render for hundreds of milliseconds on 3G. At SAP, extracting critical CSS (above-the-fold styles) as inline styles and loading the rest async cut FCP by 800 ms.

Techniques
  • 🔑 Critical CSS inlining (above-fold)
  • 📦 PurgeCSS / Tailwind JIT (remove unused)
  • 🔗 CSS Modules / Scoped CSS (no global leaks)
  • 📐 CSS containment (scope style recalc)
  • 🗜️ Minify + deduplicate rules
Anti-patterns
  • ❌ @import in CSS (sequential downloads)
  • ❌ Universal selectors with heavy specificity
  • ❌ Loading 300 KB Bootstrap for 3 components
  • ❌ Inline styles in JS with new objects (defeats memo)
  • ❌ Unused rule sets from abandoned features

CSS optimization technique guide

Critical CSS extraction — tools like critters (Next.js), critical (npm) scan the HTML for above-fold elements and inline their styles. Everything else loads async with media="print" onload trick.
PurgeCSS / Tailwind JIT — scan template files for class usage, remove all unused CSS rules before shipping. Tailwind with JIT ships only what's used — 5 KB instead of 400 KB.
CSS Modules / styled-components — scoped class names prevent style leakage, enable per-component chunking. Angular component styles with ViewEncapsulation.Emulated are automatically scoped.
CSS containment — contain: layout style paint tells the browser that changes inside this element cannot affect outside. Dramatically speeds up style recalculation for dense UIs like data tables.

CSS optimization patterns

<!-- Async non-critical CSS load -->
<link rel="preload" as="style" href="styles.css"
  onload="this.onload=null;this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="styles.css"></noscript>

/* ─── CSS containment for dense tables ───*/
.order-table {
  contain: layout style paint; /* scope recalc to this element */
}

/* ─── CSS custom properties for theming (no reparse) ───*/
:root {
  --primary: #60a5fa;
  --bg: #0f1117;
}
.btn { background: var(--primary); }
/* Theme switch = single property change, no CSS reload */

// ─── PurgeCSS config (vite) ───
import purgeCss from 'vite-plugin-purgecss';
export default defineConfig({
  plugins: [purgeCss({
    content: ['./src/**/*.{ts,tsx,html}'],
    safelist: [/^sap-/, /^mat-/], // keep dynamic classes
  })],
});

// ─── Angular component styles: ViewEncapsulation ───
@Component({
  selector: 'app-order-table',
  encapsulation: ViewEncapsulation.Emulated, // scoped shadow-DOM-like
  styles: ['.row { color: var(--primary); }']
})
