Hybrid: Feature-based core + shared infrastructure

src/
  features/              // Domain-specific (feature-based)
    orders/
    users/
    analytics/
  shared/                // Cross-feature shared (layer-based internally)
    components/          // Design system atoms/molecules
      Button.tsx
      Modal.tsx
    hooks/               // Generic hooks: useDebounce, useMediaQuery
    utils/               // Pure functions: formatDate, sanitize
    types/               // Shared TypeScript interfaces
  app/                   // App wiring: router, store config, providers
    App.tsx
    router.tsx
    store.ts
Rule: If something is used by only 1 feature → inside that feature. If used by 2+ features → promote to shared/. This is the rule Hruday applied at SAP when refactoring the Fiori monolith.
