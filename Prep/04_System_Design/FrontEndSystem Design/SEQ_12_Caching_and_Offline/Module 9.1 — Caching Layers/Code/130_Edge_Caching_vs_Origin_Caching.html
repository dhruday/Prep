The caching stack: browser → edge PoP → origin

A request for a resource passes through multiple caches before reaching your origin server. Each layer can serve the response, short-circuiting the chain. Understanding which layer serves what determines your latency: browser cache (~0ms), edge CDN PoP nearby (~10ms), origin (~100-300ms).

Browser Cache (L1)
Headers: Cache-Control: max-age, ETag, Last-Modified. Zero latency when HIT. Invalidated by hard refresh or expiry.
~0ms
Edge CDN PoP (L2) — Cloudflare, Fastly, CloudFront
Serves cached responses from PoP nearest to user. Controlled by Cache-Control: s-maxage, CDN-Cache-Control, Surrogate-Control. Supports purge by URL or tag.
~5-30ms
Origin Cache (L3) — Varnish, Redis, application cache
Internal cache at origin (Redis, Varnish). Protects DB/backend from thundering herd. Even on CDN MISS, origin cache may hit without DB query.
~50ms
Origin DB (MISS all caches)
Full request reaches DB. All caches missed or not applicable (auth'd, dynamic). Slowest path.
~200-500ms

Cache-Control headers for each layer

// Static immutable assets (JS/CSS with content hash in filename)
Cache-Control: public, max-age=31536000, immutable
// Browser caches for 1 year; CDN caches for 1 year; never revalidates

// Public HTML pages (cacheable but must revalidate)
Cache-Control: public, max-age=0, s-maxage=60, stale-while-revalidate=3600
// Browser: no cache; CDN: 60s cache; serve stale for 1hr while refreshing

// Authenticated pages — NEVER cache at shared CDN layer
Cache-Control: private, no-store
// private = browser can cache; no-store = even browser must not retain

// API responses — short cache with ETag validation
Cache-Control: public, max-age=10, stale-while-revalidate=60
ETag: "v1-abc123"
// Client sends If-None-Match: "v1-abc123" on next req
// If unchanged: 304 Not Modified (no body = faster)

// Cloudflare / CDN-specific: separate CDN from browser
Cache-Control: public, max-age=60          /* browser sees */
CDN-Cache-Control: max-age=86400            /* CDN sees */
Surrogate-Control: max-age=86400             /* Fastly/Varnish */
Cache-Tag: product-123, category-electronics   /* for tag-based purge */

// Cloudflare: purge by tag when product data changes
await fetch(`https://api.cloudflare.com/client/v4/zones/${ZONE}/purge_cache`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${CF_TOKEN}` },
  body: JSON.stringify({ tags: [`product-${productId}`] })
