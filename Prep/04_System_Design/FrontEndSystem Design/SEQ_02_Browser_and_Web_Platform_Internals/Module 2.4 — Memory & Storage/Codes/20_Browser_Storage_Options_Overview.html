💾 LocalStorage — Persistent, Synchronous

Used: 0 bytes / ~5MB limit

Empty
localStorage: Persists until explicitly cleared. Shared across all tabs for same origin. Synchronous API — can block main thread if storing large data. Max ~5MB.

// Watch for storage events from other tabs:

});

⏱ SessionStorage — Tab-Scoped

KeyValue
Empty
sessionStorage: Same API as localStorage but data is cleared when the tab is closed. Not shared between tabs (even same origin). Perfect for sensitive multi-step form wizards.

🗃 IndexedDB — Async, Structured, Large

IDNameAge
Click "Get All" to load
IndexedDB: Fully async, transactional key-value database. Supports structured data (objects, blobs). Size: up to ~50% of disk space. Great for offline apps, caching API responses, file storage.

🍪 Cookies — Server-Sent, HttpOnly option

NameValueFlags
No cookies yet
Cookies: Sent with EVERY HTTP request to matching origin (can increase bandwidth). HttpOnly flag prevents JS access — protects from XSS. SameSite prevents CSRF. Max size: ~4KB. Use for auth tokens that server needs to read.

📋 Cookie Flags Reference

// Cookies are sent to server on every request
FlagPurpose
HttpOnlyJS cannot read — protects from XSS
SecureOnly sent over HTTPS
SameSite=StrictNever sent cross-site — prevents CSRF
SameSite=LaxSent on top-level navigation (default)
SameSite=None;SecureCross-site cookies (3rd party)
Expires / Max-AgeExpiry. No Expires = session cookie
PathScope to URL path
DomainScope to domain + subdomains
