📖 Event Loop Rule

1. Run all synchronous code (stack)
2. Drain ALL microtasks (repeat until empty)
3. Check for render opportunity (rAF)
4. Pick ONE macrotask from queue
5. Go to step 2 ↑
Key: Microtasks always run to completion before ANY macrotask or render opportunity. A microtask spawning more microtasks can starve the render loop!

⚖️ Microtask vs Macrotask

Microtasks

  • Promise.then/catch/finally
  • async/await (await resumes)
  • queueMicrotask()
  • MutationObserver
  • ALL drained per tick

Macrotasks

  • setTimeout / setInterval
  • setImmediate (Node.js)
  • I/O callbacks
  • UI event handlers
  • ONE per event loop tick
