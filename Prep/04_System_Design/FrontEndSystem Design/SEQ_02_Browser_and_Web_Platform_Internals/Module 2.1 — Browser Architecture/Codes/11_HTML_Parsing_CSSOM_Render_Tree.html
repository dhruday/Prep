🌳 DOM, CSSOM & Render Tree

See how the browser builds 3 separate trees and merges them into what's actually painted

📄 DOM Tree

HTML Parsing is incremental: DOM is built as bytes arrive over the network. Sync <script> blocks the parser mid-way.

🎨 CSSOM Tree

CSSOM is NOT incremental: Must be fully parsed before any styles can be applied. Later rules can override earlier ones (cascade).

🖼️ Render Tree (DOM + CSSOM)

🔬 How the Render Tree is Built

1

Tokenize HTML → DOM Nodes

Browser reads bytes, converts to tokens (StartTag, EndTag, Character), builds DOM tree nodes.

2

Tokenize CSS → CSSOM Rules

CSS bytes parsed into CSSOM. Once started, must be fully completed — render blocked until done.

3

Style Calculation (Right-to-Left)

Browser matches CSS selectors to DOM nodes right-to-left for efficiency. Attaches computed styles.

4

Build Render Tree

Only VISIBLE DOM nodes enter the Render Tree. display:none is excluded entirely. visibility:hidden IS included (takes space).

5

Pseudo-elements Added

::before and ::after are virtual nodes in the Render Tree — they render but don't exist in the DOM.
