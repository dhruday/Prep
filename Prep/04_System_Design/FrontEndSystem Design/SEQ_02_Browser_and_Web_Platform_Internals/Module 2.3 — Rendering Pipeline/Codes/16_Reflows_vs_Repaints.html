🏗️ What Each Phase Does

REFLOW (Layout): Recalculates geometry of ALL affected elements. Very expensive — cascades through the tree.
REPAINT: Re-draws pixels for changed elements. No geometry change. Cheaper than reflow but still hits GPU.
COMPOSITE ONLY: GPU moves already-painted layers. Happens on compositor thread — doesn't block main thread. Cheapest!

Key Rule: Animate with transform and opacity — they run on the compositor thread and never block the main thread. Avoid animating top/left/width/height which force reflows every frame.
