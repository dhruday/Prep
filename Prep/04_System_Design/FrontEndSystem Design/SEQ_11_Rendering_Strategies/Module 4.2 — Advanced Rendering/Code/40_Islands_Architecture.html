Islands Architecture

Coined by Katie Sylor-Miller, Islands Architecture treats the page as a "sea of static HTML" with small interactive "islands." Only islands ship JavaScript and get hydrated. Static content stays as plain HTML — zero JavaScript, zero hydration cost.

❌ SPA/Full hydration
100% page JS. Every component hydrated — even static blog text. Huge TBT.
✅ Islands
Static HTML ocean. Only Search, Cart, Carousel shipJS. Page load 90% less JS.
Client directives (Astro): client:load / client:idle / client:visible / client:media / client:only — each controls when the island's JS downloads and hydrates.

Astro — Islands with client directives

---
// src/pages/product.astro
import Header from '../components/Header.astro'; // static
import SearchBar from '../components/SearchBar.jsx'; // island
import ProductCarousel from '../components/Carousel.jsx'; // island
import Cart from '../components/Cart.jsx'; // island
---

<!-- Static HTML - no JS -->
<Header />

{/* Island — loads JS immediately */}
<SearchBar client:load />

{/* Island — hydrates when browser is idle */}
<ProductCarousel client:idle />

{/* Island — hydrates when scrolled into view */}
<Cart client:visible />

{/* Island — only in browser, no SSR at all */}
<Analytics client:only="react" />

{/* Pure static content — ZERO JavaScript */}
<article>{frontmatter.content}</article>
