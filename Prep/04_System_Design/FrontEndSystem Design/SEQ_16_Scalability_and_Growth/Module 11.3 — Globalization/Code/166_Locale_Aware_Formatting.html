The Intl API — browser-native internationalization

The Intl namespace (ECMAScript Internationalization API) provides locale-aware formatting out of the box — no external library needed for numbers, dates, currencies, lists, relative time, and pluralization. Using "1,000.00" everywhere is wrong — Indians write "1,000.00", Germans write "1.000,00", but French write "1 000,00". Hard-coding format strings is a bug.

Intl.NumberFormat
Currencies, percents, scientific, compact (1K, 1M). Different decimal/grouping separators per locale.
Intl.DateTimeFormat
Date, time, calendar systems (Hijri, Buddhist). Long/short/narrow formats. Timezone-aware.
Intl.RelativeTimeFormat
"3 days ago", "in 5 minutes" in any language with natural phrasing.
Intl.PluralRules
Russian has 3 plural forms, Arabic has 6. Automate "1 result" vs "2 results" correctly.
Intl.ListFormat
"A, B, and C" vs "A, B et C" (French). Correct conjunctions per locale.
Intl.Collator
Correct alphabetical sort for non-ASCII. "ä" after "a" in German, not at end.

Production-grade formatting utilities

// Cache formatters for performance (costly to create)
const _cache = new Map<string, Intl.NumberFormat>();
function getFormatter(locale: string, opts: Intl.NumberFormatOptions) {
  const key = `${locale}-${JSON.stringify(opts)}`;
  if (!_cache.has(key)) _cache.set(key, new Intl.NumberFormat(locale, opts));
  return _cache.get(key)!;
}

// Currency formatting
export function formatCurrency(amount: number, currency: string, locale: string): string {
  return getFormatter(locale, { style: 'currency', currency }).format(amount);
}
// formatCurrency(2499, 'INR', 'en-IN') → "₹2,499.00"
// formatCurrency(2499, 'EUR', 'de-DE') → "2.499,00 €"

// Relative time (build your own delta → unit logic)
export function timeAgo(date: Date, locale: string): string {
  const rtf = new Intl.RelativeTimeFormat(locale, { numeric: 'auto' });
  const diff = date.getTime() - Date.now();
  const units: [Intl.RelativeTimeFormatUnit, number][] = [
    ['year', 31536000000], ['month', 2592000000],
    ['week', 604800000],  ['day', 86400000],
    ['hour', 3600000],   ['minute', 60000], ['second', 1000]
  ];
  const [unit, ms] = units.find(([, ms]) => Math.abs(diff) >= ms) || ['second', 1000];
  return rtf.format(Math.round(diff / ms), unit);
}

// Pluralization — avoid hardcoded "s" suffix
const pr = new Intl.PluralRules('en-US');
const plurals: Record<string, string> = { one: 'result', other: 'results' };
const label = (n: number) => `${n} ${plurals[pr.select(n)]}`;
// label(1) → "1 result"; label(2) → "2 results"
