What is clickjacking?

Clickjacking (UI redressing) embeds a target site in a transparent <iframe> overlaid on a decoy page. The user thinks they're clicking the decoy; they're actually clicking buttons on the hidden target (confirm payment, delete account, follow, etc.).

Attack scenario
1. Attacker creates evil.com
2. Embeds bank.com/transfer in an invisible iframe at z-index 9999
3. Positions "Win a Prize!" button exactly over the transfer 4. Victim clicks → transfer executes
5. Victim sees only the prize page
Requirements for attack to work
• Target page allows framing (no X-Frame-Options or CSP frame-ancestors)
• Action is triggered by a single click (no confirmation)
• User is already logged in (cookies sent automatically)
• Page is predictably laid out (button always in same position)

Defence comparison

X-Frame-Options: DENYHTTP header; browser refuses to render page in any iframeNo bypass; but deprecated — use CSP instead
CSP: frame-ancestors 'none'CSP header; can whitelist specific origins. More flexible than XFONo bypass in modern browsers; IE unsupported

X-Frame-Options + CSP frame-ancestors + Next.js config

// ─── 1. HTTP response headers (most important) ───
// Option A: X-Frame-Options (legacy, still widely supported)
X-Frame-Options: DENY
// or whitelist your own domain:
X-Frame-Options: SAMEORIGIN

// Option B: Content-Security-Policy (modern, preferred)
Content-Security-Policy: frame-ancestors 'none';
// or whitelist specific trusted embedder:
Content-Security-Policy: frame-ancestors 'self' https://parent-allowed.com;

// ─── 2. Next.js next.config.js ───
const nextConfig = {
  async headers() {
    return [{
      source: '/(.*)',
      headers: [
        { key: 'X-Frame-Options', value: 'DENY' },
        { key: 'Content-Security-Policy',
          value: "frame-ancestors 'none'" }
      ]
    }];
  }
};

// ─── 3. JS frame-busting (fallback, NOT primary defence) ───
// Runs before render — shows page blank if framed
if (window.top !== window.self) {
  document.body.style.display = 'none';
  window.top.location = window.self.location.href;
}
