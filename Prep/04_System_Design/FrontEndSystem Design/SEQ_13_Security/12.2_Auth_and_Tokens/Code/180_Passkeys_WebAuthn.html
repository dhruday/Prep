How WebAuthn works

Registration
Browser → requests challenge from server
Authenticator → prompts biometric/PIN
Device → generates key pair
→ privateKey stays on device 🔒
→ publicKey + credential ID → server
Server → stores publicKey (safe to leak)
Authentication
Browser → requests challenge from server
Server → sends random nonce
Device → user verifies biometric/PIN
→ signs nonce with privateKey
→ sends signature to server
Server → verifies signature with publicKey ✅
✅ Phishing-proof
Key bound to exact origin — fake domains can't trigger it
✅ Breach-safe
Server only has public key — useless to attackers
✅ No replay
Random challenge per login — intercepted assertions can't be reused

WebAuthn registration & authentication

// Dependencies: npm install @simplewebauthn/browser

// === REGISTRATION ===
async function registerPasskey() {
  // Step 1: Get options from server (challenge, rp, user)
  const opts = await fetch('/api/auth/register/begin', {method:'POST'}).then(r=>r.json());

  // Step 2: Create credential (triggers biometric prompt)
  const cred = await navigator.credentials.create({
    publicKey: {
      challenge: base64urlDecode(opts.challenge),
      rp: { name: 'My App', id: window.location.hostname },
      user: { id: base64urlDecode(opts.userId), name: opts.email, displayName: opts.name },
      pubKeyCredParams: [{type:'public-key', alg:-7}],  // ES256
      authenticatorSelection: {
        residentKey: 'required',      // discoverable passkey
        userVerification: 'required',   // biometric/PIN required
      }
    }
  }) as PublicKeyCredential;

  // Step 3: Send public key to server for storage
  await fetch('/api/auth/register/verify', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify(encodeCredential(cred))
  });
}

// === AUTHENTICATION ===
async function loginWithPasskey() {
  const opts = await fetch('/api/auth/begin', {method:'POST'}).then(r=>r.json());

  const assertion = await navigator.credentials.get({
    publicKey: {
      challenge: base64urlDecode(opts.challenge),
      userVerification: 'required',
      // empty allowCredentials = shows all passkeys for this origin
    }
  }) as PublicKeyCredential;

  // Server verifies signature against stored public key
  const result = await fetch('/api/auth/verify', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify(encodeAssertion(assertion))
  }).then(r=>r.json());

  if (result.verified) router.push('/dashboard');
}
