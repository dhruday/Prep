Helmet.js — Security Headers Middleware

// Helmet sets 11+ security headers with one line:
const helmet = require('helmet');
app.use(helmet());

// Default headers set by helmet():
// Content-Security-Policy: default-src 'self'; ...
// Cross-Origin-Embedder-Policy: require-corp
// Cross-Origin-Opener-Policy: same-origin
// Cross-Origin-Resource-Policy: same-origin
// Origin-Agent-Cluster: ?1
// Referrer-Policy: no-referrer
// Strict-Transport-Security: max-age=15552000; includeSubDomains
// X-Content-Type-Options: nosniff
// X-DNS-Prefetch-Control: off
// X-Download-Options: noopen
// X-Frame-Options: SAMEORIGIN
// X-Permitted-Cross-Domain-Policies: none
// X-XSS-Protection: 0 (disabled — CSP is better)

// Customize:
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'", "'nonce-abc123'"],
    }
  },
  frameguard: { action: 'deny' }
}));

Essential Security Headers

// ═══ 1. X-Content-Type-Options ═══
X-Content-Type-Options: nosniff
// Prevents MIME sniffing. Browser trusts Content-Type header.
// Without it: browser might execute text/plain as JavaScript

// ═══ 2. X-Frame-Options ═══
X-Frame-Options: DENY
// Prevents clickjacking (legacy — use frame-ancestors too)

// ═══ 3. Strict-Transport-Security (HSTS) ═══
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
// Forces HTTPS for 2 years, all subdomains, preload eligible

// ═══ 4. Referrer-Policy ═══
Referrer-Policy: strict-origin-when-cross-origin
// Controls what URL info is sent in Referer header

// ═══ 5. Permissions-Policy (formerly Feature-Policy) ═══
Permissions-Policy: camera=(), microphone=(), geolocation=()
// Blocks/controls powerful browser APIs

// ═══ 6. Cross-Origin headers ═══
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
Cross-Origin-Resource-Policy: same-origin
// Enables SharedArrayBuffer, prevents Spectre-style attacks

Google Senior Frontend — Security Headers

Q: Which security headers should every web app have?

Tier 1 (Must have): (1) Content-Security-Policy — XSS prevention. (2) Strict-Transport-Security — force HTTPS. (3) X-Content-Type-Options: nosniff — prevent MIME confusion. (4) X-Frame-Options + frame-ancestors — clickjacking. Tier 2 (Important): (5) Referrer-Policy — prevent URL leakage. (6) Permissions-Policy — disable unused APIs. (7) Cross-Origin-Opener-Policy — isolate browsing contexts. Tier 3 (Defense-in-depth): (8) Cross-Origin-Embedder-Policy — cross-origin isolation. (9) Cross-Origin-Resource-Policy — prevent cross-origin reads. (10) X-XSS-Protection: 0 — deliberately DISABLED (old XSS auditor had its own vulnerabilities; CSP replaces it). Common mistake: Removing X-Powered-By but not Server header. Both reveal technology stack. Helmet removes X-Powered-By automatically.
