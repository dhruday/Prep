Cache as state — the key insight

Instead of storing fetched data in Redux, treat the HTTP cache as the state layer. Libraries like TanStack Query and SWR maintain a normalised in-memory cache keyed by queryKey. They handle stale → fetch → fresh transitions automatically.

🆕
fresh
Data within staleTime window
🕰️
stale
Past staleTime; shown while refetching
⬇️
fetching
Active network request in-flight
🗑️
garbage
Past gcTime; removed from memory

Cache invalidation strategies

Time-based (staleTime)
Mark data stale after N milliseconds. Next observer triggers a background refetch while stale data remains visible.
Mutation-triggered invalidation
After a POST/PATCH, call queryClient.invalidateQueries({ queryKey: ['orders'] }). Forces a fresh fetch for all matching queries.
Optimistic updates
Immediately update the cache with the expected result before the server responds. Roll back on error.
Focus / reconnect refetch
TanStack Query auto-refetches stale data when the window regains focus or the network reconnects.

TanStack Query cache patterns

// Basic cache query with staleTime
const { data, isLoading, isFetching } = useQuery({
  queryKey: ['sap-orders', { status: 'pending' }],
  queryFn: () => fetchOrders({ status: 'pending' }),
  staleTime: 5 * 60 * 1000,  // fresh for 5 min
  gcTime: 10 * 60 * 1000,    // kept in memory 10 min after unmount
  refetchOnWindowFocus: true, // auto-refresh on tab switch
});

// Mutation with optimistic update
const approve = useMutation({
  mutationFn: (id: string) => approveOrder(id),
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ['sap-orders'] });
    const prev = queryClient.getQueryData(['sap-orders']);
    queryClient.setQueryData(['sap-orders'], (old: Order[]) =>
      old.map(o => o.id === id ? { ...o, status: 'approved' } : o)
    );
    return { prev };             // rollback context
  },
  onError: (_err, _id, ctx) => queryClient.setQueryData(['sap-orders'], ctx?.prev),
  onSettled: () => queryClient.invalidateQueries({ queryKey: ['sap-orders'] }),
});
