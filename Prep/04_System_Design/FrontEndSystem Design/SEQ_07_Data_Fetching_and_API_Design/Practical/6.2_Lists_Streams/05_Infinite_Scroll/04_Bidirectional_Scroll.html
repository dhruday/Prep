Two-Sentinel Pattern

Place sentinels at both top and bottom of the scrollable area. Top sentinel triggers loading older content; bottom sentinel triggers newer content.

// Two observers, two sentinels
const topSentinel = document.getElementById('sentinel-top');
const bottomSentinel = document.getElementById('sentinel-bottom');

const topObserver = new IntersectionObserver(([e]) => {
  if (e.isIntersecting) loadOlderMessages();
}, { root: chatContainer, rootMargin: '200px 0px 0px 0px' });

const bottomObserver = new IntersectionObserver(([e]) => {
  if (e.isIntersecting) loadNewerMessages();
}, { root: chatContainer, rootMargin: '0px 0px 200px 0px' });

topObserver.observe(topSentinel);
bottomObserver.observe(bottomSentinel);
Critical challenge: When prepending items at the top, the scroll position jumps. You must compensate by adjusting scrollTop by the height of the prepended content.

Maintaining Scroll Position on Prepend

// THE PROBLEM: Prepending content shifts everything down
// Before prepend: scrollTop = 100, content height = 2000
// After prepend:  20 new items add 800px at top
// User sees a jarring jump to different content

// THE FIX: Adjust scrollTop by the height of added content
async function loadOlderMessages() {
  const container = chatRef.current;
  const prevHeight = container.scrollHeight;
  const prevScrollTop = container.scrollTop;

  // Prepend new messages
  const older = await fetchOlder(oldestCursor);
  prependMessages(older);

  // Compensate scroll position
  const addedHeight = container.scrollHeight - prevHeight;
  container.scrollTop = prevScrollTop + addedHeight;
}

Modern API: scrollTo with anchor

// Chrome 108+ supports CSS overflow-anchor
// But for cross-browser, manual adjustment is safest

// CSS approach (partial support):
#messages { overflow-anchor: auto; }
#anchor   { overflow-anchor: auto; }
* { overflow-anchor: none; }  // disable on others

// The anchor element stays in place while content
// is prepended above it
overflow-anchor CSS — browser auto-adjusts scroll when content is added above the anchor. Works in Chrome/Edge but not Safari. Always have a JS fallback.

Q: How to prevent layout shift on prepend?

Method 1 — ScrollHeight delta:
Record scrollHeight before prepend. After DOM update, calculate delta = newScrollHeight - oldScrollHeight. Set scrollTop += delta. Wrap in requestAnimationFrame for timing.

Method 2 — CSS overflow-anchor:
Set overflow-anchor: none on all items, overflow-anchor: auto on a stable anchor element. Browser handles the math. Limited browser support.

Method 3 — Reverse flex column:
Use flex-direction: column-reverse. New items appended at the "bottom" of the flex container appear at the top visually. Scroll position naturally maintained. Used by Facebook Messenger.

Q: Chat app scroll UX patterns

// Pattern 1: Auto-scroll to bottom on new message
//   ONLY if user is already near bottom (within 100px)
const isNearBottom = container.scrollHeight -
  container.scrollTop - container.clientHeight < 100;
if (isNearBottom) container.scrollTop = container.scrollHeight;

// Pattern 2: "New messages ↓" badge
//   If user scrolled up, show badge instead of auto-scrolling
if (!isNearBottom) showNewMessageBadge(newCount);

// Pattern 3: Unread marker
//   Track last-read message ID
//   Insert "── New Messages ──" divider

// Pattern 4: Jump to bottom on send
//   Always scroll to bottom when USER sends a message
FAANG answer: Auto-scroll only when near bottom. Show "N new messages" badge when scrolled up. Always scroll on own send. Save unread marker based on visibility (IntersectionObserver on last message).
