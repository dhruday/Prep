Optimistic Add Flow

1. Generate temp-<random> ID → insert into list immediately
2. POST to server → on success, swap temp ID with real server ID
3. On failure → remove item from list with animation

Why Temp IDs?

We need a key to track the item in the UI before the server assigns a real ID. Using temp- prefix makes it easy to identify optimistic items that haven't been confirmed yet.

Core Logic

async function addItem() {
  const text = inp.value.trim();
  const tempId = 'temp-' + Math.random().toString(36).slice(2,8);

  // 1. Optimistic insert
  todos.push({ id: tempId, text, pending: true });
  render();

  try {
    const res = await fetch(`${API}/api/posts/todos`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ text })
    });
    const data = await res.json();
    // 2. Replace temp ID with real ID
    const item = todos.find(t => t.id === tempId);
    item.id = data.id;
    item.pending = false;
  } catch {
    // 3. Remove on failure
    todos = todos.filter(t => t.id !== tempId);
  }
  render();
}
