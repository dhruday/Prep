📖 AbortSignal.any() — Combine Multiple Signals

// Two independent abort sources
const manualController = new AbortController();
const timeoutSignal = AbortSignal.timeout(5000);

// Combine: abort if EITHER fires
const combined = AbortSignal.any([
  manualController.signal,
  timeoutSignal
]);

const res = await fetch(url, { signal: combined });

// Cancel button calls:
manualController.abort(); // Triggers combined signal

🧩 Use Cases for Multi-Signal

// 1. Timeout + user cancel (this lab)
// 2. Component unmount + request timeout
// 3. Route change + API deadline
// 4. User idle timeout + manual refresh
// 5. Parent controller + child controller (nested scopes)
AbortSignal.any() creates a signal that aborts when ANY of the input signals abort. Available in modern browsers (Chrome 116+, Firefox 124+, Safari 17.4+).

🔍 Identifying Which Signal Triggered Abort

const manual = new AbortController();
const timeout = AbortSignal.timeout(5000);
const combined = AbortSignal.any([manual.signal, timeout]);

try {
  await fetch(url, { signal: combined });
} catch (e) {
  if (e.name === 'TimeoutError') {
    // Triggered by AbortSignal.timeout()
    console.log('⏱ Request timed out');
  } else if (e.name === 'AbortError') {
    // Triggered by manual controller.abort()
    console.log('🖐 User cancelled');
  }
}

// You can also check signal.reason:
combined.addEventListener('abort', () => {
  console.log(combined.reason); // DOMException or TimeoutError
});
TimeoutError comes from AbortSignal.timeout(). AbortError comes from controller.abort(). This lets you show different UIs for each case.
