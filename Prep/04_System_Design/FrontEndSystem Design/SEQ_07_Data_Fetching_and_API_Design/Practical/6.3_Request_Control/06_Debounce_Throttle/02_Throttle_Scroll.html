What Is Throttle?

Throttle ensures a function executes at most once per specified interval, no matter how many times it's called. Unlike debounce, it fires during activity.

Classic Implementation

function throttle(fn, limit) {
  let waiting = false;
  return (...args) => {
    if (!waiting) {
      fn(...args);
      waiting = true;
      setTimeout(() => { waiting = false; }, limit);
    }
  };
}

RAF Throttle

function rafThrottle(fn) {
  let ticking = false;
  return (...args) => {
    if (!ticking) {
      ticking = true;
      requestAnimationFrame(() => { fn(...args); ticking = false; });
    }
  };
}

Scroll Events & the Main Thread

Every scroll event runs on the main thread. Heavy handlers block rendering, causing jank. Throttling limits execution to keep the frame budget (~16 ms for 60 fps).

setTimeout vs requestAnimationFrame

setTimeout(fn, 200) fires a macro-task ~200 ms later — it doesn't align with paint frames.
requestAnimationFrame fires once per paint frame (~16 ms at 60 fps), giving the smoothest visual sync.

Passive Event Listeners

// Passive = browser can scroll immediately, no preventDefault
el.addEventListener('scroll', handler, { passive: true });

Combine passive: true with throttle for optimal scroll performance.

Q: When would you choose throttle over debounce?

When you need continuous feedback during activity — scroll position tracking, drag handlers, resize layout recalculations. Debounce is better when you only care about the final value.

Q: What is the trailing-edge problem with basic throttle?

A simple throttle may drop the last call if it happens mid-interval. Libraries like Lodash add a trailing option to ensure the final invocation is captured.

Q: RAF throttle vs fixed interval?

RAF aligns with paint cycles (~60 fps), so it's ideal for visual updates. A fixed interval (e.g., 200 ms) is better when you want to limit network requests or analytics pings.

Q: Can throttle cause stale reads?

Yes — the handler may read layout properties from a previous frame. Use requestAnimationFrame to guarantee you read committed layout values.
