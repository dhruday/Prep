BroadcastChannel Messages

Cross-Tab Synchronization

BroadcastChannel API allows same-origin tabs to send messages to each other without a server.
When a circuit breaker changes state in one tab, it broadcasts the new state to all other tabs on the same channel.
Receiving tabs update their local breaker to match, preventing redundant requests to a known-down service.
This avoids the "thundering herd" problem where every tab independently discovers the service is down.

Sync via BroadcastChannel

const channel = new BroadcastChannel('circuit-breaker');

// On state change, broadcast
function onStateChange(state, failures) {
  channel.postMessage({
    type: 'state-change',
    state, failures,
    tabId: TAB_ID,
    timestamp: Date.now()
  });
}

// Listen for broadcasts from other tabs
channel.onmessage = (e) => {
  const { state, failures } = e.data;
  breaker.state = state;
  breaker.failures = failures;
  if (state === 'OPEN')
    breaker.nextAttempt = Date.now() + cooldown;
  updateUI();
};

Key Takeaways

✅ BroadcastChannel is zero-server cross-tab communication for same-origin pages.
✅ Syncing circuit state prevents N tabs from all hammering a failing service independently.
✅ Include a tabId to identify the source and avoid echo loops.
✅ Fallback: SharedWorker or localStorage events for older browsers.
