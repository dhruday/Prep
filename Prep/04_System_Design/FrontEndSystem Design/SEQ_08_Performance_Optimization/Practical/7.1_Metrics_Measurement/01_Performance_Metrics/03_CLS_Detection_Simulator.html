Fixing CLS

// Common CLS causes and fixes:
//
// 1. Images without dimensions
// ❌ <img src="photo.jpg">
// ✅ <img src="photo.jpg" width="400" height="300">
// ✅ img { aspect-ratio: 4/3; width: 100%; }
//
// 2. Ads/embeds without reserved space
// ✅ .ad-slot { min-height: 250px; }
//
// 3. Dynamic content injected above viewport
// ✅ Use CSS containment: contain: layout
// ✅ Use transform animations instead of top/height
//
// 4. Web fonts causing FOUT
// ✅ font-display: optional (prevents shift)
// ✅ Preload critical fonts: <link rel="preload">
// ✅ Use size-adjust in @font-face
