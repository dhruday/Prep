INP — replaced FID as a Core Web Vital in March 2024

INP measures the latency of the worst interaction during a page visit (click, keypress, tap). Specifically: the time from user input to the next visible paint. Unlike FID (which measures input delay only), INP includes: input delay + processing time + presentation delay.

≤ 200ms
Good — feels instant
200–500ms
Needs improvement
> 500ms
Poor — feels broken
INP anatomy:
INP = input delay + processing time + presentation delay
• Input delay: time browser was busy (long tasks) when event arrived
• Processing: your JS event handler running
• Presentation: style + layout + paint after handler completes

INP optimisation checklist

1. Reduce input delay — break up long tasks before event arrives using chunking / scheduler.yield(). The browser can't check the event queue mid-task.
2. Minimise event handler work — defer non-critical work to after paint using startTransition (React 18) or requestAnimationFrame. Show visual feedback instantly; do the heavy lifting after.
3. React 18 startTransition — marks a state update as non-urgent. Browser paints the urgent update first, then processes the transition. Used for filter changes, search, tab switches.
4. Reduce presentation delay — avoid forced synchronous layouts (measure → mutate in same frame). Batch DOM writes. CSS containment reduces style recalc scope.
5. Measure with web-vitals onINP — report INP to your analytics. Segment by page, interaction type, device class. P75 is the official CWV threshold check.

// ─── React 18 startTransition — keep filter instant ───
const [query, setQuery] = useState('');
const [results, setResults] = useState(allItems);

const handleSearch = (e: React.ChangeEvent<HTMLInputElement>) => {
  setQuery(e.target.value);                  // urgent — input updates immediately
  startTransition(() => {
    setResults(filterItems(allItems, e.target.value)); // deferred — heavy filtering
  });
};

// ─── Optimistic UI — skip waiting for server ───
async function handleApprove(orderId: string) {
  dispatch(setOrderStatus({ id: orderId, status: 'approved' })); // visual immediately
  try {
    await api.approveOrder(orderId);
  } catch {
    dispatch(setOrderStatus({ id: orderId, status: 'pending' }));  // rollback
  }
}

// ─── Measure INP with web-vitals ───
import { onINP } from 'web-vitals';

onINP(({ value, rating, entries }) => {
  trackEvent('inp', { value, rating }); // send to RUM
  if (value > 200)
    console.warn('Poor INP:', value, entries);
}, { reportAllChanges: false });
