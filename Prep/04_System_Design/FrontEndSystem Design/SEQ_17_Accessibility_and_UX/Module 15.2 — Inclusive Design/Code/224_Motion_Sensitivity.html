Motion Sensitivity — prefers-reduced-motion

Topic 224 · Part 15 / Module 15.2 — Inclusive Design · Hruday's Interview Prep

What is Motion Sensitivity?

~35% of people experience some form of motion discomfort. prefers-reduced-motion detects OS-level "Reduce motion" setting and lets you provide non-triggering alternatives.

🤢 Parallax Scrolling

Backgrounds moving at different speeds cause vestibular discomfort.

💫 Page Transitions

Slide/zoom transitions between routes trigger dizziness.

🔄 Auto-playing Animation

Continuous motion causes distraction and seizure risk.

📏 Zoom Effects

Scaling/zooming transitions cause nausea in vestibular disorders.

Principle: Don't remove visual feedback — replace motion with opacity/color changes. Card hover: instead of translateY, use a border highlight.

CSS Implementation

/* Default: animations enabled */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
  transform: translateY(-8px);
}

/* Reduced motion: replace with non-motion alternative */
@media (prefers-reduced-motion: reduce) {
  .card {
    transition: box-shadow 0.1s ease;
  }
  .card:hover {
    transform: none;
    box-shadow: 0 0 0 3px #a78bfa; /* outline instead */
  }

  /* Nuclear option: remove ALL animations */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

JavaScript Detection

const prefersReducedMotion = 
  window.matchMedia('(prefers-reduced-motion: reduce)');

prefersReducedMotion.addEventListener('change', (e) => {
  if (e.matches) disableAnimations();
  else enableAnimations();
});
