4 Pillars of Cognitive Accessibility

Affects 10-15% of the population — dyslexia, ADHD, autism, memory impairments, age-related cognitive decline.

P

Plain Language

Write at 8th-grade level. Short sentences, common words, no jargon. Use headings and bullets.

E

Error Prevention

Prevent mistakes, don't just report them. Confirmations, undo, inline validation, autosave.

P

Predictability

Consistent navigation, terminology, and help location across every page.

P

Progressive Disclosure

Show less, group logically. One task per screen. Reveal complexity on demand.

Mnemonic: PEPP — Prevent errors, Easy language, Predictable patterns, Progressive disclosure. "Design for the stressed, tired version of every user."

Submit → Error → "Invalid email format" → User confused

✅ Error Prevention + Recovery
