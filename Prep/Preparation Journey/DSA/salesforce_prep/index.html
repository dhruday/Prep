DSA Pattern Recognition Guide

Use this table to quickly identify which algorithm to reach for. Read the problem clue → match to a pattern → apply the standard technique.

If the problem says... Think about... Why
Subarray + target sum / count subarraysPrefix Sum + HashMapTrack cumulative sums; complement lookup in O(1)
Top K elements / K most frequentMin-Heap of size KKeep K largest; evict the smallest as you go
Kth largest / smallestHeap or QuickselectHeap: O(n log k); Quickselect: O(n) avg
Cache with eviction (LRU / LFU)HashMap + Doubly Linked ListO(1) lookup + O(1) ordered eviction
Connected grid cells / flood fillDFS or BFS on gridVisit all reachable cells from a starting cell
Shortest path in unweighted graphBFSBFS guarantees shortest hop-count path
Shortest path weighted graphDijkstra (min-heap)Greedy expansion of cheapest frontier node
Prerequisites / course ordering / dependenciesTopological Sort (Kahn's BFS)Process nodes with in-degree 0 first; detect cycles
All combinations / permutations / subsetsBacktrackingExplore all branches, prune invalid paths early
Overlapping intervals / schedulingSort + Heap or Sweep LineSort by start; use heap to track active intervals
Maximum contiguous subarray sumKadane's AlgorithmKeep running sum; reset when it goes negative
Repeated overlapping subproblemsDynamic ProgrammingMemoize or tabulate to avoid recomputation
Matching opening/closing bracketsStackPush opens; pop and verify on close
Search in sorted dataBinary SearchEliminate half the search space each step; O(log n)
At most / exactly K distinct elements in windowSliding WindowExpand right, shrink left to maintain invariant
Next greater / smaller elementMonotonic StackMaintain stack of decreasing elements; pop on found
Connected components / union queriesUnion-Find (DSU)Near O(1) amortized union and find operations
Anagram grouping / character frequencyHashMap with sorted key or freq arraySort chars as key; group equal signatures
Stream / online medianTwo Heaps (max + min)Max-heap for lower half, min-heap for upper half
Binary tree reconstruction / traversalDFS + HashMap for inorder indexPreorder gives root; inorder splits left/right subtrees
String split / rearrange / compressTwo Pointers or GreedyIn-place write pointer + read pointer pattern
Minimum steps to reach / transformBFS or DPBFS for fewest steps; DP for overlapping subproblems
