## 🚀 How to Use

1. **By Company** — Navigate to the company folder directly
2. **By Role Type** — Choose `FullStack/` or `Frontend/`
3. **By Index** — Use `00_INDEX.md` for searchable tables filtered by company, difficulty, result, and round type
4. **For Prep** — Each file contains **interview-ready answers** you can directly use in interviews

## 📄 File Format

Each experience file contains:
- **Meta table** — Company, Role, Level, YOE, Date, Result, Source URL
- **Round-by-round breakdown** — Every round with exact questions asked
- **Interview-ready answers** — Production-grade solutions with code, complexity, diagrams
- **Follow-up questions** — What interviewers asked as follow-ups
- **Key takeaways** — What worked, what to improve, candidate tips
- **Difficulty assessment** — Per-round difficulty rating with topics

## 🎯 Answer Quality Standards

Every interview-ready answer meets these standards:

| Round Type | Answer Quality |
|-----------|---------------|
| **DSA/Coding** | Brute → Optimal progression, production code, O() analysis, edge cases |
| **System Design** | Requirements, ASCII architecture, DB schema, API design, scale numbers |
| **Machine Coding** | Class diagrams, design patterns, SOLID, working code |
| **Frontend** | Component architecture, performance, a11y, testing strategy |
| **Behavioral** | STAR format with quantifiable impact metrics |
